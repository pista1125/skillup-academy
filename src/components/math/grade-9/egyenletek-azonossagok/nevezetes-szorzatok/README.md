# 3. Nevezetes szorzatok

## Tananyag Áttekintés
A legfontosabb algebrai azonosságok (nevezetes szorzatok), algebrai és geometriai szemléltetésük, valamint alkalmazásuk kifejezések kibontásában és numerikus fejszámolásban 9. osztályban.

---

## Fő Nevezetes Azonosságok
1. **Kéttagú összeg négyzete:**
   $$(a + b)^2 = a^2 + 2ab + b^2$$
   - Geometriai jelentés: egy $a+b$ oldalú négyzet területe felbontható egy $a^2$ és egy $b^2$ területű négyzetre, valamint két $ab$ területű téglalapra.
2. **Kéttagú különbség négyzete:**
   $$(a - b)^2 = a^2 - 2ab + b^2$$
   - Figyelem: a középső tag előjele negatív ($-2ab$), a harmadik tag négyzete pozitív ($+b^2$).
3. **Két tag összegének és különbségének szorzata:**
   $$(a + b)(a - b) = a^2 - b^2$$
   - A vegyes tagok ($+ab$ és $-ab$) kiejtik egymást!

---

## Gyakorlati Példák
- $(2x + 3)^2 = 4x^2 + 12x + 9$
- $(3x - 5y)^2 = 9x^2 - 30xy + 25y^2$
- $(4x + 7)(4x - 7) = 16x^2 - 49$
- Gyors fejszámolás: $51 \cdot 49 = (50 + 1)(50 - 1) = 50^2 - 1^2 = 2500 - 1 = 2499$.
