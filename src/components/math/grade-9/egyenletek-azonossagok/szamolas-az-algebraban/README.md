# 2. Számolás az algebrában

## Tananyag Áttekintés
Egynemű algebrai kifejezések azonosítása és összevonása, polinomok összeadása, kivonása, szorzása, valamint a zárójelfelbontás és előjelszabályok precíz alkalmazása 9. osztályban.

---

## Fő Témakörök és Műveletek
- **Egynemű kifejezések összevonása:**
  - Azok a tagok egyneműek, amelyek betűrésze (és a betűk kitevője) megegyezik (pl. $3a^2b$ és $-7a^2b$).
  - Összevonás: együtthatók előjeles összeadása: $3a^2b - 7a^2b = -4a^2b$.
- **Polinomok szorzása:**
  - Egytagú szorzása többtagúval: $a(b + c - d) = ab + ac - ad$.
  - Többtagú szorzása többtagúval: minden tagot minden taggal megszorzunk és összevonunk:
    $$(a + b)(c + d) = ac + ad + bc + bd$$
- **Zárójelfelbontási szabályok:**
  - Zárójel előtt $+$ jel: a tagok előjele változatlan marad.
  - Zárójel előtt $-$ jel: a zárójelen belüli minden tag előjele az ellentettjére változik: $-(a - b + c) = -a + b - c$.
