# 4. Szorzattá alakítás

## Tananyag Áttekintés
Polinomok szorzattá alakításának alapvető módszerei (kiemelés, nevezetes azonosságok alkalmazása visszafelé, csoportosítás), törtek egyszerűsítésének és egyenletmegoldásnak az előkészítése 9. osztályban.

---

## Fő Módszerek és Stratégiák
1. **Közös tényező kiemelése:**
   - A tagok legnagyobb közös osztójának (szám- és betűrész) zárójel elé hozása:
     $$6x^3 - 9x^2 = 3x^2(2x - 3)$$
2. **Nevezetes azonosságok felismerése és alkalmazása:**
   - Négyzetek különbsége: $a^2 - b^2 = (a - b)(a + b)$ (pl. $25x^2 - 16 = (5x - 4)(5x + 4)$).
   - Teljes négyzetté alakítás: $a^2 \pm 2ab + b^2 = (a \pm b)^2$ (pl. $x^2 - 10x + 25 = (x - 5)^2$).
3. **Csoportosításos szorzattá alakítás:**
   - Tagok párosítása közös tényezők kiemeléséhez:
     $$ax + ay + bx + by = a(x + y) + b(x + y) = (x + y)(a + b)$$
