# 8. Gyakorlás (Hatványozás)

## Tananyag Áttekintés
Összetett hatványos kifejezések egyszerűsítése, algebrai és numerikus azonosságok magabiztos alkalmazása 9. osztályban.

---

## Fő Típusfeladatok
- Törtes hatványkifejezések legegyszerűbb alakra hozása (közös alapra hozás, kitevők összevonása).
- Előjeles alapok hatványozása ($(-a)^{2n} = a^{2n}$, $(-a)^{2n+1} = -a^{2n+1}$).
- Hatványok összehasonlítása és nagyság szerinti rendezése közös alap vagy közös kitevő kialakításával (pl. $2^{30}$ vs. $3^{20}$).
- Egyenletek egyszerűbb hatványos alakokkal.
