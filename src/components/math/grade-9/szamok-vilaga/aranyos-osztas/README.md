# 5. Arányos osztás

## Tananyag Áttekintés
Adott mennyiség felosztása előre meghatározott arányban (két vagy több részre), arányos osztási feladatok geometriában, keverékekben és gazdasági helyzetekben 9. osztályban.

---

## Fő Témakörök és Módszerek
- **Arányos osztás algoritmusa:**
  - Ha az $M$ mennyiséget $a : b : c$ arányban kell szétosztani:
    1. Összes arányrész kiszámítása: $S = a + b + c$.
    2. Egy arányrész értéke: $e = \frac{M}{S}$.
    3. Az egyes részek nagysága: $R_1 = a \cdot e, R_2 = b \cdot e, R_3 = c \cdot e$.
    4. Ellenőrzés: $R_1 + R_2 + R_3 = M$.
- **Gyakorlati alkalmazások:**
  - Háromszög szögeinek vagy oldalainak kiszámítása adott arányból.
  - Ötvözetek, oldatok, receptek összetevőinek arányos kimérése.
  - Vállalkozási nyereség vagy költségek arányos elosztása.
