# 5. Gyakorlás (Kombinatorika)

## Tananyag Áttekintés
A kombinatorikai ismeretek, fadiagramok, számzárak, sorbarendezések és gráfos modellek feladatközpontú elmélyítése 9. osztályban.

---

## Fő Típusfeladatok
- Számalkotási feladatok adott számjegyekből (ismétlődéssel / ismétlődés nélkül, oszthatósági feltételekkel).
- Ültetési és sorbarendezési feladatok speciális megszorításokkal (pl. két barát egymás mellett vagy külön ül).
- Gráfelméleti bizonyítások a kézfogási lemma segítségével (lehet-e olyan társaság, ahol...).
- Úthálózatok és kombinatorikus játékok elemzése.
