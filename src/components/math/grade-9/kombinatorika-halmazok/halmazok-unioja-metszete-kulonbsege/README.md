# 7. Halmazok uniója, metszete, különbsége

## Tananyag Áttekintés
Halmazműveletek precíz definíciói, tulajdonságai (kommutativitás, asszociativitás, disztributivitás), De Morgan azonosságok és Venn-diagramos ábrázolás 9. osztályban.

---

## Fő Témakörök és Fogalmak
- **Halmazműveletek:**
  - **Metszet (közös rész):** $A \cap B = \{x \mid x \in A \text{ és } x \in B\}$.
    - Diszjunkt halmazok: ha $A \cap B = \emptyset$.
  - **Unió (egyesítés):** $A \cup B = \{x \mid x \in A \text{ vagy } x \in B\}$.
  - **Különbség:** $A \setminus B = \{x \mid x \in A \text{ és } x \notin B\}$.
  - **Komplementer (kiegészítő halmaz):** $H$ alaphalmazra nézve $\overline{A} = H \setminus A$.
- **Műveleti azonosságok:**
  - Kommutativitás: $A \cup B = B \cup A$, $A \cap B = B \cap A$.
  - Asszociativitás: $(A \cup B) \cup C = A \cup (B \cup C)$.
  - Disztributivitás: $A \cap (B \cup C) = (A \cap B) \cup (A \cap C)$.
  - De Morgan szabályok: $\overline{A \cup B} = \overline{A} \cap \overline{B}$ és $\overline{A \cap B} = \overline{A} \cup \overline{B}$.
- **Venn-diagramok:**
  - Síkbeli zárt görbékkel történő ábrázolás, területek besatírozása és azonosítása.
