# 9. Intervallumok

## Tananyag Áttekintés
A valós számok részhalmazainak megadása intervallumokkal, ábrázolás a számegyenesen, nyílt, zárt és félig nyílt intervallumok, valamint műveletek intervallumokkal 9. osztályban.

---

## Fő Témakörök és Fogalmak
- **Intervallum típusok és jelölések:**
  - **Zárt intervallum:** $[a; b] = \{x \in \mathbb{R} \mid a \le x \le b\}$ (a végpontok beletartoznak, teli karika).
  - **Nyílt intervallum:** $]a; b[ = \{x \in \mathbb{R} \mid a < x < b\}$ (a végpontok nem tartoznak bele, üres karika).
  - **Félig nyílt / félig zárt intervallumok:** $[a; b[$ és $]a; b]$.
  - **Végtelen intervallumok:** $[a; +\infty[$, $]-\infty; b[$, $]-\infty; +\infty[ = \mathbb{R}$.
- **Műveletek intervallumokkal:**
  - Két intervallum metszete: $]1; 5] \cap [3; 8[ = [3; 5]$.
  - Két intervallum uniója: $]1; 5] \cup [3; 8[ = ]1; 8[$.
  - Két intervallum különbsége: $[0; 6] \setminus ]2; 4] = [0; 2] \cup ]4; 6]$.
- **Számegyenesen való ábrázolás:**
  - Színezés, végpontok pontos megkülönböztetése.
