# 1. A sík geometriája

## Tananyag Áttekintés
A síkgeometria alapfogalmai (alapelemek, relációk, axiómák), szögek származtatása, szögfajták és nevezetes szögpárok vizsgálata 9. osztályban.

---

## Fő Témakörök és Fogalmak
- **Geometriai alapelemek:**
  - Alapfogalmak (nem definiáljuk): pont, egyenes, sík, illeszkedés.
  - Származtatott alakzatok: félegyenes, szakasz (két pont közötti egyenesrész), félsík.
- **Szögek fajtái:**
  - Nullszög ($0^\circ$), hegyesszög ($0^\circ < \alpha < 90^\circ$), derékszög ($90^\circ$), tompaszög ($90^\circ < \alpha < 180^\circ$), egyenesszög ($180^\circ$), homorúszög ($180^\circ < \alpha < 360^\circ$), teljesszög ($360^\circ$).
- **Nevezetes szögpárok:**
  - **Mellékszögek:** egy egyenesen lévő, közös szárú szögek, összegük $180^\circ$ ($\alpha + \beta = 180^\circ$).
  - **Csúcsszögek:** szárai egymás meghosszabbításai, nagyságuk egyenlő ($\alpha = \beta$).
  - **Pótszögek:** összegük $90^\circ$ ($\alpha + \beta = 90^\circ$).
  - **Párhuzamos szárú szögek:** egyállású szögek (egyenlők), váltószögek (egyenlők), társszögek (összegük $180^\circ$).
