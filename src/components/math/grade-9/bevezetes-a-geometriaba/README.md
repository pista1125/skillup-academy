# IV. Bevezetés a geometriába (9. osztály)
- Geometriai alapfogalmak: pont, egyenes, félegyenes, szakasz, sík, térelemek
- Szögek és szögfajták, szögpárok (mellékszögek, csúcsszögek, pótszögek, párhuzamos szárú szögek)
- Háromszögek felosztása oldalak és szögek szerint
- Háromszögek nevezetes vonalai és pontjai: oldalfelező merőlegesek, magasságvonalak, belső szögfelezők, súlyvonalak
- Alapvető geometriai szerkesztések (szakaszfelező, merőleges, szögfelező, szögmásolás)
