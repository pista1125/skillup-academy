# VI. Egybevágóság, négyszögek (9. osztály)
- Egybevágósági transzformációk: tengelyes tükrözés, középpontos tükrözés, eltolás, elforgatás
- Háromszögek egybevágóságának alapesetei (ooo, osho, oszö, osvzö)
- Négyszögek fajtái, tulajdonságai és hierarchiája:
  - Trapéz, húrtrapéz
  - Paralelogramma, rombusz, téglalap, négyzet
  - Deltoid
- Sokszögek átlóinak száma, belső és külső szögeinek összege
