# 6. Szimmetrikus négyszögek

## Tananyag Áttekintés
A konvex négyszögek osztályozása, hierarchikus kapcsolata, szimmetriatulajdonságai, oldalai, szögei és átlói 9. osztályban.

---

## Négyszögek Hierarchiája és Tulajdonságai
1. **Általános négyszög:**
   - Belső szögek összege: $(4 - 2) \cdot 180^\circ = 360^\circ$.
   - Átlók száma: $\frac{4(4-3)}{2} = 2$.
2. **Trapéz:**
   - Legalább egy párhuzamos oldalpárja van ($a \parallel c$).
   - **Húrtrapéz (szimmetrikus trapéz):** a szárak egyenlők ($b = d$), az alapon fekvő szögek egyenlők, átlói egyenlő hosszúak, 1 szimmetriatengelye van (az alapok közös felezőmerőlegese), húrnégyszög.
3. **Paralelogramma:**
   - Két párhuzamos oldalpárja van ($a \parallel c, b \parallel d$).
   - Szemközti oldalai és szögei egyenlők ($\alpha = \gamma, \beta = \delta$).
   - Szomszédos szögek összege $180^\circ$ ($\alpha + \beta = 180^\circ$).
   - Átlói felezik egymást.
   - Középpontosan szimmetrikus az átlók metszéspontjára.
4. **Rombusz:**
   - Minden oldala egyenlő hosszúságú paralelogramma ($a = b = c = d$).
   - Átlói merőlegesen felezik egymást és felezik a belső szögeket.
   - 2 szimmetriatengelye van (a két átlója), érintőnégyszög.
5. **Téglalap:**
   - Minden szöge derékszögű paralelogramma ($\alpha = \beta = \gamma = \delta = 90^\circ$).
   - Átlói egyenlő hosszúak és felezik egymást.
   - 2 szimmetriatengelye van (az oldalfelező merőlegesek), húrnégyszög.
6. **Négyzet:**
   - Egyszerre rombusz és téglalap (minden oldala egyenlő, minden szöge $90^\circ$).
   - 4 szimmetriatengelye és $90^\circ$-os forgásszimmetriája van.
7. **Deltoid:**
   - Két-két szomszédos oldala egyenlő ($a = b, c = d$).
   - Átlói merőlegesek egymásra, a szimmetriaátló felezi a másik átlót és két szemközti szöget.
   - 1 szimmetriatengelye van, érintőnégyszög.
