# 4. Szerkesztések

## Tananyag Áttekintés
Euklideszi alapszerkesztések körzővel és egyélű vonalzóval: szakasz- és szögmásolás, szakaszfelező merőleges, szögfelezés, merőleges és párhuzamos állítás, valamint háromszögek és négyszögek szerkesztése transzformációkkal 9. osztályban.

---

## Alapszerkesztések Lépései
1. **Szakaszfelező merőleges szerkesztése:**
   - A szakasz két végpontjából a félhossznál nagyobb, azonos sugarú köríveket húzunk.
   - A két metszéspontot összekötő egyenes a szakaszfelező merőleges.
2. **Szögfelező szerkesztése:**
   - A szög csúcsából tetszőleges sugárral elmetsszük a szárakat.
   - A metszéspontokból egyenlő sugarú köríveket húzunk a szögtartományba.
   - A metszéspontot összekötjük a csúccsal.
3. **Merőleges egyenes szerkesztése:**
   - Adott pontból (egyenesen lévő vagy azon kívüli pontból) merőleges állítása.
4. **Párhuzamos egyenes szerkesztése:**
   - Váltószögek másolásával vagy két egymást követő merőlegessel.
5. **Nevezetes szögek szerkesztése:**
   - $60^\circ$ (szabályos háromszögből), $30^\circ, 15^\circ$ (felezésekkel).
   - $90^\circ$ (merőlegesből), $45^\circ$ (felezéssel).
