# 16. Egyenlőtlenségek

## Tananyag Áttekintés
Egyenlőtlenségek grafikus és algebrai megoldása: melyik függvénygörbe fekszik a másik felett ($f(x) > g(x)$) vagy alatt ($f(x) < g(x)$), és a megoldáshalmaz felírása intervallumokkal 9. osztályban.

---

## Grafikus Megoldási Módszer
- **Értelmezés:**
  - $f(x) > g(x)$: azon $x$ értékek keresése, ahol az $f(x)$ grafikonja a $g(x)$ grafikonja **felett** halad.
  - $f(x) \le g(x)$: azon $x$ értékek, ahol az $f(x)$ grafikonja a $g(x)$ grafikonja **alatt** halad vagy metszi azt.
- **Lépések:**
  1. Ábrázoljuk mindkét függvényt ($f(x)$ és $g(x)$).
  2. Kiszámítjuk vagy leolvassuk a metszéspontok $x$-koordinátáit (a határokat).
  3. Megállapítjuk, mely intervallumokon teljesül az egyenlőtlenség.
  4. Felírjuk a megoldáshalmazt intervallumként (ügyelve a nyílt / zárt végpontokra).
- **Kisebb, nagyobb, egyenlő vizsgálatok:**
  - Nullával való összehasonlítás ($f(x) > 0 \implies$ az $x$-tengely feletti rész).
