# 3. Változások ábrázolása

## Tananyag Áttekintés
Két változó mennyiség közötti összefüggések, folyamatok időbeli változásának megjelenítése a derékszögű koordináta-rendszerben 9. osztályban.

---

## Fő Témakörök
- **Derékszögű koordináta-rendszer:**
  - $x$-tengely (abszcissza - független változó, pl. idő), $y$-tengely (ordináta - függő változó).
  - Négy síknegyed előjelei.
- **Folyamatok ábrázolása:**
  - Növekedés (pozitív változás), csökkenés (negatív változás), állandóság (vízszintes szakasz).
  - Változási sebesség szemléltetése a görbe meredekségével.
