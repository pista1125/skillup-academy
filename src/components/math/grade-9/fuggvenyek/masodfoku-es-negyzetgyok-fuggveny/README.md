# 13. Másodfokú függvény és a négyzetgyök-függvény

## Tananyag Áttekintés
A másodfokú alapfüggvény ($f(x) = x^2$) parabola grafikonja, a teljes négyzetté alakítás és a transzformációk ($f(x) = a(x-u)^2 + v$), valamint a négyzetgyök-függvény ($g(x) = \sqrt{x}$) tulajdonságai és ábrázolása 9. osztályban.

---

## Fő Függvények és Transzformációk
- **1. Másodfokú függvény:**
  - **Alapfüggvény:** $f(x) = x^2$, grafikonja origó csúcspontú parabola, $D_f = \mathbb{R}, R_f = [0; +\infty[$.
  - **Transzformált alak (teljes négyzet):**
    $$f(x) = a(x - u)^2 + v$$
    - Tengelyponti / csúcsponti forma: $C(u; v)$.
    - $u$: vízszintes eltolás ($x$-tengely).
    - $v$: függőleges eltolás ($y$-tengely).
    - $a > 0$: felfelé nyíló parabola (minimuma van a csúcspontban: $\min = v$ az $x=u$ helyen).
    - $a < 0$: lefelé nyíló parabola (maximuma van a csúcspontban: $\max = v$ az $x=u$ helyen).
  - Általános alakból ($ax^2 + bx + c$) áttérés teljes négyzetté: kiemelés és kiegészítés.
- **2. Négyzetgyök-függvény:**
  - **Alapfüggvény:** $g(x) = \sqrt{x}$.
  - Értelmezési tartomány: $D_g = [0; +\infty[$ (nemnegatív számok).
  - Értékkészlet: $R_g = [0; +\infty[$.
  - Grafikonja: fekvő félparabola, szigorúan monoton növekvő.
  - Transzformációk: $g(x) = a\sqrt{x - u} + v$, kezdőpontja $(u; v)$.
