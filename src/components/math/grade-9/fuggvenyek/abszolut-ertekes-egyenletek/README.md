# 17. Abszolút értékes egyenletek

## Tananyag Áttekintés
Abszolút értéket tartalmazó egyenletek és egyenlőtlenségek megoldása geometriai szemlélettel (távolság a számegyenesen) és algebrai esetszétválasztással 9. osztályban.

---

## Megoldási Módszerek
1. **Geometriai módszer (távolság):**
   - $|x - a| = b$ ($b \ge 0$): azon $x$ számok, amelyek az $a$ számtól pontosan $b$ távolságra vannak.
   - Megoldások: $x_1 = a - b$ és $x_2 = a + b$.
   - $|x - a| < b$: az $a$ pont $b$ sugarú környezete: $x \in ]a - b; a + b[$.
2. **Algebrai esetszétválasztás:**
   - $|kifejezés| = \begin{cases} kifejezés, & \text{ha } kifejezés \ge 0 \\ -(kifejezés), & \text{ha } kifejezés < 0 \end{cases}$
   - Megkeressük a zérushelyet, és mindkét intervallumon külön megoldjuk az egyenletet, majd összevetjük az intervallummal.
3. **Grafikus megoldás:**
   - $f(x) = |x - u| + v$ és $g(x) = c$ ábrázolása, metszéspontok $x$-értékeinek leolvasása.
