# 11. Függvények jellemzése

## Tananyag Áttekintés
A függvények átfogó vizsgálatának szempontrendszere: értelmezési tartomány, értékkészlet, zérushely, monotonitás, paritás és korlátosság 9. osztályban.

---

## Jellemzési Szempontok és Fogalmak
1. **Értelmezési tartomány ($D_f$):** a bemeneti valós számok intervalluma.
2. **Értékkészlet ($R_f$):** a grafikon $y$-tengelyre vetített tartománya (felvett értékek).
3. **Zérushelyek ($x_0$):** azok az $x$ értékek, ahol $f(x) = 0$ (a grafikon és az $x$-tengely metszéspontjai).
4. **Monotonitás (menet):**
   - Szigorúan monoton növekvő: $x_1 < x_2 \implies f(x_1) < f(x_2)$.
   - Szigorúan monoton csökkenő: $x_1 < x_2 \implies f(x_1) > f(x_2)$.
5. **Paritás (szimmetria):**
   - **Páros függvény:** $f(-x) = f(x)$ minden $x \in D_f$ esetén (grafikonja az $y$-tengelyre szimmetrikus, pl. $x^2, |x|$).
   - **Páratlan függvény:** $f(-x) = -f(x)$ minden $x \in D_f$ esetén (grafikonja az origóra középpontosan szimmetrikus, pl. $x, x^3, \frac{1}{x}$).
6. **Korlátosság:**
   - Alulról korlátos (van olyan $k$, hogy $f(x) \ge k$), felülről korlátos (van olyan $K$, hogy $f(x) \le K$), vagy korlátos (mindkét oldalról).
