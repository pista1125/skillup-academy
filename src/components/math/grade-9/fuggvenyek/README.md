# V. Függvények (9. osztály)
- Függvény fogalma, alapfogalmak: értelmezési tartomány (D_f), értékkészlet (R_f), hozzárendelési szabály
- Lineáris függvények ábrázolása, meredekség (m), tengelymetszetek
- Másodfokú függvények alapalakja és transzformációi (f(x) = a(x-u)² + v)
- Abszolútérték-függvény és alapvető hatványfüggvények ábrázolása
- Függvények vizsgálata: zérushely, szélsőérték (minimum, maximum), menet (monotonitás), paritás, korlátosság
