# 7. Ráadás – Párhuzamos szelők tétele

## Tananyag Áttekintés
A párhuzamos szelők és párhuzamos szelőszakaszok tétele, a tétel megfordítása, valamint szakaszok adott arányú osztása és szerkesztése.

---

## Fő Tételek és Összefüggések

- **Párhuzamos szelők tétele:**
  - Ha egy szög szárait párhuzamos egyenesekkel metsszük, akkor az egyik száron keletkező szakaszok aránya megegyezik a másik száron keletkező megfelelő szakaszok arányával:
    $$\frac{a_1}{a_2} = \frac{b_1}{b_2}$$

- **Párhuzamos szelőszakaszok tétele:**
  - A párhuzamosokból a szárak által kimetszett szakaszok aránya megegyezik a csúcstól mért megfelelő szárszakaszok arányával:
    $$\frac{c_1}{c_2} = \frac{a_1}{a_1 + a_2}$$

- **Szerkesztési alkalmazás:**
  - Szakasz felosztása adott számú egyenlő részre vagy adott arányban párhuzamos szelőkkel.
  - Negyedik arányos szerkesztése ($a : b = c : x$).
