# IX. Hasonlóság (10. osztály)
- Párhuzamos szelők és szelőszakaszok tétele és megfordítása
- Háromszögek hasonlóságának alapesetei és kritériumai
- Derékszögű háromszögek tételei: magasságtétel és befogótétel
- Hasonló síkidomok kerületének és területének aránya ($k_1/k_2 = \lambda$, $T_1/T_2 = \lambda^2$)
- Hasonló testek felszínének és térfogatának aránya ($A_1/A_2 = \lambda^2$, $V_1/V_2 = \lambda^3$)
- Gyakorlati magasság- és távolságmérések hasonlósággal
