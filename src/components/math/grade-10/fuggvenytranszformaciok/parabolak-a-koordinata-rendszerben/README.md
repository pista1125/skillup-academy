# 2. Parabolák a koordináta-rendszerben (21. lecke)

## Tananyag Áttekintés
Az $f(x) = x^2$ alapfüggvény (normálparabola) tulajdonságai, szimmetriája, csúcspontja és elhelyezkedése a derékszögű koordináta-rendszerben.

---

## Fő Témakörök és Jellemzés

- **Az $f(x) = x^2$ alapfüggvény vizsgálata:**
  - **Értelmezési tartomány:** $D_f = \mathbb{R}$.
  - **Értékkészlet:** $R_f = [0; \infty[$ (mivel bármely valós szám négyzete nemnegatív).
  - **Zérushely:** $x = 0$ ($f(0) = 0$).
  - **Szélsőérték:** Globális minimuma van az $x = 0$ helyen, a minimum értéke $y = 0$. Maximumpontja nincs.
  - **Monotonitás:** Szigorúan monoton csökken a $]-\infty; 0]$ intervallumon, szigorúan monoton nő a $[0; \infty[$ intervallumon.
  - **Paritás és szimmetria:** Páros függvény ($f(-x) = (-x)^2 = x^2 = f(x)$), a grafikon szimmetrikus az $y$-tengelyre.
  - **Csúcspont (tengelypont):** $C(0; 0)$.
