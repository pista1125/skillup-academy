# 6. Másodfokú függvények (25. lecke)

## Tananyag Áttekintés
Az általános alakban megadott másodfokú függvények ($f(x) = ax^2 + bx + c$) átalakítása kanonikus alakra teljes négyzetté kiegészítéssel, a parabola csúcspontjának algebrai meghatározása és a függvény tulajdonságainak leolvasása.

---

## Fő Témakörök és Átalakítások

- **A másodfokú függvény alakjai:**
  - **Polinom (általános) alak:** $f(x) = ax^2 + bx + c$ ($a \neq 0$).
  - **Kanonikus (teljes négyzetes) alak:** $f(x) = a(x - u)^2 + v$, ahol $C(u; v)$ a parabola csúcspontja.

- **Áttérés teljes négyzetté kiegészítéssel:**
  1. $a$ kiemelése a másodfokú és elsőfokú tagból: $a \left(x^2 + \frac{b}{a}x\right) + c$.
  2. Belső kifejezés kiegészítése teljes négyzetté: $\left(x + \frac{b}{2a}\right)^2 - \left(\frac{b}{2a}\right)^2$.
  3. Kifejtés és összevonás:
     $$u = -\frac{b}{2a}, \quad v = c - \frac{b^2}{4a} = -\frac{b^2 - 4ac}{4a} = -\frac{D}{4a}$$

- **A csúcspont koordinátái:**
  $$C\left(-\frac{b}{2a}; -\frac{D}{4a}\right)$$
  - Ha $a > 0$: a csúcspontban minimum van.
  - Ha $a < 0$: a csúcspontban maximum van.
