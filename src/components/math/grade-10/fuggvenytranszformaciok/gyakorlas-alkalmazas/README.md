# 8. Altéma: Gyakorlás, alkalmazás

## Tananyag Áttekintés
A függvénytranszformációk és másodfokú függvények gyakorlati alkalmazásai: szélsőérték-feladatok (pl. maximális területű bekerített telek, optimális bevétel), fizikai folyamatok (hajítások pályája) és grafikus egyenletmegoldás.

---

## Fő Témakörök és Feladattípusok

- **Gyakorlati szélsőérték-feladatok:**
  - Adott kerületű téglalapok közül a négyzet területe maximális ($x = K/4$).
  - Egy meglévő fal mentén bekerített 3 oldalas kordon dupla akkora maximális területet ad ($x = K/4$, $b = K/2$, $T_{\max} = K^2 / 8$).
  - Költség- és bevételfüggvények profitmaximuma.
  - A parabola csúcspontjának fizikai és gazdasági értelmezése.

- **Fizikai hajítási modellek:**
  - Függőleges hajítás: $h(t) = -5t^2 + v_0 t + h_0$.
  - Tetőpont ideje: $t_{\text{tető}} = v_0 / 10$, maximális magasság: $h_{\max} = h_0 + v_0^2 / 20$.
  - Talajra érkezés ideje: $h(t) = 0$ pozitív gyöke.

- **Függvények grafikus egyenlet- és egyenlőtlenség-megoldásban:**
  - Az $f(x) = g(x)$ egyenlet megoldása a grafikonok metszéspontjainak $x$-koordinátája.
  - Az $f(x) \le g(x)$ egyenlőtlenség megoldása azon $x$ intervallumok, ahol $f$ grafikonja a $g$ grafikonja alatt halad vagy metszi azt.
  - Függvények leszűkített $[a; b]$ értelmezési tartományon (a csúcspont és a végpontok szerepe az értékkészletben).
