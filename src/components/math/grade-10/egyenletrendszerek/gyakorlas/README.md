# 4. Gyakorlás (10. lecke)

## Tananyag Áttekintés
Az egyenletrendszer-megoldási technikák magabiztos elmélyítése, a legcélravezetőbb algebrai stratégia kiválasztása adott típusú egyenletekhez, valamint a típusfeladatok begyakorlása.

---

## Fő Témakörök és Gyakorlási Területek

- **A leghatékonyabb megoldási módszer kiválasztása:**
  - Mikor érdemes behelyettesítő módszert választani? (ha valamelyik ismeretlen együtthatója $1$ vagy $-1$).
  - Mikor célszerű az egyenlő együtthatók módszere? (ha a keresztszorzások kisebb számokkal járnak, pl. $2x + 3y$ és $4x - 5y$).
  - Törtes és zárójeles egyenletrendszerek rendezése standard alakra ($ax + by = c$).

- **Összetett feladattípusok:**
  - Paraméteres egyenletrendszerek vizsgálata (milyen $p$ valós paraméter esetén nincs / pontosan egy / végtelen sok megoldás?).
  - Szimmetrikus egyenletrendszerek megoldása új ismeretlenek bevezetésével ($u = x + y$, $v = x \cdot y$).
  - Geometriai és gazdasági szöveges feladatok megoldása és az eredmények reális értelmezése.
