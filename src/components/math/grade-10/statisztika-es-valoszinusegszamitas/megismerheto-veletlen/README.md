# 7. Megismerhető véletlen (56. lecke)

## Tananyag Áttekintés
A valószínűség matematikai modellje: eseménytér felírása, elemi események egyenlő valószínűsége, és a klasszikus valószínűségi modell felépítése.

---

## Fő Fogalmak és Modellek

- **Eseménytér ($\Omega$):**
  - A kísérlet összes lehetséges kimenetelének halmaza.
  - Elemi események: Az eseménytér egyelemű részhalmazai.

- **A klasszikus valószínűségi mező feltétele:**
  - Véges sok lehetséges kimenetel ($n$).
  - Szimmetria: Minden elemi esemény egyenlően valószínű (pl. szabályos dobókocka vagy pénzérme).

- **A klasszikus valószínűség képlete:**
  - $P(A) = \frac{\text{kedvező kimenetelek száma}}{\text{összes lehetséges kimenetel száma}} = \frac{k}{n}$
  - Kombinatorikai eszközök (permutáció, kombináció) bevonása a kedvező és összes eset megszámolására.
