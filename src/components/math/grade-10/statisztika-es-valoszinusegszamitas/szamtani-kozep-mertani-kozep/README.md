# 2. Ráadás – Számtani közép, mértani közép

## Tananyag Áttekintés
Két nemnegatív valós szám számtani és mértani közepe közötti nevezetes egyenlőtlenség vizsgálata, geometriai és algebrai bizonyítása, valamint alkalmazása szélsőérték-feladatokban.

---

## Fő Fogalmak és Összefüggések

- **Mértani közép ($G$):**
  - Két nemnegatív szám mértani közepe: $G = \sqrt{a \cdot b}$
  - Geometriai jelentése: a magasságtétel és a befogótétel derékszögű háromszögekben.

- **A számtani és mértani közép közötti egyenlőtlenség:**
  - Bármely $a, b \ge 0$ valós szám esetén:
  - $\frac{a + b}{2} \ge \sqrt{ab}$
  - Egyenlőség akkor és csak akkor áll fenn, ha $a = b$.

- **Szélsőérték-feladatok algebrai megoldása:**
  - Ha két pozitív szám összege állandó ($a + b = K$), szorzatuk akkor maximális, ha $a = b$.
  - Ha két pozitív szám szorzata állandó ($a \cdot b = P$), összegük akkor minimális, ha $a = b$.
