# VI. Egybevágóság és kör (10. osztály)
- Kör és egyenes kölcsönös helyzete (érintő, szelő, kívül fekvő egyenes)
- Kerületi és középponti szögek tétele és a tétel megfordítása
- Thálész-tétel és annak kiterjesztése kerületi szögként
- Érintőszakaszok egyenlősége, érintőnégyszögek tétele ($a+c = b+d$)
- Húrnégyszögek tétele (szemközti szögek összege 180°) és megfordítása
- Háromszögek beírt és köré írt köre, valamint hozzáírt körök
