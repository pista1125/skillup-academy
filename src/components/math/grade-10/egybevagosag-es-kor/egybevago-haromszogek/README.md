# 2. Egybevágó háromszögek (42. lecke)

## Tananyag Áttekintés
Egybevágó háromszögek tulajdonságainak alkalmazása geometriai tételek és bizonyítások során: egyenlő szakaszok és szögek igazolása összetett síkgeometriai alakzatokban.

---

## Fő Fogalmak és Alkalmazások

- **Megfelelő elemek párosítása:**
  - Csúcsok helyes sorrendje az egybevágósági relációban ($ABC \triangle \cong A'B'C'$).
  - Szemközti oldalak és szögek azonosítása.

- **Bizonyítási feladatok:**
  - Szakaszok egyenlőségének igazolása egybevágó háromszögek keresésével.
  - Szögek egyenlőségének levezetése.
  - Háromszögek nevezetes vonalainak tulajdonságai (oldalfelező merőlegesek, szögfelezők, magasságvonalak).

- **Szimmetrikus alakzatok szétbontása:**
  - Egyenlő szárú és egyenlő oldalú háromszögek belső szimmetriái.
  - Négyszögek átlói által alkotott háromszögek egybevágóságának vizsgálata.
