# 7. Sokszögek és körök (47. lecke)

## Tananyag Áttekintés
Szabályos és általános sokszögek kapcsolata a beírt és köré írt körökkel: húrsokszögek, érintősokszögek, szabályos n-szögek metrikus relációi.

---

## Fő Fogalmak és Összefüggések

- **Szabályos sokszögek és köreik:**
  - Minden szabályos sokszögnek létezik beírt és köré írt köre, melyek középpontja megegyezik.
  - Szabályos sokszög felbontása $n$ darab egybevágó egyenlő szárú háromszögre.
  - Középponti szög: $\frac{360^\circ}{n}$, belső szög: $\frac{(n-2)\cdot 180^\circ}{n}$.

- **Háromszögek nevezetes körei:**
  - Köré írt kör középpontja: az oldalfelező merőlegesek metszéspontja ($R = \frac{abc}{4T}$).
  - Beírt kör középpontja: a belső szögfelezők metszéspontja ($r = \frac{T}{s}$, ahol $s = \frac{a+b+c}{2}$).

- **Négyszögek speciális körei:**
  - **Húrnégyszögek:** Szemközti szögeik összege $180^\circ$ ($\alpha + \gamma = \beta + \delta = 180^\circ$).
  - **Érintőnégyszögek:** Szemközti oldalaik összege egyenlő ($a + c = b + d$).
