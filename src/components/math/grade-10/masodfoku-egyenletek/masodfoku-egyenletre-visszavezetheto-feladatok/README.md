# 8. Másodfokú egyenletre visszavezethető feladatok (36. lecke)

## Tananyag Áttekintés
Olyan összetettebb egyenletek (negyedfokú bikvadratikus, törtes, gyökös és abszolútértékes egyenletek) megoldása, amelyek új ismeretlen bevezetésével vagy algebrai átalakításokkal másodfokúvá alakíthatók.

---

## Fő Típusok és Módszerek

- **Bikvadratikus egyenletek ($ax^4 + bx^2 + c = 0$):**
  - Új ismeretlen bevezetése: $u = x^2$ ($u \ge 0$).
  - Ekkor az egyenlet: $au^2 + bu + c = 0$.
  - Megoldjuk $u$-ra ($u_1, u_2$), majd visszatérünk $x$-hez: $x = \pm\sqrt{u}$ (csak a nemnegatív $u$ gyökökből adódik valós $x$).

- **Ismeretlent a nevezőben tartalmazó (törtes) egyenletek:**
  - Kikötések felírása (nevezők nem lehetnek nullák).
  - Beszorzás a közös nevezővel $\rightarrow$ másodfokú egyenlet.
  - A kapott gyökök összevetése a kikötésekkel (hamis gyökök kizárása).

- **Gyökös egyenletek másodfokú alakra hozása:**
  - Gyökös tag izolálása, négyzetre emelés mindkét oldalon.
  - Ellenőrzés kötelező az eredeti egyenletbe való behelyettesítéssel.
