# V. Másodfokú egyenletek (10. osztály)
- A másodfokú egyenlet általános alakja: $ax^2 + bx + c = 0$ ($a \neq 0$)
- A másodfokú egyenlet megoldóképlete és a diszkrimináns ($D = b^2 - 4ac$)
- Gyökök száma és jellege a diszkrimináns előjele alapján ($D > 0, D = 0, D < 0$)
- Viète-formulák ($x_1 + x_2 = -\frac{b}{a}$, $x_1 x_2 = \frac{c}{a}$) és a másodfokú polinom gyöktényezős alakja: $a(x-x_1)(x-x_2)$
- Másodfokú egyenlőtlenségek megoldása grafikus módszerrel és előjeltáblázattal
- Másodfokúra visszavezethető egyenletek új ismeretlen bevezetésével
