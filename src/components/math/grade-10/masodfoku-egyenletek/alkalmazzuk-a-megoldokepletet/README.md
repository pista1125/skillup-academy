# 4. Alkalmazzuk a megoldóképletet! (32. lecke)

## Tananyag Áttekintés
A másodfokú megoldóképlet rutinszerű, magabiztos alkalmazása különféle egyenleteknél, nullára rendezés, előjelhibák kiküszöbölése és a gyökök ellenőrzése.

---

## Fő Témakörök és Gyakorlati Lépések

- **A megoldás algoritmusa:**
  1. **Nullára rendezés:** Minden tagot egy oldalra viszünk ($ax^2 + bx + c = 0$).
  2. **Együtthatók azonosítása:** $a, b, c$ előjeles értékeinek pontos leolvasása (pl. $2x^2 - 5x - 3 = 0 \Rightarrow a=2, b=-5, c=-3$).
  3. **Behelyettesítés a képletbe:** Különös figyelem a $-b$-re (ha $b = -5$, akkor $-b = 5$) és a $(-b)^2$-re.
  4. **Kiszámítás:** A diszkrimináns kiszámítása, gyökvonás, majd $x_1$ és $x_2$ meghatározása.
  5. **Ellenőrzés:** Behelyettesítés az eredeti egyenletbe.

- **Egyszerűsítés szorzótényezővel:**
  - Ha az együtthatóknak van közös osztója, érdemes előre végigosztani az egyenletet.
  - Törtes együtthatók esetén beszorzás a közös nevezővel.
