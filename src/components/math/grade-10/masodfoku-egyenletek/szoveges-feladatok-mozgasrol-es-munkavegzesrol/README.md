# 10. Szöveges feladatok mozgásról és munkavégzésről (38. lecke)

## Tananyag Áttekintés
Összetett gyakorlati problémák modellezése: egyenes vonalú egyenletes mozgások (sebesség, út, idő: $s = v \cdot t$) és együttes munkavégzések (teljesítmény, idő, munka: $W = P \cdot t$), amelyek törtes másodfokú egyenletekre vezetnek.

---

## Fő Témakörök és Modellek

- **Mozgásos feladatok:**
  - Alapösszefüggés: $t = \frac{s}{v}$.
  - Ha két jármű sebessége vagy menetideje eltér egymástól: pl. $\frac{s}{v} - \frac{s}{v + \Delta v} = \Delta t$.
  - Beszorzás a nevezőkkel ($v(v + \Delta v)$) $\rightarrow$ másodfokú egyenlet $v$-re.
  - Negatív sebességérték elvetése.

- **Együttes munkavégzéses feladatok:**
  - Együtt végzett munka: $P_{\text{összes}} = P_1 + P_2 = \frac{1}{t_1} + \frac{1}{t_2}$.
  - Ha az egyik munkás $d$ órával gyorsabban végez, mint a másik ($t_2 = t_1 + d$):
    $$\frac{1}{t_1} + \frac{1}{t_1 + d} = \frac{1}{t_{\text{közös}}}$$
  - A közös nevezővel beszorozva másodfokú egyenletet kapunk az időre.
