# 12. Gyakorlás, tudáspróba (40. lecke)

## Tananyag Áttekintés
A fejezet átfogó összefoglalása, a megszerzett tudás elmélyítése és a témazáró felmérőre való felkészülés a másodfokú egyenletek témaköréből.

---

## Fő Fogalmak és Összefoglaló Témák

- **Hiányos másodfokú egyenletek megoldása:**
  - $ax^2 + c = 0 \implies x^2 = -\frac{c}{a}$
  - $ax^2 + bx = 0 \implies x(ax + b) = 0$

- **A teljes négyzetté kiegészítés lépései és logikája:**
  - Átalakítás $(x \pm u)^2 = v$ alakra.

- **A megoldóképlet magabiztos alkalmazása:**
  - $x_{1,2} = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$
  - A diszkrimináns ($D = b^2 - 4ac$) szerepe a valós gyökök számában ($D > 0, D = 0, D < 0$).

- **Visszavezethető egyenletek:**
  - Új ismeretlen bevezetése (biquadratikus egyenletek $u = x^2$, törtes egyenletek).

- **Szöveges feladatok megoldási algoritmusa:**
  - Ismeretlen kijelölése, értelmezési tartomány/feltételek rögzítése.
  - Egyenlet felírása, megoldása és a gyökök ellenőrzése a szöveg alapján (hamis gyökök kizárása, pl. negatív hosszúság, negatív idő).
  - Szöveges válaszadás mértékegységekkel.
