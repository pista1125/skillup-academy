# III. Hatványozás és négyzetgyök (10. osztály)
- A hatványfogalom kiterjesztése racionális kitevőre ($a^{m/n} = \sqrt[n]{a^m}$)
- Az n-edik gyök fogalma és azonosságai nemnegatív számokra
- Gyökös kifejezések átalakítása, tényező kivitele a gyökjel alól és bevitele a gyökjel alá
- Nevező gyöktelenítése egytagú és kéttagú gyökös nevezők esetén
- Számítások normálalakkal és törtkitevős hatványokkal
