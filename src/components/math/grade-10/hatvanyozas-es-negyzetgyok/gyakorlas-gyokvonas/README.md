# 7. Gyakorlás (18. lecke)

## Tananyag Áttekintés
Összetett négyzetgyökös algebrai feladatok megoldása, nevezetes azonosságok alkalmazása gyökös kifejezéseknél, a gyökös egyenletek bevezető típusai és a helyes kikötések felírása.

---

## Fő Témakörök és Gyakorlási Területek

- **Nevezetes azonosságok gyökös számokkal:**
  - $(\sqrt{a} + \sqrt{b})^2 = a + 2\sqrt{ab} + b$
  - $(\sqrt{a} - \sqrt{b})^2 = a - 2\sqrt{ab} + b$
  - $(\sqrt{a} + \sqrt{b})(\sqrt{a} - \sqrt{b}) = a - b$
  - Gyök alatti teljes négyzetek felismerése: pl. $\sqrt{7 + 4\sqrt{3}} = \sqrt{(2 + \sqrt{3})^2} = 2 + \sqrt{3}$.

- **Értelmezési tartomány (kikötések) meghatározása:**
  - Páros gyök alatt csak nemnegatív kifejezés állhat: $\sqrt{f(x)} \Rightarrow f(x) \ge 0$.
  - Tört nevezőjében lévő gyök: $\frac{1}{\sqrt{g(x)}} \Rightarrow g(x) > 0$.

- **Egyszerű gyökös egyenletek előkészítése:**
  - Négyzetre emelés mint nem ekvivalens átalakítás (hamis gyökök keletkezhetnek).
  - Az ellenőrzés kötelező lépése.
