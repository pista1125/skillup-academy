# 7. Ráadás – Viète-formulák!

## Tananyag Áttekintés
François Viète francia matematikus tételei: a másodfokú egyenlet együtthatói és a gyökök közötti algebrai kapcsolat, valamint ezen összefüggések hatékony alkalmazása feladatmegoldásokban.

---

## Fő Képletek és Alkalmazások

- **A Viète-formulák tétele:**
  - Ha az $ax^2 + bx + c = 0$ ($a \neq 0$) egyenlet gyökei $x_1$ és $x_2$, akkor:
    $$x_1 + x_2 = -\frac{b}{a}$$
    $$x_1 \cdot x_2 = \frac{c}{a}$$
  - Főegyütthatós ($a=1$, azaz $x^2 + px + q = 0$) alakban:
    $$x_1 + x_2 = -p \quad \text{és} \quad x_1 \cdot x_2 = q$$

- **Gyakorlati trükkök és alkalmazások:**
  - Egész gyökök gyors megsejtése és ellenőrzése fejben.
  - Gyökök előjelének megállapítása anélkül, hogy kiszámítanánk őket.
  - Szimmetrikus kifejezések kiszámítása a gyökökből:
    $$x_1^2 + x_2^2 = (x_1 + x_2)^2 - 2x_1 x_2 = \left(-\frac{b}{a}\right)^2 - 2\frac{c}{a}$$
    $$\frac{1}{x_1} + \frac{1}{x_2} = \frac{x_1 + x_2}{x_1 x_2} = \frac{-b/a}{c/a} = -\frac{b}{c}$$
