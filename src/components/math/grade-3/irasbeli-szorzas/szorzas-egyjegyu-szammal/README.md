# 1. Szorzás egyjegyű számmal

## Tananyag Áttekintés
A háromjegyű számok egyjegyű számmal való szorzásának szóbeli megalapozása: a többjegyű szám felbontása százasok, tízesek és egyesek összegére, az összeg tagonkénti szorzása, és a részszorzatok összeadása.

---

## Szóbeli Szorzás Tagolással

### Példa: $234 \cdot 3$

$$234 = 200 + 30 + 4$$

1. **Százasok szorzása:** $200 \cdot 3 = \mathbf{600}$
2. **Tízesek szorzása:** $30 \cdot 3 = \mathbf{90}$
3. **Egyesek szorzása:** $4 \cdot 3 = \mathbf{12}$
4. **Összegzés:** $600 + 90 + 12 = \mathbf{702}$

$$\text{Kifejezéssel: } 234 \cdot 3 = (200 \cdot 3) + (30 \cdot 3) + (4 \cdot 3) = 600 + 90 + 12 = \mathbf{702}$$
