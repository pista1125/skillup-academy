# 6. Megálló (Összefoglalás)

## Tananyag Áttekintés
A háromjegyű számok egyjegyű szorzóval történő írásbeli szorzásának, becslésének, műveleti sorrendjének és szöveges feladatainak átfogó összefoglaló tudáspróbája 3. osztályos szinten.

---

## Összefoglaló Ellenőrző Lista

- [x] **Szóbeli felbontás:** Háromjegyű szám tagonkénti szorzása egyjegyű számmal.
- [x] **Becslés:** Szorzat előzetes megbecslése kerek tízesekkel és százasokkal.
- [x] **Írásbeli szorzás:** Algoritmus pontos végrehajtása átlépéssel és maradékok felvitelével.
- [x] **Összefüggések:** Tényezők és a szorzat arányos változásának megértése.
- [x] **Műveleti sorrend:** A szorzás elsőbbségének és a zárójeleknek a helyes alkalmazása.
- [x] **Szöveges feladatok:** Szorzást tartalmazó összetett szöveges feladatok megoldása és ellenőrzése.
