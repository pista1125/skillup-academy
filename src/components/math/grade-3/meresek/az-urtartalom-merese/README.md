# 3. Az űrtartalom mérése

## Tananyag Áttekintés
Folyadékok térfogatának és az edények befogadóképességének (űrtartalmának) mérése: milliliter, centiliter, deciliter, liter és hektoliter összefüggései, mértékváltások és szöveges feladatok.

---

## Mértékegységek és Váltószámok

```mermaid
graph LR
    ML["milliliter (ml)"] -- "· 10" --> CL["centiliter (cl)"]
    CL -- "· 10" --> DL["deciliter (dl)"]
    DL -- "· 10" --> L["liter (l)"]
    L -- "· 100" --> HL["hektoliter (hl)"]
```

### 1. Alapvető Átváltások
$$1\text{ cl} = 10\text{ ml}$$
$$1\text{ dl} = 10\text{ cl} = 100\text{ ml}$$
$$1\text{ l} = 10\text{ dl} = 100\text{ cl} = 1000\text{ ml}$$
$$1\text{ hl} = 100\text{ l}$$

### 2. Törtrészek a Mindennapokban
- **Fél liter:** $\frac{1}{2}\text{ l} = 5\text{ dl} = 500\text{ ml}$
- **Negyed liter:** $\frac{1}{4}\text{ l} = 2\text{ dl } 5\text{ cl} = 250\text{ ml}$
- **Háromnegyed liter:** $\frac{3}{4}\text{ l} = 7\text{ dl } 5\text{ cl} = 750\text{ ml}$

---

## Gyakorlati Példák
- $2\text{ l } 6\text{ dl} = 26\text{ dl} = 2600\text{ ml}$
- $1\text{ l} - 35\text{ cl} = 100\text{ cl} - 35\text{ cl} = 65\text{ cl}$
- $4\text{ dl } 50\text{ ml} + 5\text{ dl } 50\text{ ml} = 9\text{ dl } 100\text{ ml} = 10\text{ dl} = 1\text{ l}$
