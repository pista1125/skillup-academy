# 5. A kerület mérése

## Tananyag Áttekintés
A kerület fogalmának szemléletes megértése: a síkidomot határoló vonalak (oldalak) együttes hossza. A kerület meghatározása körbejárással, zsinórral, lépésekkel, valamint az oldalhosszak megmérésével és összeadásával.

---

## Mi a Kerület ($K$)?

> [!IMPORTANT]
> A síkidom **kerülete ($K$)** a határoló oldalainak összege, vagyis amekkora utat megteszünk, ha a síkidomot **teljesen körbejárjuk**.

---

## Sokszögek Kerületének Kiszámítása

### 1. Háromszög Kerülete
$$K = a + b + c$$
- *Példa:* $a = 4\text{ cm}$, $b = 5\text{ cm}$, $c = 6\text{ cm} \implies K = 4 + 5 + 6 = \mathbf{15\text{ cm}}$.

### 2. Tetszőleges Sokszög Kerülete
Az összes határoló oldal hosszát összeadjuk:
$$K = a + b + c + d + \dots$$
- *Példa (ötszög):* $3\text{ cm} + 4\text{ cm} + 3\text{ cm} + 5\text{ cm} + 4\text{ cm} = \mathbf{19\text{ cm}}$.
