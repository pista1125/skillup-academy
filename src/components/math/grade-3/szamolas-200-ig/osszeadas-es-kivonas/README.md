# 4. Összeadás és kivonás

## Tananyag Áttekintés
Szóbeli műveletek végzése a 200-as számkörben: kerek százashoz adás és elvétel, kerek tízesek műveletei, százasátlépéses összeadások és kivonások, valamint a kiegészítés 200-ra.

---

## Műveleti Stratégiák

### 1. Kerek Tízesekkel Végzett Műveletek
- $120 + 50 = 170$ $\quad (12\text{ tízes} + 5\text{ tízes} = 17\text{ tízes})$
- $190 - 40 = 150$ $\quad (19\text{ tízes} - 4\text{ tízes} = 15\text{ tízes})$
- $80 + 70 = 150$ $\quad (8\text{ tízes} + 7\text{ tízes} = 15\text{ tízes})$
- $160 - 90 = 70$ $\quad (16\text{ tízes} - 9\text{ tízes} = 7\text{ tízes})$

### 2. Összeadás és Kivonás Átlépéssel
- $135 + 48$:
  - $135 + 40 = 175$
  - $175 + 8 = 175 + 5 + 3 = \mathbf{183}$
- $172 - 35$:
  - $172 - 30 = 142$
  - $142 - 5 = 142 - 2 - 3 = \mathbf{137}$

### 3. Kiegészítés 200-ra
$$160 + \square = 200 \implies \square = 40$$
$$135 + \square = 200 \implies 135 + 5 = 140 \implies 140 + 60 = 200 \implies \square = 65$$
