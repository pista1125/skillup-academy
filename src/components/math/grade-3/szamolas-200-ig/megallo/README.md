# 6. Megálló (Összefoglalás)

## Tananyag Áttekintés
A 200-as számkör számfogalmának, számszomszédjainak, kerekítéseinek és alapműveleteinek (összeadás, kivonás, szorzás, osztás) összefoglalása és tudáspróbája 3. osztályos szinten.

---

## Összefoglaló Ellenőrző Lista

- [x] **Számfogalom 200-ig:** Háromjegyű számok írása, olvasása, felbontása százasokra, tízesekre, egyesekre.
- [x] **Számegyenes:** Számok pontos bejelölése és leolvasása 0 és 200 között.
- [x] **Számszomszédok és kerekítés:** Egyes, tízes és százas szomszédok, kerekítés a legközelebbi tízesre és százasra.
- [x] **Összeadás és kivonás:** Fejszámolás 200-ig tízesátlépéssel és kerekítésekkel, kiegészítés 200-ra.
- [x] **Szorzás és osztás:** Kerek tízesek szorzása és osztása egyjegyű számokkal.
