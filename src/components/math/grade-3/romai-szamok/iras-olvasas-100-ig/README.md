# 2. Római számok írása és olvasása 100-ig

## Tananyag Áttekintés
Kétjegyű számok felbontása és felírása római számokkal, római számok leolvasása és átváltása arab számokra, számszomszédok keresése és összehasonlítás ($<, >, =$).

---

## Számok Felépítése (Tízesek + Egyesek)

A római számok írásakor a számot először felbontjuk **kerek tízesekre és egyesekre**, majd mindkét részt átírjuk:

$$\text{Arab szám} = \text{Tízesek} + \text{Egyesek} \implies \text{Római alak}$$

---

| **83** | $80 + 3$ | $\text{LXXX}$ | $\text{III}$ | **LXXXIII** |
| **99** | $90 + 9$ | $\text{XC}$ | $\text{IX}$ | **XCIX** |

---

## Számszomszédok és Összehasonlítás

### 1. Számszomszédok Római Számokkal
- $\text{XXIII} < \mathbf{XXIV} < \text{XXV} \quad (23 < 24 < 25)$
- $\text{XLVIII} < \mathbf{XLIX} < \text{L} \quad (48 < 49 < 50)$
- $\text{XCVIII} < \mathbf{XCIX} < \text{C} \quad (98 < 99 < 100)$

### 2. Relációs Jelek
- $\text{XLIV} < \text{LXIV} \quad (44 < 64)$
- $\text{XC} > \text{LXX} \quad (90 > 70)$
- $\text{XXXV} = 35$
