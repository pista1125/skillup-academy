# 5. Megálló (Összefoglalás)

## Tananyag Áttekintés
Az 500-as számkör számfogalmának, számszomszédjainak, kerekítéseinek és alapműveleteinek (összeadás, kivonás, szorzás, osztás) összefoglalása és tudáspróbája 3. osztályos szinten.

---

## Összefoglaló Ellenőrző Lista

- [x] **Számfogalom 500-ig:** Háromjegyű számok írása, olvasása, felbontása százasokra, tízesekre, egyesekre.
- [x] **Számegyenes:** Számok pontos bejelölése és leolvasása 0 és 500 között.
- [x] **Számszomszédok és kerekítés:** Egyes, tízes és százas szomszédok, kerekítés a legközelebbi tízesre és százasra.
- [x] **Összeadás és kivonás:** Fejszámolás 500-ig tízesátlépéssel és kerekítésekkel, kiegészítés 500-ra.
- [x] **Szorzás és osztás:** Kerek tízesek és százasok szorzása és osztása egyjegyű számokkal az 500-as számkörben.
- [x] **Pénzszámolás:** Számolás 500 Ft-ig és fizetési szituációk.
