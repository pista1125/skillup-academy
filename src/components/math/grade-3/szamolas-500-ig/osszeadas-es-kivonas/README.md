# 3. Összeadás és kivonás

## Tananyag Áttekintés
Szóbeli műveletek végzése az 500-as számkörben: kerek százashoz adás és elvétel, kerek tízesek műveletei, százasátlépéses összeadások és kivonások, valamint a kiegészítés 500-ra.

---

## Műveleti Stratégiák

### 1. Kerek Százasok és Tízesek Műveletei
- $200 + 300 = 500$
- $340 + 60 = 400$
- $450 - 200 = 250$
- $380 - 90 = 290$ $\quad (38\text{ tízes} - 9\text{ tízes} = 29\text{ tízes})$

### 2. Összeadás és Kivonás Átlépéssel
- $235 + 48$:
  - $235 + 40 = 275$
  - $275 + 8 = 275 + 5 + 3 = \mathbf{283}$
- $372 - 85$:
  - $372 - 80 = 292$
  - $292 - 5 = 292 - 2 - 3 = \mathbf{287}$

### 3. Kiegészítés 500-ra
$$360 + \square = 500 \implies \square = 140$$
$$335 + \square = 500 \implies 335 + 5 = 340 \implies 340 + 160 = 500 \implies \square = 165$$
