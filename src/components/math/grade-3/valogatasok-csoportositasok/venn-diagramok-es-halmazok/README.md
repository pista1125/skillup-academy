# 2. Venn-diagramok és halmazok

## Tananyag Áttekintés
A halmaz és részhalmaz fogalma, valamint a két- és háromkarikás Venn-diagramok használata: elemek elhelyezése a tartományokban, a közös tulajdonságú elemek (metszet), a csak az egyik halmazba tartozó elemek, és a halmazon kívül rekedt elemek megkülönböztetése.

---

## 1. A Venn-diagram Részei

```
+-----------------------------------+
|  Alaphalmaz (Körökön kívül)      |
|   +-----------+   +-----------+   |
|   | Csak A    | A | Csak B    |   |
|   |           | és|           |   |
|   |           | B |           |   |
|   +-----------+---+-----------+   |
+-----------------------------------+
```

1. **„Csak A” tartomány:** Olyan elemek, amelyek rendelkeznek az $A$ tulajdonsággal, de nem rendelkeznek a $B$ tulajdonsággal.
2. **„A és B” (Közös rész / Metszet):** Olyan elemek, amelyek **mindkét** tulajdonsággal rendelkeznek (pl. páros és $100$-nál nagyobb).
3. **„Csak B” tartomány:** Olyan elemek, amelyek rendelkeznek a $B$ tulajdonsággal, de az $A$-val nem.
4. **Körökön kívül:** Olyan elemek, amelyek egyik feltételnek sem felelnek meg.

---

## 2. Logikai Állítások Vizsgálata
- **Minden** elem piros? (Általános állítás)
- **Van olyan** elem, ami páros? (Létezési állítás)
- **Nincs olyan** szám, ami egyszerre páros és páratlan.
- Állítások értékelése: **Igaz**, **Hamis**, **Lehetséges**.
