# 4. Az összeg változásai

## Tananyag Áttekintés
A tagok és az összeg közötti összefüggések felismerése: hogyan változik az összeg, ha az egyik vagy mindkét tagot változtatjuk (növeljük/csökkentjük), a tagok felcserélhetőségének törvénye ($a + b = b + a$) és a csoportosítás szabálya.

---

## Szabályok és Összefüggések

### 1. Egy Tag Változása
- Ha az egyik összeadandó tagot **növeljük** $x$-szel, az **összeg is nő** $x$-szel:
  $$140 + 80 = 220 \implies (140 + \mathbf{20}) + 80 = 220 + \mathbf{20} = 240$$
- Ha az egyik tagot **csökkentjük** $x$-szel, az **összeg is csökken** $x$-szel:
  $$140 + 80 = 220 \implies 140 + (80 - \mathbf{15}) = 220 - \mathbf{15} = 205$$

### 2. Ellentétes Változások (Az összeg változatlan marad)
- Ha az egyik tagot növeljük $x$-szel, a másik tagot csökkentjük $x$-szel, az **összeg nem változik**:
  $$140 + 80 = (140 + \mathbf{10}) + (80 - \mathbf{10}) = 150 + 70 = \mathbf{220}$$

### 3. Tagok Felcserélhetősége és Csoportosítása
$$235 + 148 = 148 + 235$$
$$(120 + 80) + 145 = 200 + 145 = 345$$
