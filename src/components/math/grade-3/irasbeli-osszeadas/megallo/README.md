# 6. Megálló (Összefoglalás)

## Tananyag Áttekintés
A háromjegyű számok írásbeli összeadásának, becslésének, átlépési szabályainak és szöveges feladatainak összefoglalása és felmérő tudáspróbája 3. osztályos szinten.

---

## Összefoglaló Ellenőrző Lista

- [x] **Helyiértékes lejegyzés:** Háromjegyű számok pontos egymás alá írása helyiérték szerint.
- [x] **Becslés:** Előzetes becslés készítése kerek tízesekre és százasokra.
- [x] **Írásbeli összeadás:** Algoritmus végrehajtása átlépés nélkül, tízesátlépéssel és százasátlépéssel.
- [x] **Maradék továbbvitele:** A tízes és százas maradékok („maradt az 1”) pontos kezelése.
- [x] **Összeg változásai:** A tagok és az összeg közötti szabályok alkalmazása.
- [x] **Szöveges feladatok:** 6 lépéses módszeres feladatmegoldás és válaszadás.
