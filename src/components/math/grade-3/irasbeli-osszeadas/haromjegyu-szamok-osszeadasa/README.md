# 1. Háromjegyű számok összeadása

## Tananyag Áttekintés
A háromjegyű számok összeadásának előkészítése és helyiértékes elrendezése: a számok helyes egymás alá írása (egyesek az egyesek, tízesek a tízesek, százasok a százasok alá), valamint a szóbeli és írásbeli összeadás összehasonlítása.

---

## Helyiértékes Elrendezés

```
  Sz  T  E
  2   3   4
+ 1   5   3
-----------
  3   8   7
```

### Szabályok
1. **Pontos igazítás:** Az azonos helyiértékű számjegyeknek szigorúan egymás alá kell kerülniük.
2. **Kezdés:** Mindig a legkisebb helyiértéktől (az **egyesektől**) indulunk jobbról balra haladva.
3. **Összeadás:**
   - Egyesek: $4 + 3 = 7$
   - Tízesek: $3 + 5 = 8$
   - Százasok: $2 + 1 = 3$
   $$\text{Eredmény: } 387$$
