# 2. Az összeg becslése

## Tananyag Áttekintés
Az írásbeli műveletek elvégzése előtti elengedhetetlen lépés a becslés: az összeadandó tagok kerekítése a legközelebbi kerek tízesre vagy kerek százasra, és a becsült összeg meghatározása a nagyságrendi hibák elkerülése érdekében.

---

## Becslési Stratégiák

### 1. Becslés Kerek Százasokra ($B_{sz}$)
Példa: $238 + 174$
- $238 \approx 200$
- $174 \approx 200$
$$B_{sz}: 200 + 200 = \mathbf{400}$$

### 2. Becslés Kerek Tízesekre ($B_t$)
Példa: $238 + 174$
- $238 \approx 240$
- $174 \approx 170$
$$B_t: 240 + 170 = \mathbf{410}$$

### 3. Pontos Számolás és Összevetés
$$\text{Pontos érték: } 238 + 174 = \mathbf{412}$$
- A pontos érték ($412$) nagyon közel van a becsült értékhez ($410$), így a számolás valószínűleg helyes!
