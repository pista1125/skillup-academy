# VII. Írásbeli összeadás (3. osztály)

## Fejezet Áttekintés
A fejezet célja a háromjegyű számok írásbeli összeadásának elsajátítása és automatizálása a 3. osztályban: a helyiértékes lejegyzés szabályai, az összeg előzetes becslése kerekítéssel, az algoritmus lépései átlépés nélkül és átlépéssel, a tagok és az összeg változásainak összefüggései, valamint összetett szöveges feladatok megoldása.

---

## Altémák

1. **Háromjegyű számok összeadása** (`g3-wr-add-sec-1`)
   - Helyiértékes elrendezés (egyesek az egyesek, tízesek a tízesek, százasok a százasok alá), szóbeli és írásbeli művelet kapcsolata.
2. **Az összeg becslése** (`g3-wr-add-sec-2`)
   - Előzetes becslés kerek tízesekre és kerek százasokra kerekített értékekkel.
3. **Írásbeli összeadás** (`g3-wr-add-sec-3`)
   - Az írásbeli összeadás algoritmusa: összeadás egyesekkel kezdve, tízesátlépés és százasátlépés kezelése („maradt az 1”).
4. **Az összeg változásai** (`g3-wr-add-sec-4`)
   - Az összeg változása a tagok növelése/csökkentése esetén, tagok felcserélhetősége ($a + b = b + a$).
5. **Szöveges feladatok** (`g3-wr-add-sec-5`)
   - Életszerű összetett feladatok: adatok lejegyzése, becslés, írásbeli műveletvégzés, ellenőrzés, válaszadás.
6. **Megálló** (`g3-wr-add-sec-6`)
   - Összefoglaló vegyes feladatsor és fejezeti tudáspróba.
