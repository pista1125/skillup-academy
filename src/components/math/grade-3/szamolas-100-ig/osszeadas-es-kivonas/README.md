# 2. Összeadás és kivonás

## Tananyag Áttekintés
Kétjegyű számok összeadása és kivonása a 100-as számkörben: műveletek tízesátlépés nélkül és tízesátlépéssel, a tagok felcserélhetősége és csoportosíthatósága, valamint a műveletek ellenőrzése.

---

## Műveleti Stratégiák

### 1. Összeadás Tízesátlépés Nélkül
- $34 + 23$:
  - Tízesek összeadása: $30 + 20 = 50$
  - Egyesek összeadása: $4 + 3 = 7$
  $$34 + 23 = 50 + 7 = 57$$

### 2. Összeadás Tízesátlépéssel
- $38 + 27$:
  - $38 + 20 = 58$
  - $58 + 7 = 58 + 2 + 5 = 65$
  $$\text{Vagy: } (30 + 20) + (8 + 7) = 50 + 15 = 65$$

### 3. Kivonás Tízesátlépéssel
- $73 - 28$:
  - $73 - 20 = 53$
  - $53 - 8 = 53 - 3 - 5 = 45$
  $$\text{Ellenőrzés: } 45 + 28 = 73$$

### 4. Tagok Felcserélhetősége
$$a + b = b + a \quad (\text{pl. } 17 + 56 = 56 + 17 = 73)$$
- A kivonásnál a tagok **nem** cserélhetők fel: $73 - 28 \neq 28 - 73$.
