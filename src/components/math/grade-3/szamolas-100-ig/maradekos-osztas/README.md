# 4. Maradékos osztás

## Tananyag Áttekintés
A maradékos osztás értelmezése és gyakorlása 100-ig: mikor keletkezik maradék, a maradékos osztás képlete és lépései, a maradék és az osztó kapcsolata ($M < O$), valamint a maradékos osztás helyességének ellenőrzése szorzással és összeadással.

---

## A Maradékos Osztás Szabályai

### 1. Alapképlet
$$\text{Osztandó} : \text{Osztó} = \text{Hányados, maradék: } M$$
$$\text{Ellenőrzés: } \text{Hányados} \cdot \text{Osztó} + \text{Maradék} = \text{Osztandó}$$

### 2. Aranyszabály
> [!IMPORTANT]
> A maradék **mindig szigorúan kisebb**, mint az osztó!
> $$M < O$$
> Ha $5$-tel osztunk, a lehetséges maradékok csak: $0, 1, 2, 3, 4$ lehetnek!

---

## Példák és Lépések

### Példa: $38 : 5 = \ ?$
1. Keressük meg a legnagyobb olyan számot $38$-ig, ami osztható $5$-tel: ez a **$35$** ($7 \cdot 5 = 35$).
2. A hányados: **$7$**.
3. A maradék: $38 - 35 = \mathbf{3}$.
4. **Lejegyzés:** $38 : 5 = 7\text{, m: } 3$.
5. **Ellenőrzés:** $7 \cdot 5 + 3 = 35 + 3 = 38$.
