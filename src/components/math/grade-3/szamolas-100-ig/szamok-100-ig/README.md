# 1. Számok 100-ig

## Tananyag Áttekintés
A 100-as számkör számfogalmának elmélyítése: helyiérték-táblázat (tízesek és egyesek), a számok írása és olvasása, számszomszédok (egyes és tízes), kerekítés a legközelebbi kerek tízesre, páros és páratlan számok, valamint a számegyenesen való tájékozódás.

---

## Fő Fogalmak és Szabályok

### 1. Helyiértékek 100-ig
- Kétjegyű szám felbontása tízesekre és egyesekre:
  $$47 = 4\text{ tízes} + 7\text{ egyes} = 40 + 7$$
  $$100 = 1\text{ százas} + 0\text{ tízes} + 0\text{ egyes} = 10\text{ tízes}$$

### 2. Számszomszédok
- **Egyes számszomszédok:**
  $$E_k < 58 < E_n \implies 57 < 58 < 59$$
- **Tízes számszomszédok:**
  $$T_k < 58 < T_n \implies 50 < 58 < 60$$

### 3. Kerekítés Kerek Tízesre
- Ha az egyesek helyén **0, 1, 2, 3, 4** áll $\implies$ **lefelé** kerekítünk (pl. $63 \approx 60$).
- Ha az egyesek helyén **5, 6, 7, 8, 9** áll $\implies$ **felfelé** kerekítünk (pl. $65 \approx 70$, $68 \approx 70$).

### 4. Páros és Páratlan Számok
- **Páros számok:** utolsó jegyük $0, 2, 4, 6, 8$ (párokba állíthatók, maradék nélkül oszthatók 2-vel).
- **Páratlan számok:** utolsó jegyük $1, 3, 5, 7, 9$.
