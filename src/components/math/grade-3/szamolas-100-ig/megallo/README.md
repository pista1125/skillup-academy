# 8. Megálló (Összefoglalás)

## Tananyag Áttekintés
A 100-as számkör műveleteinek, törvényszerűségeinek, a szorzótáblának, a maradékos osztásnak és a műveleti sorrendnek átfogó, rendszerező összefoglalása és tudáspróbája 3. osztályos szinten.

---

## Összefoglaló Ellenőrző Lista

- [x] **Számfogalom és helyiértékek:** Biztos eligazodás 0 és 100 között, számszomszédok, kerekítés tízesekre.
- [x] **Összeadás és kivonás:** Fejszámolás tízesátlépéssel és anélkül 100-ig.
- [x] **Szorzás és osztás:** A teljes szorzótábla (1–10) és a bennfoglalás magabiztos készségszintű tudása.
- [x] **Maradékos osztás:** Kiszámítás, a maradék vizsgálata ($M < O$) és ellenőrzés szorzással.
- [x] **Szöveges feladatok:** Szövegértés, nyitott mondat felírása, pontos számolás és válaszadás.
- [x] **Műveletek sorrendje és zárójel:** A zárójel és a műveleti rangsor helyes alkalmazása.
