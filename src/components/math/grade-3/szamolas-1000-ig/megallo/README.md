# 5. Megálló (Összefoglalás)

## Tananyag Áttekintés
A számolás $0$-tól $1000$-ig témakörének átfogó fejezeti összefoglalása és felmérő tudáspróbája 3. osztályos szinten.

---

## Összefoglaló Ellenőrző Lista

- [x] **Számfogalom 1000-ig:** $Ez, Sz, T, E$ helyiértékek, számok írása, olvasása, ábrázolása.
- [x] **Számszomszédok:** Egyes, tízes és százas szomszédok magabiztos felismerése.
- [x] **Kerekítés:** Kerekítés szabályos végrehajtása kerek tízesekre és százasokra.
- [x] **Szóbeli összeadás és kivonás:** Fejszámolás kerek tízesekkel, százasokkal és átlépéssel.
- [x] **Szorzás és osztás:** Kerek tízesek és százasok szorzása és osztása egyjegyű számokkal.
- [x] **Szöveges feladatok:** $1000$-es számkörű szöveges feladatok és nyitott mondatok megoldása.
