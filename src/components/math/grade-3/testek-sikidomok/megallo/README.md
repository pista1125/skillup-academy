# 5. Megálló (Összefoglalás)

## Tananyag Áttekintés
A 3. osztályos testek, síkidomok és szimmetria tananyagának rendszerezése, összefoglalása és felmérő tudáspróbája.

---

## Összefoglaló Ellenőrző Lista

- [x] **Testek felismerése:** Kocka, téglatest, gúla, henger, kúp, gömb azonosítása.
- [x] **Kocka és téglatest elemei:** $6$ lap, $12$ él, $8$ csúcs magabiztos ismerete.
- [x] **Síkidomok és sokszögek:** Háromszögek, négyszögek, sokszögek és a kör tulajdonságai.
- [x] **Négyzet és téglalap:** Szemközti oldalak, derékszögek, kerületszámítás.
- [x] **Tükrözés és szimmetria:** Szimmetriatengely felismerése, szimmetrikus ábra kiegészítése négyzethálón.
