# 5. Megálló (Összefoglalás)

## Tananyag Áttekintés
Az írásbeli összeadás, írásbeli kivonás, műveleti sorrend és összetett szöveges feladatok fejezeti összefoglaló tudáspróbája a teljes $1000$-es számkörben.

---

## Összefoglaló Ellenőrző Lista

- [x] **Írásbeli összeadás:** Több tagú és többszöri átlépéses összeadások $1000$-ig.
- [x] **Írásbeli kivonás:** Kivonás $1000$-ből és kerek százasokból többszöri átváltással.
- [x] **Műveletek ellenőrzése:** Kivonás ellenőrzése összeadással, összeadás ellenőrzése felcseréléssel/kivonással.
- [x] **Műveleti sorrend:** Zárójelek elsőbbségének helyes alkalmazása.
- [x] **Nyitott mondatok:** Hiányzó tag, kisebbítendő, kivonandó kiszámítása.
- [x] **Szöveges feladatok:** Többlépéses összetett feladatok megoldása és válaszadás.
