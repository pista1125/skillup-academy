# 4. Vegyes műveletek és szöveges feladatok

## Tananyag Áttekintés
Összetett, több lépésből álló életszerű szöveges feladatok és nyitott mondatok megoldása az $1000$-es számkörben: adatok rendezése, tervkészítés zárójellel vagy részszámításokkal, becslés, írásbeli műveletek végzése és ellenőrzése.

## 1. Nyitott Mondatok Megoldása
- $450 + \square = 820 \implies \square = 820 - 450 = \mathbf{370}$
- $1000 - \triangle = 365 \implies \triangle = 1000 - 365 = \mathbf{635}$
- $\bigcirc - 280 = 430 \implies \bigcirc = 430 + 280 = \mathbf{710}$

## 2. Minta Összetett Szöveges Feladat
> *Egy iskolai kirándulásra a 3. évfolyam $1000\text{ Ft}$ támogatást kapott diákonként a belépőkre. A múzeumi belépő $380\text{ Ft}$, az állatkerti belépő $450\text{ Ft}$ volt. Mennyi pénz maradt meg egy-egy tanulónak fagylaltra?*

- **Adatok:** Összes pénz: $1000\text{ Ft}$, Múzeum: $380\text{ Ft}$, Állatkert: $450\text{ Ft}$, Maradt: $?\text{ Ft}$
- **Terv:** $1000 - (380 + 450) = \square$
- **1. Lépés (Költések összege):**
  $$380 + 450 = 830\text{ Ft}$$
- **2. Lépés (Maradék kiszámítása):**
  $$1000 - 830 = 170\text{ Ft}$$
- **Ellenőrzés:** $830 + 170 = 1000\text{ Ft}$ $\checkmark$
- **Válasz:** A tanulóknak $170\text{ Ft}$-juk maradt meg fagylaltra.
