# 1. Bevezetés

## Tananyag Áttekintés
A tört fogalmának megértése az egész egyenlő részekre való osztásával: az „egész” felbontása kézzelfogható modelleken (alma, pizza, csokitábla, hajtogatott papírcsík), és a nevezetes törtrészek megismerése.

---

## 1. Az Egész és a Részek

```
  [  EGÉSZ  ]  = 1 egész
  [ FÉL | FÉL ] = 2 egyenlő fél (1/2 + 1/2 = 1)
  [NEGYED|NEGYED|NEGYED|NEGYED] = 4 egyenlő negyed (4/4 = 1)
```

- **Fél ($\frac{1}{2}$):** Az egészet $2$ egyenlő részre osztjuk, és $1$ részt veszünk.
- **Harmad ($\frac{1}{3}$):** Az egészet $3$ egyenlő részre osztjuk, és $1$ részt veszünk.
- **Negyed ($\frac{1}{4}$):** Az egészet $4$ egyenlő részre osztjuk, és $1$ részt veszünk.
- **Nyolcad ($\frac{1}{8}$):** Az egészet $8$ egyenlő részre osztjuk, és $1$ részt veszünk.

$$\text{Fontos szabály: } \text{Csak akkor beszélünk törtről, ha a részek PONTOSAN EGYENLŐEK!}$$
