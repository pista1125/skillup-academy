# 3. Összehasonlítás (Megálló)

## Tananyag Áttekintés
A törtek nagyságrendi összehasonlítása szemléletes modellekkel és relációs jelekkel, valamint a törtek témakörének összefoglaló tudáspróbája.

---

## 1. Törtek Összehasonlítása

### 1. Azonos Nevezőjű Törtek
- Ha a nevezők egyenlők (a részek egyenlő méretűek), **az a tört a nagyobb, amelyiknek a számlálója nagyobb**:
  $$\frac{1}{5} < \frac{2}{5} < \frac{4}{5}$$

### 2. Azonos Számlálójú Törtek (Egységtörtek)
- Minél több felé osztjuk az egészet, annál kisebb egy-egy rész:
  $$\frac{1}{8} < \frac{1}{6} < \frac{1}{4} < \frac{1}{3} < \frac{1}{2}$$

---

## 2. Megálló – Összefoglaló Ellenőrző Lista

- [x] **A tört fogalma:** Egyenlő részekre osztás megértése.
- [x] **Nevezetes törtrészek:** Fél ($\frac{1}{2}$), harmad ($\frac{1}{3}$), negyed ($\frac{1}{4}$) felismerése.
- [x] **Tört felépítése:** Számláló, törtvonal, nevező szerepének ismerete.
- [x] **Törtrész számítása:** Mennyiség törtrészének meghatározása ($24$ fele, negyede, háromnegyede).
- [x] **Összehasonlítás:** Relációs jelek helyes használata törtek között.
