# 3. Összehasonlítás és változások (Megálló)

## Tananyag Áttekintés
Számok összehasonlítása és rendezése a negatív tartományban: relációs jelek helyes használata, a „minél balrább, annál kisebb” elv alkalmazása, egyszerű hőmérséklet- és szintváltozások követése, valamint a fejezet záró tudáspróbája.

---

## 1. Számok Összehasonlítása

### A Számegyenes Alapszabálya
- A számegyenesen **balra lévő szám mindig KISEBB**, mint a tőle jobbra lévő szám.

### Példák
- $-5 < -2$ *(Mert $-5\text{ °C}$ hidegebb, mint $-2\text{ °C}$, és $-5$ balrább van a számegyenesen)*
- $-3 < 0$ *(Minden negatív szám kisebb a nullánál)*
- $-4 < 2$ *(Minden negatív szám kisebb minden pozitív számnál)*
- $0 < 3$

### Növekvő Sorrend
$$-7 < -4 < -1 < 0 < 2 < 5$$

---

## 2. Hőmérséklet Változása
- Reggel $-3\text{ °C}$ volt, délre emelkedett $5\text{ fokot}$:
  $$-3 + 5 = \mathbf{+2\text{ °C}}$$
- Este $+1\text{ °C}$ volt, éjszaka hűlt $4\text{ fokot}$:
  $$1 - 4 = \mathbf{-3\text{ °C}}$$
