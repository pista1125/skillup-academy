# 5. Megálló (Összefoglalás)

## Tananyag Áttekintés
A háromjegyű számok írásbeli kivonásának, becslésének, átváltási eljárásainak és szöveges feladatainak összefoglalása és felmérő tudáspróbája 3. osztályos szinten.

---

## Összefoglaló Ellenőrző Lista

- [x] **Helyiértékes lejegyzés:** Kisebbítendő és kivonandó pontos egymás alá írása.
- [x] **Becslés:** Előzetes becslés készítése kerek tízesekre és százasokra a kivonás előtt.
- [x] **Írásbeli kivonás:** Pótlásos algoritmus elvégzése átváltás nélkül, tízes- és százasátváltással.
- [x] **Ellenőrzés:** Az írásbeli kivonás eredményének ellenőrzése írásbeli összeadással.
- [x] **Különbség változásai:** A tagok és a különbség kapcsolatának megértése.
- [x] **Szöveges feladatok:** Szöveges feladatok megoldása írásbeli kivonással és ellenőrzéssel.
