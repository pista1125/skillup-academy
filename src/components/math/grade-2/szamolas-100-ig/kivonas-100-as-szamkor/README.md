# 3. Kivonás 100-as számkör

## Tananyag Áttekintés
Kivonás 100-as számkörben: kétjegyű számból egyjegyű és kétjegyű számok elvétele, tízesátlépéses stratégiák és az eredmény ellenőrzése összeadással.

---

## Kivonási Stratégiák

### 1. Tízesátlépés nélkül
- Tízesből tízest, egyesből egyest vonunk ki:
  - $78 - 34 = (70 - 30) + (8 - 4) = 40 + 4 = 44$
  - $65 - 3 = 60 + (5 - 3) = 62$

### 2. Tízesátlépéssel
- Visszaszámlálás a kerek tízesen keresztül:
  - $53 - 7 = (53 - 3) - 4 = 50 - 4 = 46$
  - $72 - 35 = (72 - 30) - 5 = 42 - 5 = (42 - 2) - 3 = 40 - 3 = 37$

### 3. Kivonás 100-ból
- $100 - 40 = 60$
- $100 - 37 = (100 - 30) - 7 = 70 - 7 = 63$
