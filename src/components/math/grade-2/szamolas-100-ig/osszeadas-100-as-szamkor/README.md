# 2. Összeadás 100-as számkör

## Tananyag Áttekintés
Összeadás 100-as számkörben: kétjegyű számokhoz egyjegyű és kétjegyű számok hozzáadása, tízesátlépés nélküli és tízesátlépéses műveletek, összeg becslése kerekítéssel.

---

## Összeadási Stratégiák

### 1. Tízesátlépés nélkül
- Tízeshez tízest, egyeshez egyest adunk:
  - $43 + 25 = (40 + 20) + (3 + 5) = 60 + 8 = 68$
  - $52 + 6 = 50 + (2 + 6) = 58$

### 2. Tízesátlépéssel
- Lépésenkénti számolás vagy pótlás a következő kerek tízesre:
  - $47 + 8 = (47 + 3) + 5 = 50 + 5 = 55$
  - $36 + 28 = (36 + 20) + 8 = 56 + 8 = (56 + 4) + 4 = 64$
