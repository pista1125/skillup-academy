# 7. Megálló

## Tananyag Áttekintés
Az I. témakör (Számolás 0-tól 20-ig) átfogó ismétlése, rendszerezése és tudáspróbája: vegyes összeadási és kivonási feladatok 20-ig (tízesátlépéssel is), nyitott mondatok, valamint életszerű szöveges feladatok megoldása.

---

## Összefoglaló Ellenőrző Lista
- [ ] Biztos számfogalom és számszomszédok 0–20-ig
- [ ] Páros és páratlan számok megkülönböztetése
- [ ] Összeadás és kivonás a 10-es számkörben
- [ ] Összeadás és kivonás a 20-as számkörben tízesátlépéssel
- [ ] Szöveges feladatok levezetése (adatok, nyitott mondat, válasz)
- [ ] Műveletek ellenőrzése
