# 3. Kivonás 10-es számkör

## Tananyag Áttekintés
Kivonás készségszintű gyakorlása a 10-es számkörben: a kivonás értelmezése (elvétel, különbség), a kivonás és összeadás kapcsolata (ellenőrzés), valamint a hiányos műveletek (pótlás).

---

## Fő Fogalmak és Szabályok

### 1. A kivonás fogalma
- **Kisebbítendő** $-$ **Kivonandó** $=$ **Különbség**
  $$8 - 3 = 5$$

### 2. A kivonás és összeadás kapcsolata (Ellenőrzés)
- A kivonás az összeadás megfordítása:
  $$8 - 3 = 5 \iff 5 + 3 = 8$$
- Minden kivonási feladat ellenőrizhető összeadással!

### 3. Nullával végzett kivonás
- Ha egy számból nullát vonunk ki, a szám nem változik: $a - 0 = a$ ($6 - 0 = 6$).
- Ha egy számból önmagát vonjuk ki, az eredmény nulla: $a - a = 0$ ($6 - 6 = 0$).
