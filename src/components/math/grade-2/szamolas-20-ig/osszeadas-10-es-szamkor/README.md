# 2. Összeadás 10-es számkör

## Tananyag Áttekintés
Az alapvető összeadási műveletek biztos készségszintű elsajátítása a 10-es számkörben: a számok bontása, a 10-re kiegészítés (pótlás), valamint a tagok felcserélhetőségének tulajdonsága.

---

## Fő Fogalmak és Szabályok

### 1. A 10 bontása
A 10-es szám bontáspárjainak biztos ismerete elengedhetetlen a későbbi tízesátlépéshez:
- $0 + 10 = 10$
- $1 + 9 = 10$
- $2 + 8 = 10$
- $3 + 7 = 10$
- $4 + 6 = 10$
- $5 + 5 = 10$

### 2. A tagok felcserélhetősége
- Az összeadásnál a tagok sorrendje felcserélhető, az összeg nem változik:
  $$a + b = b + a \quad (\text{pl. } 3 + 6 = 6 + 3 = 9)$$

### 3. Összeadás 0-val
- Bármely számhoz nullát adva a szám értéke változatlan marad:
  $$a + 0 = a \quad (\text{pl. } 7 + 0 = 7)$$
