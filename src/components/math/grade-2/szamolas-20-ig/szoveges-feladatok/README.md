# 6. Szöveges feladatok

## Tananyag Áttekintés
Szöveges feladatok értelmezése és megoldása a 20-as számkörben. A feladatok megoldásának lépései: szövegértés, adatok kigyűjtése, rajzos modell vagy szakaszos ábrázolás, nyitott mondat felírása, számolás, ellenőrzés és szöveges válaszadás.

---

## A Megoldás Lépései

### 1. Olvasás és megértés
- Olvasd el figyelmesen a feladatot legalább kétszer!
- Keresd meg a kulcsszavakat: *több, kevesebb, összesen, maradt, kapott, elveszített*.

### 2. Adatok kigyűjtése és terv
- **Adatok:**
  - Péternek van: $12\text{ almája}$
  - Annának van: $5$-tel több almája
- **Kérdés:** Hány almája van Annának?

### 3. Nyitott mondat és számolás
$$\square = 12 + 5$$
$$\square = 17$$

### 4. Ellenőrzés és Válasz
- **Ellenőrzés:** $17 - 12 = 5$ (valóban 5-tel több).
- **Válasz:** Annának $17$ almája van.
