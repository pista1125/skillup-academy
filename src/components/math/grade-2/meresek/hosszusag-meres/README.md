# 1. Hosszúság mérés

## Tananyag Áttekintés
A hosszúság mérésének alapjai, a mértékegységek rendszere és a mérőeszközök használata 2. osztályban.

---

## Fő Mértékegységek és Átváltások

| Mértékegység | Rövidítés | Kapcsolat a többivel |
| :--- | :---: | :--- |
| **Méter** | $\text{m}$ | Alapmértékegység ($1\text{ m} = 10\text{ dm} = 100\text{ cm}$) |
| **Deciméter** | $\text{dm}$ | $1\text{ dm} = 10\text{ cm}$ |
| **Centiméter** | $\text{cm}$ | $10\text{ cm} = 1\text{ dm}$ |

---

## Fő Szabályok és Gyakorlatok
- **Mérőeszközök:** vonalzó, mérőszalag, colstok.
- **Szakaszok mérése:** a vonalzó **0** jelölését illesztjük a szakasz kezdőpontjához!
- **Összehasonlítás:** $1\text{ m} > 50\text{ cm}$, $2\text{ dm } 4\text{ cm} = 24\text{ cm}$.
