# 2. Tömeg mérés

## Tananyag Áttekintés
A tömeg mérése, mérlegek használata és a mértékegységek gyakorlása 2. osztályban.

---

## Fő Mértékegységek és Átváltások

| Mértékegység | Rövidítés | Kapcsolat a többivel |
| :--- | :---: | :--- |
| **Kilogramm** | $\text{kg}$ | $1\text{ kg} = 100\text{ dkg}$ |
| **Dekagramm** | $\text{dkg}$ | $100\text{ dkg} = 1\text{ kg}$ |

---

## Fő Szabályok és Gyakorlatok
- **Mérőeszközök:** kétkarú mérleg, digitális konyhai mérleg, személymérleg.
- **Egyensúly a mérlegen:** a kétkarú mérleg nyelve középen áll $\implies$ a két serpenyőben lévő tömeg egyenlő.
- **Fél kilogramm:** $1\text{ kg} = 100\text{ dkg} \implies \text{fél kg} = 50\text{ dkg}$.
