# 3. Űrtartalom mérés

## Tananyag Áttekintés
Az űrtartalom mérése, folyadékok térfogata, mérőedények és a mértékegységek rendszere 2. osztályban.

---

## Fő Mértékegységek és Átváltások

| Mértékegység | Rövidítés | Kapcsolat a többivel |
| :--- | :---: | :--- |
| **Liter** | $\text{l}$ | Alapmértékegység ($1\text{ l} = 10\text{ dl} = 100\text{ cl}$) |
| **Deciliter** | $\text{dl}$ | $1\text{ dl} = 10\text{ cl}$, $10\text{ dl} = 1\text{ l}$ |
| **Centiliter** | $\text{cl}$ | $10\text{ cl} = 1\text{ dl}$ |

---

## Fő Szabályok és Gyakorlatok
- **Mérőeszközök:** mérőkancsó, mérőhenger, kalibrált cumisüveg vagy mérőpohár.
- **Fél liter:** $1\text{ l} = 10\text{ dl} \implies \text{fél liter} = 5\text{ dl}$.
- **Áttöltési feladatok:** Ha egy $2\text{ l}$-es kancsóból kitöltünk $4\text{ dl}$-t, akkor $20\text{ dl} - 4\text{ dl} = 16\text{ dl} = 1\text{ l } 6\text{ dl}$ marad.
