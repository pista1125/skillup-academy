# 5. Szöveges feladatok

## Tananyag Áttekintés
Összetett, életszerű szöveges feladatok megoldása a kibővített 50-es számkörben: vásárlás, mérések, összehasonlítások és több lépésből álló számolások.

---

## A Szöveges Feladat Megoldásának Lépései
1. **Értelmező olvasás:** Mit tudunk? (Adatok) Mit keresünk? (Kérdés)
2. **Tervkészítés és modell:** Rajz, szakaszos ábra vagy táblázat készítése.
3. **Nyitott mondat felírása:** Matematikai egyenlet vagy kifejezés megfogalmazása.
4. **Számolás:** A művelet elvégzése.
5. **Ellenőrzés:** Visszaillesztés az eredeti szövegbe.
6. **Válaszadás:** Teljes mondatos, szöveges válasz.
