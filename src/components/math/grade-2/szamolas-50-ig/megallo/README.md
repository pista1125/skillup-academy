# 6. Megálló

## Tananyag Áttekintés
A II. témakör (Számkörbővítés és számolás 50-ig) átfogó rendszerezése, ismétlése és játékos tudáspróbája.

---

## Összefoglaló Ellenőrző Lista
- [ ] Kétjegyű számok helyiértékes bontása 50-ig ($T$ és $E$)
- [ ] Egyes és tízes számszomszédok magabiztos megállapítása
- [ ] Összeadás és kivonás kerek tízesekkel ($20 + 30$, $45 - 20$)
- [ ] Műveletek 50-es számkörben tízesátlépéssel
- [ ] Szöveges feladatok értelmezése és pontos megoldása
