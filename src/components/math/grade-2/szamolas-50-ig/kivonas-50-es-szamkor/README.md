# 3. Kivonás 50-es számkör

## Tananyag Áttekintés
Kivonás 50-es számkörben: kétjegyű számból egyjegyű és kétjegyű számok elvétele, tízesátlépés nélküli és tízesátlépéses műveletek, ellenőrzés összeadással.

---

## Kivonási Stratégiák

### 1. Tízesátlépés nélkül
- A kisebbítendő egyeséből elvehető a kivonandó:
  - $38 - 5 = 30 + (8 - 5) = 33$
  - $47 - 14 = (40 - 10) + (7 - 4) = 30 + 3 = 33$

### 2. Tízesátlépéssel (Visszaszámlálás és kerek tízesre bontás)
- Amikor a kisebbítendő egyeséből nem vehető el közvetlenül a kivonandó:
  - $42 - 7 = (42 - 2) - 5 = 40 - 5 = 35$
  - $35 - 8 = (35 - 5) - 3 = 30 - 3 = 27$

### 3. Ellenőrzés
- Különbség + Kivonandó = Kisebbítendő ($35 + 7 = 42$).
