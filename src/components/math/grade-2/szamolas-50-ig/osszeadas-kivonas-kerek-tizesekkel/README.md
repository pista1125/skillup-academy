# 4. Összeadás, kivonás kerek tízesekkel

## Tananyag Áttekintés
Kerek tízesekkel ($10, 20, 30, 40, 50$) végzett összeadási és kivonási műveletek megértése és begyakorlása 50-ig.

---

## Fő Művelettípusok

### 1. Kerek tízesek egymás közötti műveletei
- A művelet az 1. osztályos egyesek összeadására/kivonására vezethető vissza:
  - $2\text{ tízes} + 3\text{ tízes} = 5\text{ tízes} \implies 20 + 30 = 50$
  - $5\text{ tízes} - 2\text{ tízes} = 3\text{ tízes} \implies 50 - 20 = 30$

### 2. Kétjegyű számhoz kerek tízes hozzáadása / elvétele
- Csak a tízesek helyiértéke változik, az egyesek változatlanok maradnak:
  - $24 + 20 = (20 + 20) + 4 = 44$
  - $48 - 30 = (40 - 30) + 8 = 18$
