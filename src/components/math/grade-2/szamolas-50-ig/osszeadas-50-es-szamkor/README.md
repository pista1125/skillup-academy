# 2. Összeadás 50-es számkör

## Tananyag Áttekintés
Összeadás 50-es számkörben: kétjegyű számhoz egyjegyű és kétjegyű számok hozzáadása, tízesátlépés nélküli és tízesátlépéses stratégiák.

---

## Összeadási Stratégiák

### 1. Tízesátlépés nélkül
- Az egyesek összege nem éri el a 10-et:
  - $32 + 5 = 30 + (2 + 5) = 37$
  - $24 + 13 = (20 + 10) + (4 + 3) = 30 + 7 = 37$

### 2. Tízesátlépéssel (Kerek tízesre pótlás)
- Az egyesek összege eléri vagy meghaladja a 10-et:
  - $28 + 6 = (28 + 2) + 4 = 30 + 4 = 34$
  - $37 + 8 = (37 + 3) + 5 = 40 + 5 = 45$
