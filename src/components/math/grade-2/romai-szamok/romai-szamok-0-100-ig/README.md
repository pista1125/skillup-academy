# 4. Római számok 0-100-ig

## Tananyag Áttekintés
A római számírás teljes kiterjesztése a 100-as számkörre. A $C = 100$ és az $XC = 90$ jelek elsajátítása, összetett római számok átváltása, római számok a mindennapi életben, valamint játékos logikai feladványok (pl. gyufaszálas rejtvények).

---

## Kerek Tízesek 50-től 100-ig

| Arab szám | Római szám | Magyarázat |
| :---: | :---: | :--- |
| **50** | **L** | Ötven |
| **60** | **LX** | $50 + 10$ |
| **70** | **LXX** | $50 + 10 + 10$ |
| **80** | **LXXX** | $50 + 10 + 10 + 10$ |
| **90** | **XC** | $100 - 10$ *(kivonás: C előtt X)* |
| **100** | **C** | Száz (*Centum*) |

---

## Példák Összetett Számokra
- **68** $= 60 + 8 = \mathbf{LX} + \mathbf{VIII} = \mathbf{LXVIII}$
- **74** $= 70 + 4 = \mathbf{LXX} + \mathbf{IV} = \mathbf{LXXIV}$
- **89** $= 80 + 9 = \mathbf{LXXX} + \mathbf{IX} = \mathbf{LXXXIX}$
- **95** $= 90 + 5 = \mathbf{XC} + \mathbf{V} = \mathbf{XCV}$
- **99** $= 90 + 9 = \mathbf{XC} + \mathbf{IX} = \mathbf{XCIX}$ *(Vigyázat: nem IC!)*

---

## Római Számok a Mindennapokban
- **Órák számlapja:** $I, II, III, \dots, XII$
- **Könyvek fejezetei:** I. Fejezet, II. Kötet
- **Események, olimpiák, uralkodók:** pl. IV. Béla, XXXIII. Nyári Olimpiai Játékok
