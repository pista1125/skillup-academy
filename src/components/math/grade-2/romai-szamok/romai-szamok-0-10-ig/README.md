# 2. Római számok 0-10-ig

## Tananyag Áttekintés
A számok írása, olvasása és átváltása 1-től 10-ig római számokkal. A legfontosabb sarokkövek ($I, V, X$) és a speciális kivonási esetek ($IV, IX$) magabiztos készségszintű elsajátítása.

---

## A Számok 1-től 10-ig

| Arab szám | Római szám | Felbontás / Magyarázat |
| :---: | :---: | :--- |
| **1** | **I** | Alapjel |
| **2** | **II** | $1 + 1$ |
| **3** | **III** | $1 + 1 + 1$ |
| **4** | **IV** | $5 - 1$ *(balra írt I kivonás)* |
| **5** | **V** | Alapjel |
| **6** | **VI** | $5 + 1$ *(jobbra írt I összeadás)* |
| **7** | **VII** | $5 + 1 + 1$ |
| **8** | **VIII** | $5 + 1 + 1 + 1$ |
| **9** | **IX** | $10 - 1$ *(balra írt I kivonás)* |
| **10** | **X** | Alapjel |

---

## Gyakorlási Tippek
- **Számszomszédok római számokkal:**
  $$III < IV < V \quad (3 < 4 < 5)$$
  $$VIII < IX < X \quad (8 < 9 < 10)$$
- **Összehasonlítás:** $VII > V$ ($7 > 5$), $IV < VI$ ($4 < 6$).
