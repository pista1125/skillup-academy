# 3. Római számok 0-50-ig

## Tananyag Áttekintés
Számkörbővítés 50-ig római számokkal. A kerek tízesek felépítése, az $L = 50$ és az $XL = 40$ értelmezése, valamint kétjegyű számok leírása a tízesek és egyesek összekapcsolásával.

---

## Kerek Tízesek 50-ig

| Arab szám | Római szám | Magyarázat |
| :---: | :---: | :--- |
| **10** | **X** | 1 darab tízes |
| **20** | **XX** | $10 + 10$ |
| **30** | **XXX** | $10 + 10 + 10$ |
| **40** | **XL** | $50 - 10$ *(kivonás: L előtt X)* |
| **50** | **L** | Alapjel (ötven) |

---

## Kétjegyű Számok Felépítése
A számot felbontjuk **tízesekre** és **egyesekre**, majd egymás után írjuk őket:
- **14** $= 10 + 4 = \mathbf{X} + \mathbf{IV} = \mathbf{XIV}$
- **27** $= 20 + 7 = \mathbf{XX} + \mathbf{VII} = \mathbf{XXVII}$
- **39** $= 30 + 9 = \mathbf{XXX} + \mathbf{IX} = \mathbf{XXXIX}$
- **45** $= 40 + 5 = \mathbf{XL} + \mathbf{V} = \mathbf{XLV}$
- **49** $= 40 + 9 = \mathbf{XL} + \mathbf{IX} = \mathbf{XLIX}$
