# 5. Színesrúd-készlet

## Tananyag Áttekintés
A Cuisenaire-féle színes rudak megismerése, a hosszúság és a számok kapcsolatának felfedezése 1. osztályban.

---

## A Színes Rudak Rendszere

| Érték / Hosszúság | Szín |
| :---: | :--- |
| **1** | Fehér |
| **2** | Rózsaszín |
| **3** | Világoskék |
| **4** | Piros |
| **5** | Sárga |
| **6** | Sötétzöld |
| **7** | Fekete |
| **8** | Barna |
| **9** | Kék (sötétkék) |
| **10** | Narancssárga |

---

## Fő Játékok és Módszerek
- **Lépcsőépítés:** a rudak növekvő és csökkenő sorrendbe állítása.
- **Szőnyegezés:** azonos hosszúságú vonatok kirakása több rövidebb rúdból (pl. a sárga rúd = piros + fehér vagy világoskék + rózsaszín).
- **Hosszúság összehasonlítás:** melyik rúd hosszabb, melyik rövidebb?
