# 11. Nyitott mondatok

## Tananyag Áttekintés
A nyitott mondatok (hiányos kifejezések, algebrát előkészítő gondolkodásmód) bevezetése: a négyzet ($\square$), háromszög ($\Delta$) vagy más forma helyére illő számok megkeresése.

---

## Fő Típusok és Példák

### 1. Hiányos összeadás és kivonás
- $\square + 3 = 8 \implies \square = 5$
- $8 - \Delta = 2 \implies \Delta = 6$
- $4 + \square = 7 \implies \square = 3$

### 2. Nyitott egyenlőtlenségek
- $\square < 5 \implies \square \in \{0, 1, 2, 3, 4\}$
- $6 < \Delta \le 8 \implies \Delta \in \{7, 8\}$
