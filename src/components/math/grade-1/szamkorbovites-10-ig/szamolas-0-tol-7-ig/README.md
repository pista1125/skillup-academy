# 6. Számolás 0-tól 7-ig

## Tananyag Áttekintés
Összeadás és kivonás a 7-es számkörben, a 7 bontásainak alkalmazása a számolásban.

---

## Fő Típusfeladatok
- Összeadás 7-ig: $5 + 2 = 7, 3 + 4 = 7, 6 + 1 = 7$.
- Kivonás 7-ből: $7 - 2 = 5, 7 - 4 = 3, 7 - 1 = 6$.
- Hiányos tag keresése: $3 + \square = 7 \implies \square = 4$.
