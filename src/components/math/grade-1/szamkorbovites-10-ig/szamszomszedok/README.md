# 7. Számszomszédok

## Tananyag Áttekintés
A számszomszédok fogalma a számegyenesen: a közvetlenül kisebb (eggyel kisebb) és a közvetlenül nagyobb (eggyel nagyobb) számszomszédok megállapítása.

---

## Fő Ismeretek
- **Kisebb számszomszéd:** a számegyenesen közvetlenül balra lévő szám ($n - 1$).
- **Nagyobb számszomszéd:** a számegyenesen közvetlenül jobbra lévő szám ($n + 1$).
- **Példák:**
  - Az $5$ kisebb szomszédja a $4$, nagyobb szomszédja a $6$ ($4 < 5 < 6$).
  - A $7$ kisebb szomszédja a $6$, nagyobb szomszédja a $8$ ($6 < 7 < 8$).
