# 2. Számolás 0-tól 6-ig

## Tananyag Áttekintés
Összeadás és kivonás a 6-os számkörben, a tagok felcserélhetősége és az ellenőrzés gyakorlása.

---

## Fő Típusfeladatok
- Összeadás 6-ig: $4 + 2 = 6, 3 + 3 = 6, 5 + 1 = 6$.
- Kivonás 6-ból: $6 - 2 = 4, 6 - 3 = 3, 6 - 5 = 1$.
- Pótlással való számolás: $4 + \square = 6 \implies \square = 2$.
- Számegyenesen való lépegetés 0-tól 6-ig előre és hátra.
