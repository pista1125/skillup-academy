# 10. Számolás 0-tól 8-ig

## Tananyag Áttekintés
Összeadás és kivonás a 8-as számkörben, a 8 bontásainak gyakorlása fejben és képi eszközökkel.

---

## Fő Típusfeladatok
- Összeadás 8-ig: $4 + 4 = 8, 5 + 3 = 8, 6 + 2 = 8, 7 + 1 = 8$.
- Kivonás 8-ból: $8 - 4 = 4, 8 - 3 = 5, 8 - 2 = 6, 8 - 7 = 1$.
- Számegyenesen való lépkedés és ellenőrzés 8-ig.
