# 7. Összeadás 0-tól 5-ig

## Tananyag Áttekintés
Az összeadás műveletének bevezetése 5-ös számkörben: a halmazok egyesítése, a műveleti jelek ($+$ és $=$) értelmezése, a tagok felcserélhetősége és a 0 hozzáadása.

---

## Fő Fogalmak és Módszertan
- **Egyesítés:** „Volt 2 piros almám, kaptam még 1 sárga almát. Hány almám lett összesen?” $\implies 2 + 1 = 3$.
- **A 0 szerepe az összeadásban:** ha semmit sem adunk hozzá, az összeg nem változik ($3 + 0 = 3$).
- **Tagok felcserélhetősége:** $1 + 4 = 4 + 1 = 5$.
- **Képi segítség:** piros és kék korongok összetolása.
