# 4. A három

## Tananyag Áttekintés
A **3**-as szám fogalma: mennyiség, számkép (háromszög elrendezés), a számjegy írása és a 3 bontásai.

---

## Fő Ismeretek
- **Mennyiség:** 3 korong, 3 ujj, 3 pötty a dobókockán (átlósan).
- **Példák a világban:** közlekedési lámpa 3 színe (piros, sárga, zöld), 3 kismalac, háromszög 3 csúcsa és 3 oldala.
- **A 3 bontásai:**
  - $3 = 1 + 2$
  - $3 = 2 + 1$
  - $3 = 1 + 1 + 1$
- **Színes rúd:** világoskék rúd ($= 3$ fehér rúd).
