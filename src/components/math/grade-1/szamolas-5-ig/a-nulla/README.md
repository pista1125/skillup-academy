# 3. A nulla

## Tananyag Áttekintés
A **0** (nulla) fogalma: az üres halmaz, a „semmi” matematikai megjelenése, a 0 helye a számegyenesen és az 1-nél eggyel kisebb mennyiség.

---

## Fő Ismeretek
- **Mennyiség:** üres doboz, fa, amiről lehullott minden levél, 0 korong a keretben.
- **A számegyenesen:** az 1-től balra helyezkedik el, a számegyenes kezdőpontja.
- **Számjegy írása:** felülről kezdett, balra kanyarodó zárt ovális.
- **Kapcsolata a többivel:** $0 < 1 < 2$.
