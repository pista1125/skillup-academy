# 9. Megálló

## Tananyag Áttekintés
A II. témakör (Számolás 0-tól 5-ig) átfogó rendszerezése, összefoglalása és játékos tudáspróbája: számképek, számok bontása, összeadás és kivonás 5-ig.

---

## Összefoglaló Ellenőrző Lista
- [ ] Számjegyek szabályos írása és felismerése 0-tól 5-ig
- [ ] Mennyiségek azonnali felismerése (ujjak, korongok, dobókocka)
- [ ] Számok bontása 2-től 5-ig ($2, 3, 4, 5$)
- [ ] Összeadás 5-ig ($+$ jel, 0 hozzáadása)
- [ ] Kivonás 5-ig ($-$ jel, 0 elvétele)
- [ ] Egyszerű képes szöveges feladatok megoldása
