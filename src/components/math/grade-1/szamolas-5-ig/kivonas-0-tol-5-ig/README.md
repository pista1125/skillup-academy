# 8. Kivonás 0-tól 5-ig

## Tananyag Áttekintés
A kivonás műveletének bevezetése 5-ös számkörben: a halmazból való elvétel, a mínusz jel ($-$) értelmezése, a különbség kiszámítása, a 0 kivonása és az ellenőrzés összeadással.

---

## Fő Fogalmak és Módszertan
- **Elvétel:** „Volt 4 léggömbünk, 1 kipukkadt. Hány léggömb maradt?” $\implies 4 - 1 = 3$.
- **A 0 szerepe a kivonásban:** ha semmit sem veszünk el, a mennyiség megmarad ($5 - 0 = 5$).
- **Önmagából való kivonás:** ha mindent elveszünk, nulla marad ($4 - 4 = 0$).
- **Kapcsolat az összeadással:** $4 - 1 = 3 \iff 3 + 1 = 4$.
