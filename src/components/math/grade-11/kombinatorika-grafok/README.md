# II. Kombinatorika, gráfok (11. osztály)
- Ismétlés nélküli és ismétléses permutációk (sorba rendezések)
- Ismétlés nélküli és ismétléses variációk (kiválasztás és sorrend)
- Ismétlés nélküli és ismétléses kombinációk (kiválasztás sorrend nélkül, binomiális együtthatók)
- Pascal-háromszög és a binomiális tétel: (a+b)ⁿ kifejtése
- Gráfelméleti alapok: csúcsok, élek, fokszámok, kézfogási lemma (fokszámok összege páros)
- Gráf típusok: egyszerű, teljes, összefüggő gráfok, részgráfok, fák (fa definíciója és tulajdonságai)
- Utak, körök és Euler-vonal bejárási problémák
