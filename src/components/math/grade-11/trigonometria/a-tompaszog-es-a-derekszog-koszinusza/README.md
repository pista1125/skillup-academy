# 11. A tompaszög és a derékszög koszinusza (10. lecke)

## Tananyag Áttekintés
A koszinuszfüggvény kiterjesztése derékszögre és tompaszögekre ($90^\circ \le \alpha \le 180^\circ$): az egységkör első koordinátája ($x$-tengely), negatív előjel tompaszögekre és mellékszögek koszinusza.

---

## Fő Definíciók és Tulajdonságok

- **A koszinusz az egységkörben:**
  - Az $\alpha$ forgásszögű egységvektor végpontjának első koordinátája ($x$-koordinátája) a $\cos \alpha$.

- **Nevezetes értékek:**
  - $\cos 0^\circ = 1$
  - $\cos 90^\circ = 0$
  - $\cos 180^\circ = -1$

- **Tompaszögek koszinusza:**
  - A II. síknegyedben ($90^\circ < \alpha < 180^\circ$) az $x$-koordináta **negatív**, így a tompaszögek koszinusza negatív valós szám!
  - **Mellékszögek összefüggése:**
    $$\cos(180^\circ - \alpha) = -\cos \alpha$$
  - Példák:
    - $\cos 120^\circ = -\cos 60^\circ = -\frac{1}{2}$
    - $\cos 135^\circ = -\cos 45^\circ = -\frac{\sqrt{2}}{2}$
    - $\cos 150^\circ = -\cos 30^\circ = -\frac{\sqrt{3}}{2}$
