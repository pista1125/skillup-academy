# 8. A tompaszög és a derékszög szinusza (7. lecke)

## Tananyag Áttekintés
A szinuszfüggvény kiterjesztése derékszögre és tompaszögekre ($90^\circ \le \alpha \le 180^\circ$): forgásszögek, az egységkör geometriai modellje és a kiegészítő szögek szinuszának azonossága.

---

## Fő Definíciók és Összefüggések

- **A szinusz értelmezése az egységkörben:**
  - Az origó középpontú, 1 sugarú körben az $\alpha$ irányszögű egységvektor végpontjának második koordinátája ($y$-koordinátája) maga a $\sin \alpha$.

- **Nevezetes értékek:**
  - $\sin 0^\circ = 0$
  - $\sin 90^\circ = 1$
  - $\sin 180^\circ = 0$

- **Kiegészítő szögek azonossága ($\alpha + \beta = 180^\circ$):**
  - Bármely tompaszög szinusza egyenlő a $180^\circ$-ra való kiegészítő szögének (a mellékszögének) szinuszával:
    $$\sin(180^\circ - \alpha) = \sin \alpha$$
  - Példák: $\sin 150^\circ = \sin 30^\circ = \frac{1}{2}$, $\sin 120^\circ = \sin 60^\circ = \frac{\sqrt{3}}{2}$, $\sin 135^\circ = \sin 45^\circ = \frac{\sqrt{2}}{2}$.
  - Következmény: Háromszögben minden szög szinusza pozitív ($0 < \sin \alpha \le 1$).
