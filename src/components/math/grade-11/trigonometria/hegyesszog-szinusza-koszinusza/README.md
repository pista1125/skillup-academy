# 3. Hegyesszög szinusza, koszinusza (3. lecke)

## Tananyag Áttekintés
A hegyesszögek szinuszának és koszinuszának definíciója derékszögű háromszögben: a befogók és az átfogó aránya, valamint a szögfüggvények értékkészlete.

---

## Fő Definíciók és Tulajdonságok

- **A szinusz definíciója ($\sin \alpha$):**
  - A szöggel szemközti befogó és az átfogó hányadosa:
    $$\sin \alpha = \frac{\text{szemközti befogó}}{\text{átfogó}} = \frac{a}{c}$$

- **A koszinusz definíciója ($\cos \alpha$):**
  - A szög melletti (szomszédos) befogó és az átfogó hányadosa:
    $$\cos \alpha = \frac{\text{szomszédos befogó}}{\text{átfogó}} = \frac{b}{c}$$

- **Értékkészlet hegyesszögekre ($0^\circ < \alpha < 90^\circ$):**
  - Mivel a befogó mindig rövidebb az átfogónál ($a < c$ és $b < c$), ezért:
    $$0 < \sin \alpha < 1 \quad \text{és} \quad 0 < \cos \alpha < 1$$
