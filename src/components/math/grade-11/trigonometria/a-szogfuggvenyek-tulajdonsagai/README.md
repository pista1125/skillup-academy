# 4. A szögfüggvények tulajdonságai (4. lecke)

## Tananyag Áttekintés
Alapvető azonosságok azonos és pótszögek szögfüggvényei között, valamint a nevezetes szögek ($30^\circ, 45^\circ, 60^\circ$) pontos értékei.

---

## Fő Azonosságok és Nevezetes Értékek

- **Pótszögek összefüggése ($\alpha + \beta = 90^\circ$):**
  $$\sin(90^\circ - \alpha) = \cos \alpha \quad \text{és} \quad \cos(90^\circ - \alpha) = \sin \alpha$$
  $$\mathrm{tg}(90^\circ - \alpha) = \frac{1}{\mathrm{tg}\,\alpha}$$

- **A trigonometrikus alapegyenlet (Pitagorasz-tételből):**
  $$\sin^2 \alpha + \cos^2 \alpha = 1$$
  $$\mathrm{tg}\,\alpha = \frac{\sin \alpha}{\cos \alpha}$$

- **Nevezetes szögek táblázata:**
  | Szög ($\alpha$) | $30^\circ$ | $45^\circ$ | $60^\circ$ |
  |---|:---:|:---:|:---:|
  | $\sin \alpha$ | $\frac{1}{2}$ | $\frac{\sqrt{2}}{2}$ | $\frac{\sqrt{3}}{2}$ |
  | $\cos \alpha$ | $\frac{\sqrt{3}}{2}$ | $\frac{\sqrt{2}}{2}$ | $\frac{1}{2}$ |
  | $\mathrm{tg}\,\alpha$ | $\frac{\sqrt{3}}{3}$ | $1$ | $\sqrt{3}$ |
