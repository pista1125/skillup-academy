# 5. Hosszúságok és szögek kiszámítása (5. lecke)

## Tananyag Áttekintés
Derékszögű háromszögek teljes körű megoldása: a háromszög hiányzó oldalainak és hegyesszögeinek meghatározása két megadott alapadatból.

---

## Fő Esetek és Megoldási Módszerek

- **1. eset: Egy oldal és egy hegyesszög ismert:**
  - Másik hegyesszög: $\beta = 90^\circ - \alpha$.
  - Oldalak kiszámítása megfelelő szögfüggvénnyel ($\sin, \cos$ vagy $\mathrm{tg}$).
  - Ellenőrzés: Pitagorasz-tétellel ($a^2 + b^2 = c^2$).

- **2. eset: Két oldal ismert (két befogó vagy egy befogó és az átfogó):**
  - Harmadik oldal: Pitagorasz-tétellel.
  - Hegyesszögek: $\sin \alpha = a/c$, $\cos \alpha = b/c$ vagy $\mathrm{tg}\,\alpha = a/b$ segítségével.

- **Alkalmazások síkidomokban:**
  - Egyenlő szárú háromszög magasságvonallal két egybevágó derékszögű háromszögre bontása.
  - Rombusz és trapéz átlói és magasságai.
