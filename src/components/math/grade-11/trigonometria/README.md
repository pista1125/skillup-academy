# I. Trigonometria (11. osztály)
- Hegyesszögek szögfüggvényei derékszögű háromszögben (sin, cos, tg, ctg)
- Nevezetes szögek szögfüggvényértékei (30°, 45°, 60°) és táblázatos összefüggései
- Szögfüggvények kiterjesztése tetszőleges szögre, forgásszögek, egységkör
- Alapvető azonosságok azonos szög szögfüggvényei között (pl. sin²α + cos²α = 1)
- Szinusztétel és koszinusztétel alkalmazása tetszőleges háromszögekre
- Háromszögek trigonometrikus területszámítása: T = (a · b · sin γ) / 2
- Alapvető trigonometrikus egyenletek és összefüggések
