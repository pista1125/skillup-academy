# 2. Számolás szögek tangensével (2. lecke)

## Tananyag Áttekintés
Számológép használata szögfüggvényekhez, szög visszakeresése tangens értékből ($\mathrm{tg}^{-1}$ / $\mathrm{arctg}$), és ismeretlen befogók kiszámítása gyakorlati problémákban.

---

## Fő Számítási Lépések

- **Számológép helyes beállítása:**
  - Szögmérték: fok (DEG - Degree) mód kiválasztása (nem RAD vagy GRAD).

- **Számítások ismeretlen oldalra:**
  - Ha ismert $\alpha$ és a szomszédos befogó ($b$):
    $$a = b \cdot \mathrm{tg}\,\alpha$$
  - Ha ismert $\alpha$ és a szemközti befogó ($a$):
    $$b = \frac{a}{\mathrm{tg}\,\alpha}$$

- **Szög visszakeresése ismeretlen szögre:**
  - Ha a két befogó ismert: $\mathrm{tg}\,\alpha = \frac{a}{b} \implies \alpha = \mathrm{arctg}\left(\frac{a}{b}\right)$.

- **Gyakorlati feladatok:**
  - Magasságok becslése lépéstávolság és látószög alapján.
