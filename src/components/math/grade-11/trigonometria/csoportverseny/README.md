# 15. Csoportverseny (14. lecke)

## Tananyag Áttekintés
Kooperatív csapatverseny és interaktív feladatok a trigonometria témaköréből: villámkérdések nevezetes szögekről, gyors szinusztétel- és koszinusztétel-alkalmazás, hibakeresés számításokban és stratégiai feladványok.

---

## Fő Versenytémák

- **Nevezetes szögek gyorsasági párbaja:**
  - $\sin, \cos, \mathrm{tg}$ pontos értékeinek megadása fejben.
  - Előjelek gyors felismerése tompaszögekre.

- **Döntési feladvány: Szinusztétel vagy koszinusztétel?**
  - Adott adatokból a leghatékonyabb megoldási stratégia kiválasztása másodpercek alatt.

- **Hibakeresés levezetésekben:**
  - Kétértelmű szinusz-feladatok buktatói (hol maradt el a tompaszögű megoldás?).
  - Előjelhibák a koszinusztételben ($-2ab\cos \gamma$ negatív koszinusznál).
