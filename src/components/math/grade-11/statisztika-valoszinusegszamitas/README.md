# V. Statisztika, valószínűségszámítás (11. osztály)
- Feltételes valószínűség fogalma, kiszámítása: P(A|B) = P(A ∩ B) / P(B)
- Események függetlensége és a szorzási szabály
- Teljes valószínűség tétele és Bayes-tétel alkalmazása
- Diszkrét valószínűségi változók, eloszlások megadása táblázattal
- Várható érték és szórás kiszámítása valószínűségi változókra
- Binomiális és hipergeometrikus eloszlás modelljei
- Statisztikai minták, becslések és konfidencia intervallumok alapjai
