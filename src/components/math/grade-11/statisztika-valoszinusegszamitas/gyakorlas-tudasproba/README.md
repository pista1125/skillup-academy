# 16. Gyakorlás, tudáspróba (65. lecke)

## Tananyag Áttekintés
A Statisztika és valószínűségszámítás fejezet átfogó összefoglalása: leíró statisztikai mutatók (átlag, medián, módusz, szórás, dobozdiagram) és valószínűségszámítási modellek (hipergeometrikus, binomiális eloszlás, várható érték) témazáró tudáspróbája.

---

## Fő Összefoglaló Témák és Képletgyűjtemény

- **Statisztikai mutatók:**
  - Átlag: $\bar{x} = \frac{\sum x_i}{n}$
  - Medián: rendezett sorozat felezőértéke
  - Szórás: $s = \sqrt{\frac{\sum (x_i - \bar{x})^2}{n}}$
  - Dobozdiagram: $x_{\min}, Q_1, Me, Q_3, x_{\max}$

- **Valószínűségszámítás:**
  - Klasszikus mező: $P = \frac{\text{kedvező}}{\text{összes}}$
  - Komplementer: $P(\bar{A}) = 1 - P(A)$
  - Várható érték: $E(X) = \sum x_i p_i$
  - Visszatevés nélküli mintavétel (egyszerre húzás): $P = \frac{\binom{S}{k}\binom{N-S}{n-k}}{\binom{N}{n}}$
  - Visszatevéses mintavétel (ugyanazt többször): $P = \binom{n}{k} p^k (1 - p)^{n - k}$
