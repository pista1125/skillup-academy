# 16. Gyakorlás (80. lecke)

## Tananyag Áttekintés
Gyakorló feladatsor összetett koordinátageometriai feladatok megoldására: háromszögek oldalegyenesei, magasságvonalai, súlyvonalai és körülírt köre, valamint érintős feladatok.

---

## Fő Gyakorlati Elemek és Típusfeladatok

- **Háromszög nevezetes vonalainak egyenletei:**
  - **Oldalegyenes:** két csúcsponton ($A, B$) átmenő egyenes ($\vec{v} = \vec{AB}$).
  - **Oldalfelező merőleges:** átmegy az oldal $F_{AB}$ felezőpontján, normálvektora $\vec{n} = \vec{AB}$.
  - **Magasságvonal:** átmegy a szemközti csúcson ($C$), normálvektora az oldalvektor $\vec{n} = \vec{AB}$.
  - **Súlyvonal:** átmegy a csúcson ($C$) és a szemközti oldal felezőpontján ($F_{AB}$).

- **Köré írt kör középpontja és sugara:**
  - Két oldalfelező merőleges metszéspontja adja a $K(u; v)$ középpontot.
  - A sugár a középpont távolsága bármelyik csúcstól: $r = d(K, A)$.

- **Érintési feladatok:**
  - Adott meredekségű érintők felírása egy körhöz (a kör középpontjának távolsága az érintőtől éppen $r$).
