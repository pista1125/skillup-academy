# 7. Felezőpont (71. lecke)

## Tananyag Áttekintés
Szakasz felezőpontjának, osztópontjainak és a háromszög súlypontjának koordinátái, valamint alkalmazásuk paralelogrammák és háromszögek vizsgálatában.

---

## Fő Fogalmak és Képletek

- **Szakasz felezőpontja ($F$):**
  - Legyen $A(x_1; y_1)$ és $B(x_2; y_2)$. A szakasz felezőpontjának koordinátái a végpontok koordinátáinak számtani közepei:
    $$F\left(\frac{x_1 + x_2}{2}; \; \frac{y_1 + y_2}{2}\right)$$
  - Helyvektoros alak: $\vec{f} = \frac{\vec{a} + \vec{b}}{2}$.

- **Szakasz adott arányú osztópontja:**
  - Ha a $P$ pont az $AB$ szakaszt $A$-tól mérve $k : l$ arányban osztja:
    $$\vec{p} = \frac{l \vec{a} + k \vec{b}}{k + l} \implies x_P = \frac{l x_1 + k x_2}{k + l}, \quad y_P = \frac{l y_1 + k y_2}{k + l}$$

- **Háromszög súlypontja ($S$):**
  - A három csúcs ($A, B, C$) koordinátáinak számtani közepe:
    $$S\left(\frac{x_A + x_B + x_C}{3}; \; \frac{y_A + y_B + y_C}{3}\right)$$

- **Paralelogramma negyedik csúcsa:**
  - Mivel a paralelogramma átlói felezik egymást: $F_{AC} = F_{BD} \implies \vec{a} + \vec{c} = \vec{b} + \vec{d} \implies \vec{d} = \vec{a} + \vec{c} - \vec{b}$.
