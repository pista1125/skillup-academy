# 13. Meredekség, iránytangens (77. lecke)

## Tananyag Áttekintés
Az egyenes meredeksége (iránytangense, $m$), irányszöge ($\alpha$) és a meredekséges egyenlet: $y = mx + b$ és $y - y_0 = m(x - x_0)$.

---

## Fő Fogalmak és Képletek

- **Irányszög és meredekség kapcsolata:**
  - Irányszög ($\alpha$): az egyenes $x$-tengely pozitív irányával bezárt szöge ($0^\circ \le \alpha < 180^\circ, \alpha \neq 90^\circ$).
  - Meredekség ($m$): az irányszög tangense:
    $$m = \tan\alpha$$
  - Ha az irányvektor $\vec{v}(v_1; v_2)$ ($v_1 \neq 0$):
    $$m = \frac{v_2}{v_1} = -\frac{A}{B}$$
  - Két ponton ($A(x_1; y_1)$ és $B(x_2; y_2)$) átmenő egyenes esetén:
    $$m = \frac{y_2 - y_1}{x_2 - x_1}$$

- **Meredekséges egyenletformák:**
  - Adott $P_0(x_0; y_0)$ pont és $m$ meredekség:
    $$y - y_0 = m(x - x_0)$$
  - Tengelymetszetes (explicit) alak:
    $$y = mx + b$$
    ahol $b$ az $y$-tengelymetszet ($P(0; b)$).
