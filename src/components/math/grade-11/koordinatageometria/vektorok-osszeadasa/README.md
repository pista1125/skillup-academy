# 1. Vektorok összeadása (66. lecke)

## Tananyag Áttekintés
A vektor fogalma: irányított szakasz, nagyság (hossz) és irány. Vektorok geometriai összeadása: háromszög-módszer és paralelogramma-módszer, valamint a vektorösszeadás alaptulajdonságai.

---

## Fő Fogalmak és Geometriai Szabályok

- **A vektor fogalma:**
  - Irányított szakasz, amelyet kezdőpontja és végpontja határoz meg ($\vec{a} = \vec{AB}$).
  - Szabad vektor: önmagával párhuzamosan eltolható, iránya és hossza változatlan marad.
  - Nullvektor ($\vec{0}$): hossza 0, iránya tetszőleges / határozatlan.

- **Összeadás háromszög-módszerrel (láncszabály):**
  - A $\vec{b}$ vektor kezdőpontját az $\vec{a}$ vektor végpontjába toljuk el.
  - Az összegvektor ($\vec{a} + \vec{b}$) az $\vec{a}$ kezdőpontjából a $\vec{b}$ végpontjába mutat:
    $$\vec{AB} + \vec{BC} = \vec{AC}$$

- **Összeadás paralelogramma-módszerrel:**
  - A két vektort közös kezdőpontból mérjük fel.
  - Az általuk kifeszített paralelogramma közös kezdőpontból induló átlója adja az összeget.

- **Algebrai tulajdonságok:**
  - Kommutatív: $\vec{a} + \vec{b} = \vec{b} + \vec{a}$
  - Asszociatív: $(\vec{a} + \vec{b}) + \vec{c} = \vec{a} + (\vec{b} + \vec{c})$
  - Nullvektor elem: $\vec{a} + \vec{0} = \vec{a}$
