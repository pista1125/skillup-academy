# 2. Két vektor különbsége (67. lecke)

## Tananyag Áttekintés
Két vektor különbségének definíciója és szerkesztése: ellentett vektor fogalma, közös kezdőpontból indított vektorok különbsége és a paralelogramma másik átlója.

---

## Fő Fogalmak és Szerkesztések

- **Ellentett vektor ($-\vec{b}$):**
  - Olyan vektor, amelynek hossza és állása (egyenese) megegyezik a $\vec{b}$ vektoréval, de iránya azzal pontosan ellentétes.
  - $\vec{b} + (-\vec{b}) = \vec{0}$.

- **A különbségvektor definíciója:**
  - A kivonás az ellentett vektor hozzáadásával egyenértékű:
    $$\vec{a} - \vec{b} = \vec{a} + (-\vec{b})$$

- **Szerkesztés közös kezdőpontból:**
  - Ha az $\vec{a}$ és $\vec{b}$ vektorokat közös kezdőpontból mérjük fel ($\vec{OA} = \vec{a}$, $\vec{OB} = \vec{b}$):
    - Az $\vec{a} - \vec{b}$ különbségvektor a $\vec{b}$ végpontjából az $\vec{a}$ végpontjába mutat:
      $$\vec{BA} = \vec{a} - \vec{b}$$
    - Ellenőrzés: $\vec{b} + (\vec{a} - \vec{b}) = \vec{a}$.

- **A paralelogramma átlói:**
  - Egyik átló: $\vec{a} + \vec{b}$ (összeg)
  - Másik átló: $\vec{a} - \vec{b}$ vagy $\vec{b} - \vec{a}$ (különbség)
