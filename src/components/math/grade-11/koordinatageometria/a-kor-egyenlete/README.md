# 11. A kör egyenlete (75. lecke)

## Tananyag Áttekintés
A kör geometriai definíciója mint mértani hely, a kör kanonikus egyenlete a középpont és a sugár ismeretében, valamint az általános másodfokú egyenlet teljes négyzetté alakítása.

---

## Fő Egyenletformák és Átalakítások

- **A kör kanonikus egyenlete:**
  - A $K(u; v)$ középpontú, $r > 0$ sugarú kör pontjainak mértani helye azon $P(x; y)$ pontok, amelyekre $d(K, P) = r$:
    $$(x - u)^2 + (y - v)^2 = r^2$$
  - Speciálisan, ha a középpont az origó ($u = 0, v = 0$):
    $$x^2 + y^2 = r^2$$

- **Általános alak teljes négyzetté alakítása:**
  - $$x^2 + y^2 + D x + E y + F = 0$$
  - Teljes négyzetté kiegészítéssel:
    $$\left(x + \frac{D}{2}\right)^2 + \left(y + \frac{E}{2}\right)^2 = \left(\frac{D}{2}\right)^2 + \left(\frac{E}{2}\right)^2 - F$$
  - Ekkor:
    - Középpont: $K\left(-\frac{D}{2}; \; -\frac{E}{2}\right)$
    - Sugár: $r = \sqrt{\frac{D^2 + E^2 - 4F}{4}}$ (feltétel: $D^2 + E^2 - 4F > 0$)
