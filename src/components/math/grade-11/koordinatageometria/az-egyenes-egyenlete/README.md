# 10. Az egyenes egyenlete (74. lecke)

## Tananyag Áttekintés
Az egyenes algebrai egyenletei a síkban: normálvektoros egyenlet, irányvektoros egyenlet, tengelymetszetes alak és az egyenlet felírásának lépései.

---

## Fő Egyenletformák és Képletek

- **Normálvektoros egyenlet:**
  - Adott a $P_0(x_0; y_0)$ pont és a normálvektor $\vec{n}(A; B)$:
    $$Ax + By = Ax_0 + By_0$$
  - Magyarázat: $\vec{n} \cdot \vec{P_0P} = 0 \iff A(x - x_0) + B(y - y_0) = 0$.
  - Az $x$ és $y$ együtthatói ($A$ és $B$) közvetlenül megadják az egyenes egy normálvektorát: $\vec{n}(A; B)$.

- **Irányvektoros egyenlet:**
  - Adott a $P_0(x_0; y_0)$ pont és az irányvektor $\vec{v}(v_1; v_2)$ ($v_1, v_2 \neq 0$):
    $$v_2 x - v_1 y = v_2 x_0 - v_1 y_0$$

- **Általános egyenlet:**
  - $$Ax + By + C = 0 \quad (A^2 + B^2 > 0)$$

- **Tengelymetszetes alak:**
  - Ha az egyenes metszi a tengelyeket az $(a; 0)$ és $(0; b)$ pontokban ($a, b \neq 0$):
    $$\frac{x}{a} + \frac{y}{b} = 1$$
