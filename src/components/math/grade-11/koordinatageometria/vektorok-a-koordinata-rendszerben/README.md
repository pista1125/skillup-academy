# 5. Vektorok a koordináta-rendszerben (69. lecke)

## Tananyag Áttekintés
Descartes-féle derékszögű koordináta-rendszer a síkban: helyvektorok, vektor koordinátái, műveletek koordinátákkal és a vektor hossza.

---

## Fő Fogalmak és Képletek

- **Helyvektor és koordináták:**
  - Az origóból ($O(0; 0)$) a $P(x; y)$ pontba mutató $\vec{p} = \vec{OP}$ vektor koordinátái megegyeznek a pont koordinátáival: $\vec{p}(x; y)$.
  - Bázisvektorok: $\vec{i}(1; 0)$ és $\vec{j}(0; 1)$, így $\vec{v} = v_1 \vec{i} + v_2 \vec{j}$.

- **Két pont közötti vektor ($\vec{AB}$):**
  - Ha $A(x_1; y_1)$ és $B(x_2; y_2)$, akkor a végpont helyvektorából kivonjuk a kezdőpont helyvektorát:
    $$\vec{AB} = \vec{b} - \vec{a} = (x_2 - x_1; \; y_2 - y_1)$$

- **Műveletek koordinátákkal:**
  - Összeadás: $\vec{a}(a_1; a_2) + \vec{b}(b_1; b_2) = (a_1 + b_1; \; a_2 + b_2)$
  - Kivonás: $\vec{a}(a_1; a_2) - \vec{b}(b_1; b_2) = (a_1 - b_1; \; a_2 - b_2)$
  - Számszoros: $\lambda \vec{a} = (\lambda a_1; \; \lambda a_2)$

- **Vektor hossza (abszolútértéke):**
  - Pitagorasz-tétellel:
    $$|\vec{a}| = \sqrt{a_1^2 + a_2^2}$$
