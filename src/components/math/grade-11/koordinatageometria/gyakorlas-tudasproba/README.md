# 17. Gyakorlás, tudáspróba (81. lecke)

## Tananyag Áttekintés
A Koordinátageometria fejezet átfogó összefoglalása: vektorok, távolság, felezőpont, az egyenes és a kör egyenletei, metszéspontok, merőlegesség, párhuzamosság és érettségi típusú témazáró tudáspróba.

---

## Fő Összefoglaló Témák és Képletgyűjtemény

- **Vektorok és pontok:**
  - Két pont távolsága: $d(A, B) = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}$
  - Szakasz felezőpontja: $F\left(\frac{x_1 + x_2}{2}; \; \frac{y_1 + y_2}{2}\right)$
  - Háromszög súlypontja: $S\left(\frac{x_A + x_B + x_C}{3}; \; \frac{y_A + y_B + y_C}{3}\right)$

- **Az egyenes:**
  - Normálvektoros egyenlet: $Ax + By = Ax_0 + By_0$
  - Irányvektorból normálvektor: $\vec{v}(v_1; v_2) \implies \vec{n}(-v_2; v_1)$
  - Meredekség: $m = \tan\alpha = \frac{v_2}{v_1} = -\frac{A}{B}$
  - Párhuzamosság: $m_1 = m_2$, merőlegesség: $m_1 \cdot m_2 = -1$

- **A kör:**
  - Kanonikus egyenlet: $(x - u)^2 + (y - v)^2 = r^2$
  - Kör érintője az érintési pontban: normálvektora a sugárvektor $\vec{KE}$
