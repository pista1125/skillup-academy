# 2. Gúlák (8. osztály)

## Tananyag Áttekintés
A gúla geometriai definíciója, alkotóelemei (alaplap, csúcspont, oldalélek, oldallapok, palást, testmagasság, oldallap-magasság), a szabályos gúlák tulajdonságai, valamint a gúlahálók megszerkesztése és kiterítése.

---

## 1. A Gúla Alapfogalmai és Részei

- **Gúla (Piraxis):** Olyan térbeli test, amelynek alaplapja egy sokszög, oldallapjai pedig egy közös csúcsban ($M$, testcsúcs) találkozó háromszögek.
- **Részei:**
  - **Alaplap:** Tetszőleges sokszög (háromszög, négyszög, hatszög stb.).
  - **Palást:** Az oldalháromszögek összessége.
  - **Alapélek ($a$):** Az alaplapot határoló szakaszok.
  - **Oldalélek ($b$):** A testcsúcsot az alaplap csúcsaival összekötő élek.
  - **Testmagasság ($m$):** A csúcsból az alaplap síkjára bocsátott merőleges szakasz hossza.
  - **Oldallap magassága ($m_o$):** Az oldalháromszög alaphoz tartozó magassága.

---

## 2. Szabályos Gúlák
Egy gúla **szabályos**, ha:
1. Az alaplapja egy **szabályos sokszög** (pl. egyenlő oldalú háromszög, négyzet, szabályos hatszög).
2. A csúcs merőleges vetülete pontosan az **alaplap középpontjába** esik.
3. Következmény: Az oldalélek ($b$) mind egyenlő hosszúak, az oldallapok mind **egybevágó egyenlő szárú háromszögek**.

---

## 3. Euler-féle Poliéder-tétel
Minden konvex poliéderre, így a gúlákra is igaz:
$$\text{Csúcsok száma } (C) - \text{Élek száma } (É) + \text{Lapok száma } (L) = 2$$
Egy $n$-oldalú gúla esetén:
- Csúcsok száma: $C = n + 1$
- Lapok száma: $L = n + 1$
- Élek száma: $É = 2n$
- Ellenőrzés: $(n+1) - 2n + (n+1) = 2$.
