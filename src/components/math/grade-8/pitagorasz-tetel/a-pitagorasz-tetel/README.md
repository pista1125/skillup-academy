# 2. A Pitagorasz-tétel (8. osztály)

## Tananyag Áttekintés
A matematika egyik leghíresebb és legfontosabb tétele: a Pitagorasz-tétel kimondása, algebrai alakja, geometriai bizonyításai, valamint az átfogó és a befogók kiszámítása.

---

## 1. A Tétel Kimondása és Képlete

> [!IMPORTANT]
> **Pitagoraszi Tétel:**
> Bármely derékszögű háromszögben a két befogó hosszának négyzetösszege egyenlő az átfogó hosszának négyzetével.
> 
> $$a^2 + b^2 = c^2$$

Ahol:
- $a, b$: a két befogó hossza
- $c$: az átfogó hossza ($c > a$ és $c > b$)

---

## 2. Képletek az Oldalak Kiszámítására

1. **Átfogó kiszámítása (ha a két befogó ismert):**
   $$c = \sqrt{a^2 + b^2}$$
2. **Befogó kiszámítása (ha az átfogó és a másik befogó ismert):**
   $$a = \sqrt{c^2 - b^2}$$
   $$b = \sqrt{c^2 - a^2}$$

> [!CAUTION]
> **Gyakori hiba:** Befogó számításakor kivonni kell a négyzeteket ($c^2 - a^2$), NEM összeadni!

---

## 3. Mintapéldák

### 1. Átfogó keresése:
- $a = 6\text{ cm}, b = 8\text{ cm}$.
- $c^2 = 6^2 + 8^2 = 36 + 64 = 100 \implies c = \sqrt{100} = 10\text{ cm}$.

### 2. Befogó keresése:
- $c = 13\text{ cm}, a = 5\text{ cm}$.
- $b^2 = c^2 - a^2 = 13^2 - 5^2 = 169 - 25 = 144 \implies b = \sqrt{144} = 12\text{ cm}$.

### 3. Gyökös (nem egész) eredmény:
- $a = 3\text{ cm}, b = 4\text{ cm} \implies c = 5\text{ cm}$.
- $a = 1\text{ cm}, b = 1\text{ cm} \implies c^2 = 1^2 + 1^2 = 2 \implies c = \sqrt{2} \approx 1{,}41\text{ cm}$.
