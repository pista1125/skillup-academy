# 3. A Pitagorasz-tétel megfordítása (Kiegészítő tananyag) (8. osztály)

## Tananyag Áttekintés
A Pitagorasz-tétel megfordításának kimondása, háromszögek derékszögűségének ellenőrzése kizárólag oldalhosszakból, pitagoraszi számhármasok, valamint háromszögek hegyes-, derék- és tompaszögű osztályozása.

---

## 1. A Tétel Megfordítása

> [!IMPORTANT]
> **A Pitagorasz-tétel megfordítása:**
> Ha egy háromszög $a, b, c$ oldalaira (ahol $c$ a leghosszabb oldal) teljesül, hogy
> $$a^2 + b^2 = c^2$$
> akkor a háromszög **derékszögű**, és a $c$ oldallal szemközti szöge pontosan $90^\circ$.

---

## 2. Háromszögek Szögtípusának Meghatározása Oldalhosszak Alapján

Ha $c$ a háromszög leghosszabb oldala:

| Feltétel | Háromszög típusa | Magyarázat |
|---|---|---|
| **$c^2 = a^2 + b^2$** | **Derékszögű** | A leghosszabb oldallal szemben $90^\circ$-os szög van |
| **$c^2 < a^2 + b^2$** | **Hegyesszögű** | Minden szöge hegyesszög ($< 90^\circ$) |
| **$c^2 > a^2 + b^2$** | **Tompaszögű** | A leghosszabb oldallal szemben tompaszög van ($> 90^\circ$) |

> [!NOTE]
> **Háromszög-egyenlőtlenség feltétele:** Először mindig ellenőrizni kell, hogy egyáltalán háromszöget alkotnak-e a szakaszok: $a + b > c$.

---

## 3. Nevezetes Pitagoraszi Számhármasok

Olyan **pozitív egész számhármasok** $(a, b, c)$, amelyekre $a^2 + b^2 = c^2$:

1. **$(3, 4, 5)$** $\implies 3^2 + 4^2 = 9 + 16 = 25 = 5^2$ (és többszörösei: $6-8-10$, $9-12-15$, $12-16-20$, $30-40-50$)
2. **$(5, 12, 13)$** $\implies 5^2 + 12^2 = 25 + 144 = 169 = 13^2$ (és többszörösei: $10-24-26$)
3. **$(8, 15, 17)$** $\implies 8^2 + 15^2 = 64 + 225 = 289 = 17^2$
4. **$(7, 24, 25)$** $\implies 7^2 + 24^2 = 49 + 576 = 625 = 25^2$
5. **$(9, 40, 41)$** $\implies 9^2 + 40^2 = 81 + 1600 = 1681 = 41^2$
6. **$(20, 21, 29)$** $\implies 20^2 + 21^2 = 400 + 441 = 841 = 29^2$

> [!TIP]
> **Történelmi érdekesség (Egyiptomi zsinór):**
> Az ókori egyiptomi földmérők egy 12 egyenlő csomóra osztott zárt kötelet használtak, amelyet $3 : 4 : 5$ arányban kifeszítve pontos derékszöget tudtak kitűzni a terepen.
