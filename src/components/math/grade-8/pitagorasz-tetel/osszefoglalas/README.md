# 7. Összefoglalás (8. osztály)

## Tananyag Áttekintés
Az V. A Pitagorasz-tétel és alkalmazásai fejezet teljes anyagának rendszerezése: a tétel kimondása, megfordítása, síkbeli alkalmazások (négyzet, téglalap, háromszögek, rombusz, trapéz), térbeli alkalmazások (kocka és téglatest testátlója, gúlák testmagassága), valamint nevezetes derékszögű háromszögek.

## 2. Térbeli Alkalmazások (Előretekintés a Testek témakörhöz)

### A. Kocka Lapátlója és Testátlója
- **Lapátló ($d$):** $d = a\sqrt{2}$
- **Testátló ($D$):**
  $$D^2 = d^2 + a^2 = 2a^2 + a^2 = 3a^2 \implies D = a\sqrt{3}$$

### B. Téglatest Testátlója
- Oldalai: $a, b, c$.
- Lapátló a téglatest alján: $d^2 = a^2 + b^2$.
- Testátló:
  $$D^2 = d^2 + c^2 = a^2 + b^2 + c^2 \implies D = \sqrt{a^2 + b^2 + c^2}$$

### C. Négyzet Alapú Gúla Magassága
- Alapéle $a$, oldaléle $b$.
- Az alap lapátlója $d = a\sqrt{2}$, fele $\frac{d}{2} = \frac{a\sqrt{2}}{2}$.
- A testmagasság ($M$):
  $$M^2 + \left(\frac{a\sqrt{2}}{2}\right)^2 = b^2 \implies M = \sqrt{b^2 - \frac{a^2}{2}}$$
