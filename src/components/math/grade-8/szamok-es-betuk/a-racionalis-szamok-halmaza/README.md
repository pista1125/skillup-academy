# 4. A racionális számok halmaza (8. osztály)

## Tananyag Áttekintés
A számhalmazok hierarchiája, a racionális számok különböző alakjai (tört, tizedestört), a végtelen szakaszos tizedestörtek átírása és a számegyenesen való elhelyezés.

---

## Főbb Fogalmak és Összefüggések

### 1. Számhalmazok hierarchiája
- **Természetes számok ($\mathbb{N}$):** $\{0, 1, 2, 3, \dots\}$
- **Egész számok ($\mathbb{Z}$):** $\{\dots, -3, -2, -1, 0, 1, 2, 3, \dots\}$
- **Racionális számok ($\mathbb{Q}$):** Olyan számok, amelyek felírhatók két egész szám hányadosaként:
  $$\mathbb{Q} = \left\{ \frac{a}{b} \;\middle|\; a, b \in \mathbb{Z}, b \neq 0 \right\}$$
- **Részhalmaz-lánc:** $\mathbb{N} \subset \mathbb{Z} \subset \mathbb{Q} \subset \mathbb{R}$

### 2. Tizedestört alakok
Minden racionális szám felírható tizedestörtként, ami vagy:
1. **Véges tizedestört:** Pl. $\frac{3}{4} = 0{,}75$, $\frac{7}{8} = 0{,}875$.
   - *Feltétele:* Az egyszerűsített tört nevezőjének prímtényezős felbontásában **csak 2 és 5** szerepelhet ($2^p \cdot 5^q$).
2. **Végtelen szakaszos tizedestört:** Pl. $\frac{1}{3} = 0{,}333\dots = 0{,}\dot{3}$, $\frac{5}{6} = 0{,}833\dots = 0{,}8\dot{3}$, $\frac{4}{7} = 0{,}\dot{5}7142\dot{8}$.

### 3. Végtelen szakaszos tizedestört átírása törtté
- **Tiszta szakaszos:** $x = 0{,}\dot{7} \implies 10x = 7{,}\dot{7} \implies 9x = 7 \implies x = \frac{7}{9}$.
- **Vegyes szakaszos:** $y = 0{,}2\dot{5} \implies 100y = 25{,}\dot{5}$, $10y = 2{,}\dot{5} \implies 90y = 23 \implies y = \frac{23}{90}$.

### 4. Ellentett és Abszolútérték
- **Ellentett:** Egy $a$ szám ellentettje $-a$. Összegük: $a + (-a) = 0$.
- **Abszolútérték ($\lvert a \rvert$):** A szám távolsága a 0-tól a számegyenesen.
  $$\lvert a \rvert = \begin{cases} a, & \text{ha } a \ge 0 \\ -a, & \text{ha } a < 0 \end{cases}$$
- **Reciprok:** Az $a \neq 0$ szám reciproka $\frac{1}{a}$. Szorzatuk: $a \cdot \frac{1}{a} = 1$.
