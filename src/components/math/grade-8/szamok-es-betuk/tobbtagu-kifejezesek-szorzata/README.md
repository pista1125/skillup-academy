# 11. Többtagú kifejezések szorzata (Kiegészítő tananyag) (8. osztály)

## Tananyag Áttekintés
Többtagú algebrai kifejezések összeszorzása (minden tagot minden taggal), a nevezetes azonosságok felismerése és alkalmazása mindkét irányban (zárójelbontás és szorzattá alakítás), valamint a geometriai területmodell.

---

## Szabályok és Nevezetes Azonosságok

### 1. Kéttagú szorzása kéttagúval
- Az egyik zárójel **minden tagját megszorozzuk** a másik zárójel **minden tagjával** (összesen $2 \times 2 = 4$ tag keletkezik az összevonás előtt):
  $$(a + b)(c + d) = ac + ad + bc + bd$$
- *Példa:*
  $$(x + 3)(x + 5) = x^2 + 5x + 3x + 15 = x^2 + 8x + 15$$
  $$(2x - 1)(3x + 4) = 6x^2 + 8x - 3x - 4 = 6x^2 + 5x - 4$$

### 2. A 3 Nevezetes Azonosság
1. **Kéttagú összeg négyzete:**
   $$(a + b)^2 = a^2 + 2ab + b^2$$
   - *Példa:* $(x + 4)^2 = x^2 + 2 \cdot x \cdot 4 + 4^2 = x^2 + 8x + 16$
   - *Példa:* $(2x + 3y)^2 = (2x)^2 + 2(2x)(3y) + (3y)^2 = 4x^2 + 12xy + 9y^2$

2. **Kéttagú különbség négyzete:**
   $$(a - b)^2 = a^2 - 2ab + b^2$$
   - *Példa:* $(x - 5)^2 = x^2 - 2 \cdot x \cdot 5 + 5^2 = x^2 - 10x + 25$
   - *Példa:* $(3x - 1)^2 = 9x^2 - 6x + 1$

3. **Összeg és különbség szorzata (Négyzetek különbsége):**
   $$(a + b)(a - b) = a^2 - b^2$$
   - *Példa:* $(x + 6)(x - 6) = x^2 - 36$
   - *Példa:* $(2a + 5)(2a - 5) = 4a^2 - 25$
   - *Számolási trükk:* $42 \cdot 38 = (40 + 2)(40 - 2) = 40^2 - 2^2 = 1600 - 4 = 1596$.

### 3. Geometriai szemléltetés (Területmodell)
- Egy $(a+b)$ oldalú négyzet területe felbontható 4 részre:
  - Egy $a \times a$ négyzet ($a^2$)
  - Két $a \times b$ téglalap ($2ab$)
  - Egy $b \times b$ négyzet ($b^2$)
  - Teljes terület: $(a+b)^2 = a^2 + 2ab + b^2$.
