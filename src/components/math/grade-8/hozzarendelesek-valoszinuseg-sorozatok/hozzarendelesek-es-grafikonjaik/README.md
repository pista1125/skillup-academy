# 2. Hozzárendelések és grafikonjaik (8. osztály)

## Tananyag Áttekintés
A függvény és hozzárendelés fogalma, alaphalmaz, értelmezési tartomány ($D_f$), értékkészlet ($R_f$), elsőfokú (lineáris) függvények általános alakja ($y = ax + b$), valamint a paraméterek geometriai jelentése.

---

## 1. Alapfogalmak
- **Hozzárendelés (Függvény):** Olyan szabály, amely az alaphalmaz (értelmezési tartomány, $D_f$) minden egyes eleméhez a képhalmaz (értékkészlet, $R_f$) **pontosan egyetlen** elemét rendeli hozzá.
- **Függvényérték:** $f(x)$ vagy $y$.
- **Zérushely:** Az az $x$ érték, ahol a függvényérték nulla ($f(x) = 0$, a grafikon itt metszi az $x$-tengelyt).

---

## 2. A Lineáris Függvény ($y = ax + b$)

$$f(x) = ax + b$$

| Paraméter | Megnevezés | Geometriai jelentés |
|---|---|---|
| **$a$** | **Meredekség (iránytangens)** | - Ha $a > 0$: a függvény szigorúan monoton növekvő<br>- Ha $a < 0$: a függvény szigorúan monoton csökkenő<br>- Ha $a = 0$: konstans függvény (vízszintes egyenes $y = b$) |
| **$b$** | **Tengelymetszet ($y$-metszet)** | A grafikon és az $y$-tengely metszéspontja: $(0; b)$ pont. |

---

## 3. Nevezetes Függvénytípusok Áttekintése

1. **Konstans függvény:** $f(x) = c$ (vízszintes egyenes).
2. **Identikus (egyenlőségi) függvény:** $f(x) = x$ ($a = 1, b = 0$, az I. és III. síknegyed felezője).
3. **Abszolútérték-függvény:** $f(x) = |x|$ („V” alakú grafikon, csúcspontja az origóban).
4. **Másodfokú alapfüggvény:** $f(x) = x^2$ (parabola, tengelypontja az origóban).
