# 4. Olvassunk a grafikonról! (8. osztály)

## Tananyag Áttekintés
Gyakorlati folyamatokat (út-idő menetdiagramok, hőmérsékletváltozások, vízszintváltozások, gazdasági adatok) ábrázoló grafikonok elemzése, pontok koordinátáinak leolvasása, intervallumok, növekedési és csökkenési szakaszok, valamint szélsőértékek azonosítása.

---

## 1. A Grafikonról Leolvasható Főbb Jellemzők

1. **Értelmezési tartomány ($D_f$):** A vízszintes ($x$) tengelyen az az intervallum, amelyre a folyamat érvényes (pl. $0 \le t \le 12\text{ óra}$).
2. **Értékkészlet ($R_f$):** A függőleges ($y$) tengelyen felvett legkisebb és legnagyobb értékek közötti szakasz (pl. $-5^\circ\text{C} \le T \le 22^\circ\text{C}$).
3. **Zérushely(ek):** Ahol a grafikon átmetszi az $x$-tengelyt ($y = 0$).
4. **Szélsőértékek:**
   - **Maximum (legnagyobb érték):** A grafikon legmagasabb pontjának $y$-értéke, és az ehhez tartozó $x$ (maximumhely).
   - **Minimum (legkisebb érték):** A grafikon legmélyebb pontjának $y$-értéke, és az ehhez tartozó $x$ (minimumhely).
5. **Monotonitási szakaszok:**
   - **Növekvő szakasz:** Balról jobbra haladva a görbe felfelé emelkedik.
   - **Csökkenő szakasz:** Balról jobbra haladva a görbe lefelé lejt.
   - **Állandó (konstans) szakasz:** Vízszintes vonal (pl. állóhelyzet, pihenő).

---

## 2. Menetdiagramok ($s-t$ grafikonok) Elemzése
- **Vízszintes szakasz:** A test áll (sebessége $v = 0$).
- **Meredekebb egyenes szakasz:** Nagyobb sebesség ($v = \frac{\Delta s}{\Delta t}$).
- **Visszafelé lejtő szakasz:** Visszafordulás a kiindulópont felé.
- **Két menetdiagram metszéspontja:** A két mozgó test találkozási helye és időpontja!
