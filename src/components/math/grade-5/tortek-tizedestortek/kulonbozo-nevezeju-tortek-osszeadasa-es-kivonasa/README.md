# 5. Különböző nevezőjű törtek összeadása és kivonása

## Tananyag Áttekintés
Különböző nevezőjű törtek összeadása és kivonása közös nevezőre hozással (legkisebb közös többszörös keresése), bővítés és az elvégzett művelet egyszerűsítése.

---

## Főbb Lépések és Képletek

### 1. A Művelet Lépései
1. **Közös nevező keresése:** Megkeressük a nevezők legkisebb közös többszörösét (LKKT).
2. **Bővítés:** Mindegyik törtet kibővítjük a közös nevezőre.
3. **Művelet elvégzése:** A kapott azonos nevezőjű törtek számlálóit összeadjuk vagy kivonjuk.
4. **Egyszerűsítés:** Ha lehet, a kapott eredményt egyszerűsítjük, vagy áltört esetén vegyes számmá alakítjuk.

### Példa:
$$\frac{1}{3} + \frac{1}{4} = \frac{4}{12} + \frac{3}{12} = \frac{7}{12}$$
$$\frac{5}{6} - \frac{3}{8} = \frac{20}{24} - \frac{9}{24} = \frac{11}{24}$$
