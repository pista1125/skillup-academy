# 7. Tört osztása pozitív egész számmal

## Tananyag Áttekintés
Tört osztása egész számmal (részekre osztás), a számláló osztása vagy a nevező szorzása, összefüggés az egységtörtekkel való szorzással.

---

## Főbb Szabályok és Képletek

### 1. Kétféle Osztási Módszer
1. **Számláló osztása (ha osztható):** Ha a számláló osztható az egész számmal, a számlálót osztjuk, a nevező változatlan marad:
   $$\frac{a}{b} : n = \frac{a : n}{b}$$
2. **Nevező szorzása:** Ha a számláló nem osztható, a nevezőt szorozzuk meg az osztóval (mert a részek mérete csökken):
   $$\frac{a}{b} : n = \frac{a}{b \cdot n}$$

### Példák:
$$\frac{6}{7} : 3 = \frac{6 : 3}{7} = \frac{2}{7}$$
$$\frac{3}{5} : 2 = \frac{3}{5 \cdot 2} = \frac{3}{10}$$
