# 15. Közönséges törtek tizedes tört alakja

## Tananyag Áttekintés
Közönséges törtek átírása tizedestört alakba bővítéssel (ha a nevező $10, 100, 1000$ hatványára hozható) vagy a számláló nevezővel való elosztásával, valamint tizedestörtek felírása legegyszerűbb tört alakban.

---

## Átváltási Módszerek

### 1. Bővítés $10, 100, 1000$-es Nevezőre
- Ha a tört nevezőjének prímtényezős felbontásában csak $2$-es és/vagy $5$-ös szerepel:
  $$\frac{1}{2} = \frac{5}{10} = 0{,}5$$
  $$\frac{1}{4} = \frac{25}{100} = 0{,}25$$
  $$\frac{3}{4} = \frac{75}{100} = 0{,}75$$
  $$\frac{1}{5} = \frac{2}{10} = 0{,}2$$
  $$\frac{1}{8} = \frac{125}{1000} = 0{,}125$$

### 2. Osztással Történő Átváltás
- A számlálót elosztjuk a nevezővel:
  $$\frac{3}{8} = 3 : 8 = 0{,}375$$

### 3. Tizedestörtből Közönséges Tört
- A tizedestörtet helyiértéke szerint felírjuk törtként, majd egyszerűsítjük:
  $$0{,}75 = \frac{75}{100} = \frac{3}{4}$$
  $$0{,}4 = \frac{4}{10} = \frac{2}{5}$$
