# 4. Egyenlő nevezőjű törtek összeadása és kivonása

## Tananyag Áttekintés
Azonos nevezőjű törtek összeadása és kivonása, az eredmény egyszerűsítése vagy vegyes tört alakban történő megadása, egésszel végzett összeadás és kivonás.

---

## Főbb Műveleti Szabályok

### 1. Összeadás
- Azonos nevezőjű törteket úgy adunk össze, hogy a **számlálókat összeadjuk**, a **nevezőt változatlanul hagyjuk**:
  $$\frac{a}{c} + \frac{b}{c} = \frac{a + b}{c}$$

### 2. Kivonás
- Azonos nevezőjű törtek kivonásakor a **számlálókat kivonjuk**, a **nevezőt változatlanul hagyjuk**:
  $$\frac{a}{c} - \frac{b}{c} = \frac{a - b}{c}$$

### 3. Egészből Való Kivonás
Példa: $1 - \frac{3}{5}$
$$1 - \frac{3}{5} = \frac{5}{5} - \frac{3}{5} = \frac{2}{5}$$
$$3 - \frac{2}{7} = 2\frac{7}{7} - \frac{2}{7} = 2\frac{5}{7}$$
