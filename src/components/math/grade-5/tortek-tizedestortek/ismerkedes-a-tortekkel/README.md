# 1. Ismerkedés a törtekkel

## Tananyag Áttekintés
A törtszám fogalma mint az egész egyenlő részekre osztása, a tört részei (számláló, nevező, törtvonal), egységtörtek, valamint valódi és áltörtek felismerése vizuális modellekkel (kördiagram, téglalap, csokoládé).

---

## Főbb Fogalmak és Jelölések

### 1. A Tört Részei
$$\frac{\text{számláló}}{\text{nevező}} = \frac{a}{b}$$
- **Nevező ($b$):** Megmutatja, hány egyenlő részre osztottuk az egészet ($b \ne 0$).
- **Törtvonal:** Az osztás műveletét jelenti.
- **Számláló ($a$):** Megmutatja, hány ilyen részt vettünk az egészből.

### 2. Törtek Típusai
- **Valódi tört:** A számláló kisebb a nevezőnél ($a < b$), értéke kisebb $1$-nél (pl. $\frac{3}{4}, \frac{2}{5}$).
- **Egész értékű tört:** A számláló a nevező többszöröse (pl. $\frac{4}{4} = 1, \frac{8}{4} = 2$).
- **Áltört:** A számláló nagyobb a nevezőnél ($a > b$), értéke nagyobb $1$-nél (pl. $\frac{7}{4}, \frac{11}{3}$).
