# 10. Tizedes törtek

## Tananyag Áttekintés
A tízes alapú helyiértékes számrendszer kiterjesztése az egyesek alá: tizedesvessző, tized ($0{,}1$), század ($0{,}01$), ezred ($0{,}001$), tízezred helyiértékek, tizedestörtek írása, olvasása és helyiérték-táblázata.

---

## Helyiértékek a Tizedesvessző Után

| Egész rész | Tizedesvessző | Tizedek ($\frac{1}{10}$) | Századok ($\frac{1}{100}$) | Ezredek ($\frac{1}{1000}$) |
| :---: | :---: | :---: | :---: | :---: |
| $3$ | , | $4$ | $5$ | $8$ |

- **Kiolvasás:** *Három egész négyszázötvennyolc ezred*.
- **Értéke összegként:**
  $$3{,}458 = 3 + \frac{4}{10} + \frac{5}{100} + \frac{8}{1000}$$
- **Záró nullák szerepe:** A tizedestört végére írt nullák nem változtatják meg a szám értékét ($0{,}5 = 0{,}50 = 0{,}500$).
