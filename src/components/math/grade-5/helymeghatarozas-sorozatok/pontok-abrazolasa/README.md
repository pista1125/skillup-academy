# 4. Pontok ábrázolása

## Tananyag Áttekintés
A sík pontjait **rendezett számpárokkal** jelöljük: $P(x; y)$. A rendezettség azt jelenti, hogy a számok sorrendje szigorúan kötött!

---

## Pontok Leolvasása és Felvétele

### A Számpár Értelmezése
$$P(x; y)$$
- **$x$ koordináta (első szám):** Az origótól való vízszintes elmozdulás mértéke.
  - Ha pozitív: jobbra lépünk
  - Ha negatív: balra lépünk
- **$y$ koordináta (második szám):** A függőleges elmozdulás mértéke.
  - Ha pozitív: felfelé lépünk
  - Ha negatív: lefelé lépünk

### Példák
- $A(3; 2)$: Origóból 3 egység jobbra, majd 2 egység fel.
- $B(-4; 1)$: Origóból 4 egység balra, majd 1 egység fel.
- $C(-2; -3)$: Origóból 2 egység balra, majd 3 egység le.
- $D(5; -1)$: Origóból 5 egység jobbra, majd 1 egység le.
- **Tengelyeken fekvő pontok:**
  - $E(4; 0)$: Az $x$-tengelyen helyezkedik el (4 jobbra, 0 fel/le).
  - $F(0; -3)$: Az $y$-tengelyen helyezkedik el (0 jobbra/balra, 3 lefelé).
  - $O(0; 0)$: Az origó.

### Alakzatok Ábrázolása Pontokkal
Ha a megadott pontokat sorban összekötjük, sokszögeket, ábrákat, síkidomokat kapunk.
- Példa: $A(1; 1), B(5; 1), C(5; 4), D(1; 4)$ pontok egy téglalap csúcsai.
