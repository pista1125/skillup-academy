# 3. A derékszögű koordináta-rendszer

## Tananyag Áttekintés
A derékszögű (Descartes-féle) koordináta-rendszer két egymásra merőleges, közös kezdőpontú számegyenesből áll. Ezzel a rendszerrel a sík bármely pontjának helyzete pontos számpárokkal adható meg.

---

## A Koordináta-rendszer Felépítése

```
                   y (függőleges tengely)
                   ▲
                   │
              3 ───┼───
                   │
              2 ───┼───
                   │
              1 ───┼───
                   │   O (0; 0)
───┼───┼───┼───┼───┼───┼───┼───┼───┼───► x (vízszintes tengely)
  -4  -3  -2  -1   │   1   2   3   4
              -1 ──┼───
                   │
              -2 ──┼───
                   │
              -3 ──┼───
                   │
```

### Főbb Elemek
1. **Origó ($O$):** A két tengely metszéspontja, koordinátája: $(0; 0)$.
2. **Első tengely ($x$-tengely / abszcissza):** Vízszintes számegyenes. Jobbra a pozitív, balra a negatív számok helyezkednek el.
3. **Második tengely ($y$-tengely / ordináta):** Függőleges számegyenes. Felfelé a pozitív, lefelé a negatív számok találhatók.
4. **Egység:** A tengelyeken lévő beosztás nagysága (általában 1 rácsnégyzet = 1 egység).

### Síknegyedek
A két tengely 4 negyedre (kvadránsra) osztja a síkot:
- **I. síknegyed:** $x > 0, y > 0$ (jobbra-fenn)
- **II. síknegyed:** $x < 0, y > 0$ (balra-fenn)
- **III. síknegyed:** $x < 0, y < 0$ (balra-lenn)
- **IV. síknegyed:** $x > 0, y < 0$ (jobbra-lenn)
