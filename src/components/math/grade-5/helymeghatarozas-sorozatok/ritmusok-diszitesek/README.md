# 6. Ritmusok, díszítések

## Tananyag Áttekintés
A ritmus a természetben, a zenében, a népművészetben és a matematikában is az elemek szabályos, ismétlődő rendjét jelenti. A díszítősorok (frizek, szegélyminták) geometriai transzformációk (eltolás, tükrözés, forgatás) segítségével épülnek fel.

---

## Mintázatok és Díszítősorok

### 1. Az Alapszakasz (Motívum)
- A mintázat legkisebb önálló része, amelynek ismétlésével létrehozható az egész sor.
- **Példa:** $\circ \ \square \ \triangle \ \circ \ \square \ \triangle \ \circ \ \square \ \triangle \dots$
  - Alapszakasz: $(\circ \ \square \ \triangle)$
  - Ismétlődési hossz (periódus): 3 elem.

### 2. Díszítősorok Típusai
- **Eltolásos ritmus:** Az alakzatot egy adott távolsággal folyamatosan eltoljuk egy irányba.
- **Tükrözéses ritmus:** Az alakzatot váltakozva tükrözzük egy függőleges vagy vízszintes tengelyre.
- **Forgatásos ritmus:** Az alakzatot lépésenként elforgatjuk ($90^\circ$-kal vagy $180^\circ$-kal).

### 3. Alkalmazások a Mindennapokban
- Magyar népi hímzések, fafaragások bordűrjei
- Csempézések, mozaikok, járólapminták
- Épületek homlokzati díszítései
- Szövetek, textilek mintázata
