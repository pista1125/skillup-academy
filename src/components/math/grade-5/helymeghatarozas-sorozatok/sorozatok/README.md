# 8. Sorozatok

## Tananyag Áttekintés
A számsorozat olyan számok rendezett listája, amelyek valamilyen szabály szerint követik egymást. A sorozat elemeit **tagoknak** nevezzük.

---

## Sorozatok Típusai és Szabályai

### 1. Sorozat Megadása
- **Tagok sorrendje:** $a_1$ (1. tag), $a_2$ (2. tag), $a_3$ (3. tag), $\dots, a_n$ ($n$-edik tag).
- **Szabály megadása:**
  - Kezdőtag és a következő tag képzése (rekurzív megadás, pl. Kezdőtag: 4, lépésköz: $+3$).
  - A sorozat $n$-edik tagjának közvetlen kiszámítási módja.

### 2. Gyakori Képzési Szabályok

#### A) Állandó érték hozzáadása vagy levonása (Számtani jellegű)
- **Növekvő:** $2, 5, 8, 11, 14, 17, \dots$ (szabály: $+3$)
- **Csökkenő:** $50, 43, 36, 29, 22, \dots$ (szabály: $-7$)

#### B) Állandó értékkel való szorzás vagy osztás (Mértani jellegű)
- **Növekvő szorzás:** $1, 2, 4, 8, 16, 32, 64, \dots$ (szabály: $\cdot 2$)
- **Növekvő szorzás:** $3, 9, 27, 81, \dots$ (szabály: $\cdot 3$)
- **Csökkenő felezés:** $80, 40, 20, 10, 5, \dots$ (szabály: $: 2$)

#### C) Változó lépésközű sorozatok
- $1, 2, 4, 7, 11, 16, 22, \dots$ (szabály: $+1, +2, +3, +4, +5, +6, \dots$)
- $2, 4, 8, 14, 22, \dots$ (szabály: $+2, +4, +6, +8, \dots$)

### 3. Tipikus Feladatok
- Sorozat folytatása a következő 3 taggal
- Hiányzó tagok pótlása: $5, \underline{\phantom{00}}, 13, 17, \underline{\phantom{00}}, 25$ (megoldás: 9 és 21)
- Hibás tag megkeresése és javítása
- Szabály megfogalmazása szavakkal
