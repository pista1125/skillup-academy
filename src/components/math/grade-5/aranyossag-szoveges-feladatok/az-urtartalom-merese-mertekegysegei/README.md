# 2. Az űrtartalom mérése, mértékegységei

## Tananyag Áttekintés
Az űrtartalom a folyadékok, gázok vagy ömlesztett anyagok befogadására alkalmas térfogatot jelenti (edények, hordók, tartályok belső térfogata). Alapegysége a liter (l).

---

## Mértékegységek és Váltószámok

$$\text{milliliter (ml)} \xrightarrow{\cdot 10} \text{centiliter (cl)} \xrightarrow{\cdot 10} \text{deciliter (dl)} \xrightarrow{\cdot 10} \text{liter (l)} \xrightarrow{\cdot 100} \text{hektoliter (hl)}$$

### Alapvető Összefüggések
- $1\text{ cl} = 10\text{ ml}$
- $1\text{ dl} = 10\text{ cl} = 100\text{ ml}$
- $1\text{ l} = 10\text{ dl} = 100\text{ cl} = 1000\text{ ml}$
- $1\text{ hl} = 100\text{ l} = 1000\text{ dl}$

### Kapcsolat a Térfogat Mértékegységeivel
- **$1\text{ l} = 1\text{ dm}^3$** (Egy $1\text{ dm}$ élű kockába pontosan $1\text{ liter}$ víz fér.)
- **$1\text{ ml} = 1\text{ cm}^3$**
- **$1\text{ m}^3 = 1000\text{ l} = 10\text{ hl}$**
- **$1\text{ liter tiszta víz tömege}$** $+4^\circ\text{C}$-on pontosan **$1\text{ kg}$**.
