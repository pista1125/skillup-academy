# 4. Mértékegység-átváltások

## Tananyag Áttekintés
A mértékegység-átváltás során egy mennyiséget más mértékegységben fejezünk ki. A számérték változik, de maga a tényleges mennyiség ugyanakkora marad.

---

## Általános Átváltási Szabályok

### 1. Az Alapszabály
- **Nagyobb egységből kisebbe:** Szorzunk a váltószámmal.
  - $3{,}5\text{ kg} = 3{,}5 \cdot 100 = 350\text{ dkg}$
  - $2\text{ óra } 15\text{ perc} = 2 \cdot 60 + 15 = 135\text{ perc}$
- **Kisebb egységből nagyobba:** Osztunk a váltószámmal.
  - $750\text{ ml} = 750 : 100 = 7{,}5\text{ dl} = 0{,}75\text{ l}$
  - $4500\text{ kg} = 4500 : 1000 = 4{,}5\text{ t}$

### 2. Összetett Mennyiségek Felbontása és Összevonása
- **Felbontás:** $3\text{ kg } 45\text{ dkg} = 300\text{ dkg} + 45\text{ dkg} = 345\text{ dkg} = 3{,}45\text{ kg}$
- **Összevonás:** $145\text{ perc} = 2\text{ óra } 25\text{ perc}$ ($145 : 60 = 2$, maradék 25)
- **Tizedes törtek az átváltásokban:**
  - $0{,}25\text{ l} = 2{,}5\text{ dl} = 250\text{ ml}$
  - $0{,}75\text{ t} = 750\text{ kg} = 7{,}5\text{ q}$
