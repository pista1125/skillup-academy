# 1. A tömeg mérése, mértékegységei

## Tananyag Áttekintés
A tömeg a testek tehetetlenségének és súlyának alapvető mértéke. A metrikus mértékrendszerben a tömeg alapegysége a kilogramm (kg).

---

## Mértékegységek és Váltószámok

$$\text{milligramm (mg)} \xrightarrow{\cdot 1000} \text{gramm (g)} \xrightarrow{\cdot 10} \text{dekagramm (dkg)} \xrightarrow{\cdot 100} \text{kilogramm (kg)} \xrightarrow{\cdot 100} \text{mázsa (q)} \xrightarrow{\cdot 10} \text{tonna (t)}$$

### Alapvető Váltószámok
- $1\text{ g} = 1000\text{ mg}$
- $1\text{ dkg} = 10\text{ g} = 10\,000\text{ mg}$
- $1\text{ kg} = 100\text{ dkg} = 1000\text{ g}$
- $1\text{ q (mázsa)} = 100\text{ kg}$
- $1\text{ t (tonna)} = 10\text{ q} = 1000\text{ kg}$

### Gyakorlati Példák és Becslések
- Egy gombostű feje: kb. $10\text{ mg}$
- Egy postai levél: kb. $20\text{ g}$
- Egy alma: kb. $15\text{ dkg} = 150\text{ g}$
- Egy 5. osztályos diák: kb. $35\text{–}45\text{ kg}$
- Egy személygépkocsi: kb. $1{,}2\text{–}1{,}5\text{ t} = 1200\text{–}1500\text{ kg}$
