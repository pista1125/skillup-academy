# 10. Összefoglalás

## Tananyag Áttekintés
A IV. Hosszúság, terület, térfogat fejezet teljes összefoglalása, a síkbeli és térbeli mértékek rendszerezése, képletek gyors áttekintése és felkészülés a témazáró dolgozatra.

---

## Összefoglaló Képtár és Képletek

| Fogalom | Alakzat | Képlet | Fő mértékegység |
| :--- | :--- | :--- | :--- |
| **Kerület ($K$)** | Téglalap | $K = 2(a + b)$ | $\text{mm, cm, dm, m, km}$ |
| | Négyzet | $K = 4a$ | |
| **Terület ($T$)** | Téglalap | $T = a \cdot b$ | $\text{mm}^2, \text{cm}^2, \text{dm}^2, \text{m}^2, \text{a, ha, km}^2$ |
| | Négyzet | $T = a^2$ | |
| **Felszín ($A$)** | Téglatest | $A = 2(ab + ac + bc)$ | $\text{cm}^2, \text{dm}^2, \text{m}^2$ |
| | Kocka | $A = 6a^2$ | |
| **Térfogat ($V$)** | Téglatest | $V = a \cdot b \cdot c$ | $\text{cm}^3, \text{dm}^3, \text{m}^3, \text{ml, cl, dl, l, hl}$ |
| | Kocka | $V = a^3$ | |
