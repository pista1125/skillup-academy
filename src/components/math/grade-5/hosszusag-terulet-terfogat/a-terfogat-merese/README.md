# 7. A térfogat mérése

## Tananyag Áttekintés
A testek térbeli kiterjedésének (térfogatának, $V$) mérése egységkockákkal, a térfogat mértékegységei (köbmértékek) és az űrmértékek ($l, dl, cl, ml, hl$), valamint a két rendszer közötti kapcsolat ($1\text{ dm}^3 = 1\text{ liter}$).

---

## Térfogat Mértékegységek és Váltószámok

### Köbmértékek (Váltószám: $1000$)
$$\text{mm}^3 \xrightarrow{\cdot 1000} \text{cm}^3 \xrightarrow{\cdot 1000} \text{dm}^3 \xrightarrow{\cdot 1000} \text{m}^3 \xrightarrow{\cdot 1\,000\,000\,000} \text{km}^3$$

### Űrmértékek
$$\text{ml} \xrightarrow{\cdot 10} \text{cl} \xrightarrow{\cdot 10} \text{dl} \xrightarrow{\cdot 10} \text{liter (l)} \xrightarrow{\cdot 100} \text{hektoliter (hl)}$$

### A Két Rendszer Kapcsolata (Aranyszabályok)
- **$1\text{ dm}^3 = 1\text{ liter} = 10\text{ dl} = 1000\text{ ml}$**
- **$1\text{ cm}^3 = 1\text{ ml} = 0{,}1\text{ cl}$**
- **$1\text{ m}^3 = 1000\text{ dm}^3 = 1000\text{ liter} = 10\text{ hl}$**
