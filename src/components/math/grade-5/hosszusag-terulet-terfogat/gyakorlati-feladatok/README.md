# 9. Gyakorlati feladatok

## Tananyag Áttekintés
Összetett gyakorlati és szöveges feladatok a kerület, terület, felszín és térfogat témaköreiből (szoba burkolása, kerítésépítés, dobozok csomagolása, tartályok feltöltése).

---

## Tipikus Feladattípusok

1. **Kerítésépítés / Keretkészítés:**
   - Kerületszámítás ($K = 2a + 2b$ vagy $4a$), kapuk levonása.

2. **Festés, Parkettázás, Csempézés:**
   - Területszámítás ($T = a \cdot b$), csempék darabszáma, hulladékszázalék.

3. **Dobozok csomagolása és festése:**
   - Felszínszámítás ($A = 2(ab+ac+bc)$ vagy $6a^2$).

4. **Folyadéktárolók és akváriumok:**
   - Térfogat számítása köbdeciméterben és átváltása literbe ($V = abc$).
