# IV. Hosszúság, terület, térfogat (5. osztály)
- Hosszúság mértékegységei és átváltása, alakzatok kerülete
- Terület fogalma, mértékegységei és átváltása, téglalap és négyzet területe
- Testek felszíne (kocka, téglatest felszíne és hálója)
- Térfogat és űrtartalom mértékegységei, kocka és téglatest térfogata
