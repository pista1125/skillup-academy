# 3. A terület mérése

## Tananyag Áttekintés
A síkidomok kiterjedésének (területének, $T$) mérése egységnégyzetekkel, a terület mértékegységeinek rendszere, négyzetes váltószámok ($100$), valamint mezőgazdasági mértékegységek ($a, ha$).

---

## Terület Mértékegységek és Váltószámok

$$\text{mm}^2 \xrightarrow{\cdot 100} \text{cm}^2 \xrightarrow{\cdot 100} \text{dm}^2 \xrightarrow{\cdot 100} \text{m}^2 \xrightarrow{\cdot 100} \text{ár (a)} \xrightarrow{\cdot 100} \text{hektár (ha)} \xrightarrow{\cdot 100} \text{km}^2$$

### Alapvető Összefüggések
- $1\text{ cm}^2 = 10\text{ mm} \times 10\text{ mm} = 100\text{ mm}^2$
- $1\text{ dm}^2 = 10\text{ cm} \times 10\text{ cm} = 100\text{ cm}^2$
- $1\text{ m}^2 = 10\text{ dm} \times 10\text{ dm} = 100\text{ dm}^2 = 10\,000\text{ cm}^2$
- $1\text{ a (ár)} = 100\text{ m}^2$ (egy $10\text{ m} \times 10\text{ m}$-es négyzet területe)
- $1\text{ ha (hektár)} = 100\text{ a} = 10\,000\text{ m}^2$ (egy $100\text{ m} \times 100\text{ m}$-es négyzet területe)
- $1\text{ km}^2 = 100\text{ ha} = 1\,000\,000\text{ m}^2$
