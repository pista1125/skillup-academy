# 4. A természetes számok helyesírása

## Tananyag Áttekintés
A számok betűvel történő leírásának magyar helyesírási szabályai ($2000$-es határszabály, kötőjelezés, sorszámnevek írása ponttal).

---

## Helyesírási Szabályok

### 1. Kétezerig egybeírjuk
- $2000$-ig minden számot egybeírunk:
  - $15$ = *tizenöt*
  - $482$ = *négyszáznyolcvankettő*
  - $1999$ = *ezerkilencszázkilencvenkilenc*
  - $2000$ = *kétezer*

### 2. Kétezer felett a hármas csoportosítás szerint kötőjelezünk
- A $2000$-nél nagyobb összetett számokat a hármas számcsoportok (osztályok) határán kötőjellel tagoljuk:
  - $2001$ = *kétezer-egy*
  - $45\,320$ = *negyvenötezer-háromszázhúsz*
  - $1\,250\,000$ = *egymillió-kétszázötvenezer*
- A kerek ezresek, milliók egybeíródnak (pl. *négyezer*, *ötmillió*).

### 3. Sorszámnevek és Dátumok
- Sorszámnevek után pontot teszünk: $5.$ = *ötödik*.
- Dátumok írásakor az év és a nap után pontot teszünk.
