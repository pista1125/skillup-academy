# 15. Egész számok összeadása és kivonása

## Tananyag Áttekintés
Pozitív és negatív egész számok összeadása és kivonása a számegyenesen lépkedve, az előjelek és műveleti jelek találkozásának szabályai ($++$, $+-$, $-+$, $--$), valamint a pénzügyi (nyereség/tartozás) modell.

---

## Főbb Szabályok és Összefüggések

### 1. Előjelek Találkozása
- $a + (+b) = a + b$ (pozitív hozzáadása $\to$ jobbra lépünk)
- $a + (-b) = a - b$ (negatív hozzáadása / adósság növelése $\to$ balra lépünk)
- $a - (+b) = a - b$ (pozitív elvétele $\to$ balra lépünk)
- $a - (-b) = a + b$ (negatív elvétele / adósság elengedése $\to$ jobbra lépünk)

### 2. Azonos és Különböző Előjelű Számok Összeadása
- **Azonos előjelűek:** Összeadjuk az abszolút értékeket, és megtartjuk a közös előjelet:
  $$(-3) + (-5) = -8$$
- **Különböző előjelűek:** A nagyobb abszolút értékűből kivonjuk a kisebbet, és a nagyobb előjelét kapja az eredmény:
  $$(+7) + (-10) = -(10 - 7) = -3$$
