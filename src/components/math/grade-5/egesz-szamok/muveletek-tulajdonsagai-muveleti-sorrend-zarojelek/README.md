# 12. Műveletek tulajdonságai, műveleti sorrend, zárójelek

## Tananyag Áttekintés
A négy alapművelet hierarchiája (műveleti sorrend), zárójelek szerepe és típusai (kerek, szögletes, kapcsos), valamint az elméleti műveleti tulajdonságok (kommutativitás, asszociativitás, disztributivitás) alkalmazása a számolás megkönnyítésére.

---

## A Műveleti Sorrend Szabályai

### 1. Elsőbbségi Szabályok
1. **Zárójeles kifejezések legelőször:** A legbelső zárójeltől haladunk kifelé $( \dots ) \to [ \dots ] \to \{ \dots \}$.
2. **Magasabb rendű műveletek:** Szorzás és osztás (balról jobbra a felírás sorrendjében).
3. **Alacsonyabb rendű műveletek:** Összeadás és kivonás (balról jobbra a felírás sorrendjében).

### 2. Zárójelfelbontás és Kiemelés
- Ha a zárójel előtt szorzás áll: $c \cdot (a + b) = c \cdot a + c \cdot b$.
- Közös tényező kiemelése a számolás egyszerűsítésére: $a \cdot c + b \cdot c = (a + b) \cdot c$.
