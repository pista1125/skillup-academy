# 3. Adatgyűjtés, az adatok ábrázolása

## Tananyag Áttekintés
A statisztikai kutatás lépései: a cél meghatározása $\rightarrow$ adatgyűjtés $\rightarrow$ rendszerezés $\rightarrow$ ábrázolás $\rightarrow$ következtetések levonása.

---

## Az Adatfeldolgozás Lépései

### 1. Adatgyűjtési Módszerek
- **Megfigyelés és mérés:** Hőmérséklet mérése óránként, növények növekedésének mérése naponta.
- **Kérdőíves felmérés / Szavazás:** Kedvenc tantárgy, házi kedvencek száma.
- **Számlálás:** Elhaladó járművek száma típus szerint.

### 2. Rendszerezés: Strigulázás és Gyakoriság
- **Vonalkázás (strigulázás):** Négy függőleges vonal után az ötödik áthúzza őket ($\cancel{||||}$), így ötös csoportokban könnyű összesíteni.
- **Gyakorisági táblázat:** Megmutatja, hogy az egyes adatok hányszor fordulnak elő a mintában.

| Kedvenc gyümölcs | Strigulák | Gyakoriság (fő) |
| :--- | :--- | :---: |
| Alma | $\cancel{||||} \ ||$ | 7 |
| Banán | $\cancel{||||} \ \cancel{||||}$ | 10 |
| Narancs | $||||$ | 4 |
| Eper | $\cancel{||||}$ | 5 |
| **Összesen** | | **26** |
