# VI. Egyenletek (7. osztály)

Ebben a témakörben találhatók a 7. osztályos matematika tankönyv (**OH-MAT07TA**) hatodik fejezetének anyagai, leckéi és feladatai.

## A fejezet altémái (leckéi):

1. [**1. Egyenletmegoldási módszerek: próbálgatás és lebontogatás**](./egyenletmegoldasi-modszerek-probalgatas-es-lebontogatas/README.md)
   - Egyenlet fogalma, alaphalmaz, megoldáshalmaz, szisztematikus próbálgatás és a lebontogatás módszere.
2. [**2. A mérlegelv**](./a-merlegelv/README.md)
   - A kétkarú mérleg modellje, ekvivalens egyenlet-átalakítások szabályai és az ellenőrzés.
3. [**3. Egyenletek megoldása mérlegelvvel**](./egyenletek-megoldasa-merlegelvvel/README.md)
   - Elsőfokú egyenletek megoldási algoritmusa: zárójelfelbontás, összevonás, rendezés és törtek eltüntetése.
4. [**4. Szöveges feladatok megoldása egyenlettel**](./szoveges-feladatok-megoldasa-egyenlettel/README.md)
   - Az 5 lépéses modell: ismeretlen felvétele, egyenlet felállítása, mérlegelv, szöveges ellenőrzés és válasz.
5. [**5. Összefoglalás**](./osszefoglalas/README.md)
   - Fejezeti átfogó összefoglalás, szabálytár és módszertani rendszerezés.
