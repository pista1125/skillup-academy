# 4. A terület és a térfogat mértékegységei (7. osztály)

## Tananyag Áttekintés
A terület- és térfogatmérés egységei, váltószámai, mezőgazdasági mértékegységek (ár, hektár) és az űrmérték–térfogat kapcsolatok.

---

## Főbb Mértékegység-rendszerek és Átváltások

### 1. Területmértékegységek (Váltószám: 100)

$$\text{km}^2 \xrightarrow{\cdot 100} \text{ha} \xrightarrow{\cdot 100} \text{a} \xrightarrow{\cdot 100} \text{m}^2 \xrightarrow{\cdot 100} \text{dm}^2 \xrightarrow{\cdot 100} \text{cm}^2 \xrightarrow{\cdot 100} \text{mm}^2$$

- $1\text{ km}^2 = 100\text{ ha} = 10\ 000\text{ a} = 1\ 000\ 000\text{ m}^2$
- $1\text{ ha (hektár)} = 100\text{ a} = 10\ 000\text{ m}^2$ ($100\text{ m} \times 100\text{ m}$-es négyzet területe)
- $1\text{ a (ár)} = 100\text{ m}^2$ ($10\text{ m} \times 10\text{ m}$-es négyzet területe)
- $1\text{ m}^2 = 100\text{ dm}^2 = 10\ 000\text{ cm}^2 = 1\ 000\ 000\text{ mm}^2$

---

### 2. Térfogatmértékegységek (Váltószám: 1000)

$$\text{m}^3 \xrightarrow{\cdot 1000} \text{dm}^3 \xrightarrow{\cdot 1000} \text{cm}^3 \xrightarrow{\cdot 1000} \text{mm}^3$$

- $1\text{ m}^3 = 1\ 000\text{ dm}^3 = 1\ 000\ 000\text{ cm}^3 = 1\ 000\ 000\ 000\text{ mm}^3$
- $1\text{ dm}^3 = 1\ 000\text{ cm}^3$
- $1\text{ cm}^3 = 1\ 000\text{ mm}^3$

---

### 3. Az Űrmérték és Térfogat Kapcsolata
> [!NOTE]
> **Alapvető azonosság:**
> $$1\text{ dm}^3 = 1\text{ liter (l)}$$
> $$1\text{ cm}^3 = 1\text{ milliliter (ml)}$$
> $$1\text{ m}^3 = 1\ 000\text{ liter} = 10\text{ hektoliter (hl)}$$
