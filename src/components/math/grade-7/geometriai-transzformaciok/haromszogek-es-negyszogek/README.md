# 3. Háromszögek és négyszögek (7. osztály)

## Tananyag Áttekintés
A síkbeli sokszögek alapvető képviselői: a háromszögek és négyszögek csoportosítása, belső és külső szögeinek összefüggései, valamint az oldalak és szögek közötti kapcsolatok.

---

## Főbb Ismeretek és Fogalmak

### 1. Háromszögek Csoportosítása és Tulajdonságai

#### A) Szögek szerint:
- **Hegyesszögű háromszög:** Mindhárom belső szöge hegyesszög ($< 90^\circ$).
- **Derékszögű háromszög:** Pontosan egy derékszöge ($90^\circ$) van. A derékszöggel szemközti oldal az **átfogó** ($c$), a derékszöget bezáró oldalak a **befogók** ($a, b$).
- **Tompaszögű háromszög:** Pontosan egy tompaszöge ($> 90^\circ$) van.

#### B) Oldalak szerint:
- **Általános (különböző oldalú) háromszög:** Mindhárom oldala különböző hosszúságú.
- **Egyenlő szárú háromszög:** Legalább két oldala egyenlő ($a = b$, szárak; harmadik oldal: alap).
  - Alapon fekvő szögei egyenlők ($\alpha = \beta$).
  - Tengelyesen szimmetrikus (az alaphoz tartozó magasságvonal a szimmetriatengely).
- **Egyenlő oldalú (szabályos) háromszög:** Mindhárom oldala egyenlő ($a = b = c$).
  - Minden belső szöge pontosan $60^\circ$.
  - 3 szimmetriatengellyel rendelkezik.

---

### 2. Szögek Összefüggései Háromszögben
- **Belső szögek összege:** $\alpha + \beta + \gamma = 180^\circ$.
- **Külső szögek összege:** $\alpha' + \beta' + \gamma' = 360^\circ$.
- **Külső szög tétele:** Bármely külső szög egyenlő a két nem mellette fekvő belső szög összegével:
  $$\alpha' = \beta + \gamma, \quad \beta' = \alpha + \gamma, \quad \gamma' = \alpha + \beta$$
- **Háromszög-egyenlőtlenség:** Bármely két oldal összege nagyobb a harmadik oldalnál:
  $$a + b > c, \quad a + c > b, \quad b + c > a$$
- **Oldalak és szögek kapcsolata:** Nagyobb oldallal szemben mindig nagyobb szög fekszik, egyenlő oldalakkal szemben egyenlő szögek fekszenek.

---

### 3. Négyszögek
- **Definíció:** Négy oldal által határolt zárt síkidom.
- **Belső szögek összege:** Bármely konvex négyszögben a belső szögek összege $360^\circ$:
  $$\alpha + \beta + \gamma + \delta = 360^\circ$$
- **Külső szögek összege:** Szintén $360^\circ$.
- **Átlók száma:** Bármely négyszögnek $\frac{4 \cdot (4-3)}{2} = 2$ átlója van.

---

### 4. Négyszögek Családfája (Hierarchiája)
- **Trapéz:** Legalább egy párhuzamos oldalpárral rendelkező négyszög.
- **Paralelogramma:** Két pár párhuzamos oldallal rendelkező négyszög (a trapéz speciális esete).
  - *Téglalap:* Egyenlő szögű paralelogramma (minden szöge $90^\circ$).
  - *Rombusz:* Egyenlő oldalú paralelogramma (minden oldala $a$).
  - *Négyzet:* Szabályos négyszög (egyszerre téglalap és rombusz).
- **Deltoid:** Két-két szomszédos oldala egyenlő hosszúságú négyszög.
- **Húr- és érintőnégyszögek:** Köré írható, illetve beírható körrel rendelkező négyszögek.
