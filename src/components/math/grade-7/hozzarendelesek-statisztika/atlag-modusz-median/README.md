# 4. Átlag, módusz, medián (7. osztály)

## Tananyag Áttekintés
A statisztikai adatelemzés legfontosabb helyzetmutatói és középértékei: számtani közép (átlag), módusz, medián és terjedelem.

---

## A Négy Fő Statisztikai Mutató

### 1. Számtani Közép (Átlag - $\overline{x}$)
Az adatok összegének és az adatok számának hányadosa:

$$\overline{x} = \frac{x_1 + x_2 + x_3 + \dots + x_n}{n}$$

> [!NOTE]
> *Példa:* Jegyek: $4, 5, 3, 5, 4, 3, 5 \implies \overline{x} = \frac{4+5+3+5+4+3+5}{7} = \frac{29}{7} \approx 4{,}14$.

---

### 2. Módusz ($Mo$ - Leggyakoribb Érték)
A sokaságban **a legtöbbször előforduló adat**.
- Egy adatsornak lehet **1 módusza** (pl. a fenti jegyeknél a $5$-ös, mert 3-szor szerepel).
- Lehet **több módusza** (ha több érték azonos maximális gyakorisággal szerepel).
- Ha minden adat pontosan egyszer szerepel, nincs kitüntetett módusz.

---

### 3. Medián ($Me$ - Középső Érték)
Az adatok **növekvő nagyságrendbe állítása utáni középső elem**:
1. **Ha az adatok száma ($n$) PÁRATLAN:**
   A pontosan középen álló elem a medián.
   - *Példa ($n=7$):* $3, 3, 4, \mathbf{4}, 5, 5, 5 \implies Me = \mathbf{4}$.
2. **Ha az adatok száma ($n$) PÁROS:**
   A két középső adat számtani közepe a medián.
   - *Példa ($n=6$):* $2, 3, \mathbf{4, 6}, 7, 8 \implies Me = \frac{4 + 6}{2} = \mathbf{5}$.

---

### 4. Terjedelem ($R$)
A legnagyobb ($x_{\max}$) és legkisebb ($x_{\min}$) adat különbsége:
$$R = x_{\max} - x_{\min}$$
- *Példa:* $3, 3, 4, 4, 5, 5, 5 \implies R = 5 - 3 = 2$.
