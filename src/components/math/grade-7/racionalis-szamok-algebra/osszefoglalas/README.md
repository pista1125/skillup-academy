# 9. Összefoglalás (7. osztály)

## Fejezeti Összefoglalás: II. Racionális számok, betűs kifejezések

Ebben a leckében áttekintjük a 7. osztályos racionális számok és betűs kifejezések fejezet összes lényeges szabályát, műveleti eljárását és fogalmát.

---

## Áttekintő Képlet- és Szabálytár

### 1. Racionális számok ($\mathbb{Q}$)
- **Forma:** $\frac{a}{b}$ ($a, b \in \mathbb{Z}, b \neq 0$).
- **Műveletek:**
  - Összeadás/kivonás: közös nevezőre hozással ($\frac{a}{c} \pm \frac{b}{c} = \frac{a \pm b}{c}$).
  - Szorzás: számlálót számlálóval, nevezőt nevezővel ($\frac{a}{b} \cdot \frac{c}{d} = \frac{ac}{bd}$).
  - Osztás: szorzás a reciprokkal ($\frac{a}{b} : \frac{c}{d} = \frac{a}{b} \cdot \frac{d}{c}$).
- **Előjelek:** Azonos előjelek szorzata/hányadosa $+$, különböző előjeleké $-$.

### 2. Betűs kifejezések és algebra
- **Egynemű tagok összevonása:** $ax + bx = (a+b)x$.
- **Helyettesítési érték:** Változók helyére konkrét számok behelyettesítése és kiszámítása.
- **Zárójelfelbontás (disztributivitás):** $a(b + c) = ab + ac$.
- **Közös tényező kiemelése:** $ab + ac = a(b + c)$.
