# 5. Összetett műveletek, zárójelfelbontás (7. osztály)

## Tananyag Áttekintés
Többlépéses racionális számolási feladatok megoldása a helyes műveleti sorrend és a zárójelek szigorú szabályainak betartásával.

---

## Főbb Szabályok

### 1. A műveletek sorrendje (PEMDAS / KÖSZO)
1. **Zárójeles kifejezések** kiszámítása (belülről kifelé haladva: kerek $( )$, szögletes $[ ]$, kapcsos $\{ \}$).
2. **Magasabb rendű műveletek:** hatványozás és gyökvonás.
3. **Közepes rendű műveletek:** szorzás és osztás (balról jobbra a felbukkanás sorrendjében).
4. **Alacsonyabb rendű műveletek:** összeadás és kivonás (balról jobbra haladva).

### 2. Zárójelek elhagyása és felbontása racionális számoknál
- **Pluszjel áll a zárójel előtt:** A zárójel egyszerűen elhagyható, a benne lévő tagok előjele változatlan marad:
  $$+(a - b + c) = a - b + c$$
- **Mínuszjel áll a zárójel előtt:** A zárójel elhagyásakor a zárójelen belüli minden tag előjele az ellenkezőjére változik:
  $$-(a - b + c) = -a + b - c$$

### 3. Törtvonal mint zárójel
- A törtvonal egyszerre jelöl osztást és zárójelet: a számlálóban és a nevezőben lévő műveleteket el kell végezni a tört egyszerűsítése vagy osztása előtt:
  $$\frac{a + b}{c - d} = (a + b) : (c - d)$$
