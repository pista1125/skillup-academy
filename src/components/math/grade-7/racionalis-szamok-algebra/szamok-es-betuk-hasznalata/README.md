# 6. Számok és betűk használata (7. osztály)

## Tananyag Áttekintés
A betűs kifejezések (algebra) segítségével általános matematikai törvényszerűségeket, képleteket fogalmazhatunk meg, és ismeretlen mennyiségeket jelölhetünk.

---

## Főbb Fogalmak

### 1. Változók és kifejezések
- **Változó (ismeretlen):** Olyan betű (pl. $x, y, a, b, n$), amely egy halmaz bármely elemét helyettesítheti.
- **Konstans (állandó):** Rögzített konkrét számérték (pl. $5, -\frac{2}{3}, \pi$).
- **Algebrai kifejezés:** Számok, betűk és műveleti jelek véges összekapcsolása (pl. $3x + 2y - 7$).
- **Egytagú kifejezés (monom):** Számok és betűk szorzata (pl. $5x, -3a^2b, \frac{2}{3}y$).
- **Együttható:** Az algebrai tagban szereplő számtényező. Ha nincs kiírva szám, az együttható $1$ vagy $-1$ ($x = 1x$, $-x = -1x$).

### 2. Szöveges kifejezések lefordítása algebrai nyelvre
- „Egy szám $5$-tel nagyobb”: $x + 5$
- „Egy szám 3-szorosa”: $3x$
- „Egy szám felének és 4-nek a különbsége”: $\frac{x}{2} - 4$
- „Két szám összegének négyzete”: $(a + b)^2$
- „Két szám négyzetének összege”: $a^2 + b^2$
