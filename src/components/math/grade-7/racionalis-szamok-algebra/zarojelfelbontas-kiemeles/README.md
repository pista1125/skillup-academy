# 8. Zárójelfelbontás, kiemelés (7. osztály)

## Tananyag Áttekintés
A zárójelfelbontás és a közös tényező kiemelése egymás inverz (fordított) algebrai műveletei. Alapjuk a szorzás összeadásra és kivonásra vonatkozó disztributív (széttagolási) tulajdonsága.

---

## Főbb Szabályok és Példák

### 1. Egytagú kifejezéssel való beszorzás (Zárójelfelbontás)
- A zárójelen kívüli tényezővel a zárójel **minden egyes tagját** megszorozzuk, figyelembe véve az előjeleket:
  $$a(b + c) = ab + ac$$
  $$a(b - c) = ab - ac$$
- **Negatív tényezővel való szorzás:**
  $$-3(2x - 5y + 1) = -6x + 15y - 3$$

### 2. Közös tényező kiemelése a zárójel elé
- A kifejezés minden tagjában megtalálható közös számtényezőt és/vagy betűtényezőt a zárójel elé írjuk, a tagok megmaradt részét pedig zárójelbe tesszük:
  $$ab + ac = a(b + c)$$
- **Példák:**
  - $6x + 9 = 3(2x + 3)$
  - $4a^2 - 6ab = 2a(2a - 3b)$
  - $-5x - 10y = -5(x + 2y)$
- **Ellenőrzés:** Beszorzással mindig vissza kell kapnunk az eredeti kifejezést!
