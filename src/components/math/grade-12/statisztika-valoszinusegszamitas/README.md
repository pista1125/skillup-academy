# III. Statisztika, valószínűségszámítás (12. osztály)
- Valószínűségszámítási ismeretek összefoglalása és elmélyítése
- Feltételes valószínűség, szorzási szabály és Bayes-tétel alkalmazása összetett problémákban
- Binomiális eloszlás részletes vizsgálata: P(X = k) = (n alatt k) · p^k · (1 - p)^(n - k)
- Diszkrét valószínűségi változók várható értéke E(X) és szórása D(X)
- Statisztikai elemzések, reprezentatív minták, adatok vizualizációja (hisztogram, dobozdiagram)
- Statisztikai és valószínűségi feladatok az érettségi vizsgán
