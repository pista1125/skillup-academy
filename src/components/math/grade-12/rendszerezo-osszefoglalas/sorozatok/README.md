# 6. Sorozatok – rendszerező összefoglalás (138–143. oldal)

A magyar Oktatási Hivatal hivatalos tankönyve (`OH-MAT12TA`, Matematika 12., Rendszerező összefoglalás, „Függvények, sorozatok” blokk – Sorozatok rész, 138–143. oldal) alapján kidolgozott érettségi ismétlő modul. A diákzónában ez a IV. Rendszerező összefoglalás fejezet **6.** leckéje.

---

## 🎯 Tananyag Áttekintés

A 9–12. évfolyam sorozatos tananyaga: a számsorozat fogalma és megadási módjai, a számtani és a mértani sorozat, az n-edik tag és az első n tag összege, valamint a pénzügyi alkalmazások (kamatos kamat, gyűjtőjáradék, állandó törlesztőrészlet).

---

## 📐 Fogalmak, tételek, módszerek (tankönyvi táblázat)

- **D – Számsorozat:** a pozitív egészek halmazán értelmezett (valós értékű) függvény; jele {aₙ}.
- **M – Megadás:** körülírással, képlettel (általános tag), rekurzív módon. Pl. 2; 4; 6; 8; …: „pozitív párosok növekvő sorozata”, aₙ = 2n, a₁ = 2 és aₙ₊₁ = aₙ + 2.
- **D – Számtani sorozat:** aₙ − aₙ₋₁ = d állandó (differencia). **T:** aₙ = a₁ + (n − 1)d; Sₙ = (a₁ + aₙ)/2 · n = (2a₁ + (n − 1)d)/2 · n.
- **D – Mértani sorozat:** aₙ/aₙ₋₁ = q ≠ 0 állandó (kvóciens). **T:** aₙ = a₁ · qⁿ⁻¹; Sₙ = a₁ · (qⁿ − 1)/(q − 1), ha q ≠ 1; Sₙ = n · a₁, ha q = 1.
- **M – Kamatos kamat:** Aₙ = A₀ · (1 + p/100)ⁿ; a kamattényező a kamatozási időszakra (havi, napi) vonatkozzon.
- **M – Gyűjtőjáradék:** egyenlő időközönként azonos összeg befizetése ugyanarra a számlára.
- **M – Állandó törlesztőrészlet:** a hitelt azonos időközönként ugyanakkora összeggel fizetjük vissza.

### Kidolgozott feladatok
1. **Mértani sorozat, a₁ = 6, a₂ = 12:** q = 2, aₙ = 3 · 2ⁿ; a₁₀ = 3072; S₃₀ = 6 442 450 938 ≈ 6,44 · 10⁹; Sₙ > 10⁷ ⇒ n > 20,67, legalább 21 tag.
2. **Nyomdagép:** 42 millió Ft, évente 90%-ára csökken, +300 000 Ft karbantartás; 8 év múlva 42 · 10⁶ · 0,9⁸ + 300 000 · (0,9⁸ − 1)/(0,9 − 1) ≈ 19 788 221 ≈ 19,8 millió Ft.
3. **Két kerékpáros (189 km):** a₁ = 21, d = −1,4; b₁ = 18, d = 2. a) a₅ = 15,4 km, b₃ = 22 km. b) 0,3n² + 34,7n − 219 = 0 ⇒ n = 6: 18 órakor, A-tól 105 km-re (B útja 84 km).

### Feladatok (a modulban feldolgozva)
- **I. rész:** beiktatás 2 és 54 közé (d = 52/3); a₃ + a₄ + a₅ = 123 ⇒ a₆ = 51; a₁ = 7, d = −5/6 ⇒ a₂₀ = −53/6, S₂₀ = −55/3; a₂ = −1/9, q = 3 ⇒ a₅ = −3; S/M/E besorolás (6n, 6, n⁶, 6ⁿ, 6 + n, n − 6); a₃ = −7, a₅ = −112 ⇒ q = ±4; kétjegyű páratlanok összege 2475; 50. szám ≡ 3 (mod 7): 346; rekurzió −9; 4; −5; −1; −6; −7; −13; √5; √20; √45 számtani (d = √5); 2 millió Ft 8%-kal 2 év: 2 332 800 Ft.
- **Ráadás (1893):** a₃ = 50, a₇ = 31 250 ⇒ q = ±5, a₁ = 2; q = 5-re a₁₀ = 3 906 250, S₁₀ = 4 882 812.
- **II. rész:** cirkusz 1860 hely, 11 tálca (66 pohár), 2 092 500 · 1,01¹² ≈ 2 357 881 Ft; a₃ = −2, a₆ = 250 ⇒ q = −5, a₁₀ = 156 250; 32 millió/1,07¹⁰ ≈ 16,27 millió Ft; 1,06ⁿ = 1,5 ⇒ 7 év; 2^{1/20} ⇒ ≈ 3,53%; gyűjtőjáradék ≈ 9 507 364 Ft; a₁ = 7, d = −9: −472 nem tag, S₃₃ < −4300, Σ|aₙ| = 3719; szakaszok: n = 10, leghosszabb 29,3 cm; S₁₀ : (S₂₀ − S₁₀) = −1/4; lottó: 5 · 10⁶/1,06⁵ ≈ 3,74 millió, 5 · 10⁶ · 1,08⁵ ≈ 7,35 millió Ft; törlesztőrészlet ≈ 463 003 Ft.
