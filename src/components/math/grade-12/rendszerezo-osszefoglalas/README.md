# IV. Rendszerező összefoglalás (12. osztály)
- A 9–12. évfolyam teljes középiskolai matematika tananyagának átfogó, rendszerező áttekintése:
  - Halmazok, logika, kombinatorika, gráfelmélet
  - Számelmélet, algebrai kifejezések, egyenletek, egyenlőtlenségek, egyenletrendszerek
  - Függvénytan és analízis alapok (függvényjellemzés, sorozatok)
  - Síkgeometria, koordinátageometria, trigonometria és térgeometria
  - Valószínűségszámítás és leíró statisztika
- Tematikus érettségi típusfeladatok, próbaérettségi feladatsorok
- Feladatmegoldási stratégiák, vizsgarutin és időgazdálkodás
