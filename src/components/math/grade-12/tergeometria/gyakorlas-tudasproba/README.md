# 21. Gyakorlás, tudáspróba (21. lecke)

## Tananyag Áttekintés
A teljes 12. osztályos térgeometria fejezet átfogó összefoglalása, képlettára és fejezetzáró tudáspróbája középszintű és emelt szintű érettségi típusfeladatokkal.

---

## Teljes Térgeometriai Képlettár

| Test | Felszín ($A$) | Térfogat ($V$) | Fő összefüggés / paraméter |
|---|---|---|---|
| **Kocka** | $6a^2$ | $a^3$ | Testátló: $d = a\sqrt{3}$ |
| **Téglatest** | $2(ab + bc + ac)$ | $abc$ | Testátló: $d = \sqrt{a^2+b^2+c^2}$ |
| **Hasáb** | $2T_a + T_p$ ($T_p = K_a m$) | $T_a \cdot m$ | Cavalieri-elv érvényes |
| **Henger** | $2r\pi(r + m)$ | $r^2\pi \cdot m$ | Palást: $T_p = 2r\pi m$ |
| **Gömb** | $4R^2\pi$ | $\frac{4}{3}R^3\pi$ | Főkör területe: $R^2\pi$ |
| **Gúla** | $T_a + T_p$ | $\frac{T_a \cdot m}{3}$ | Szabályos: $T_p = \frac{K_a m_o}{2}$ |
| **Kúp** | $r\pi(r + a)$ | $\frac{r^2\pi \cdot m}{3}$ | $a^2 = r^2 + m^2$, $\alpha = \frac{r}{a}360^\circ$ |
| **Csonkagúla** | $T_A + T_F + T_p$ | $\frac{m}{3}(T_A + \sqrt{T_A T_F} + T_F)$ | $T_p$: trapézok összege |
| **Csonkakúp** | $\pi[R^2 + r^2 + (R+r)a]$ | $\frac{m\pi}{3}(R^2 + Rr + r^2)$ | $a = \sqrt{m^2 + (R-r)^2}$ |

## Önértékelő Kérdések a Tudáspróbához

1. Hogyan határozható meg két kitérő egyenes távolsága és hajlásszöge?
2. Milyen arányban változik egy test felszíne és térfogata, ha méreteit háromszorosára növeljük?
3. Hogyan bizonyítható a Cavalieri-elv segítségével a gömb térfogatképlete?
4. Milyen síkidom a forgáskúp kiterített palástja, és hogyan számítható ki a középponti szöge?
5. Milyen összefüggés van a csonkakúp alkotója, magassága és a két alapkör sugara között?
