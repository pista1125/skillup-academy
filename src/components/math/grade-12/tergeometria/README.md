# I. Térgeometria (12. osztály)
- Térelemek (pontok, egyenesek, síkok) kölcsönös helyzete a térben, kitérő egyenesek
- Egyenes és sík hajlásszöge, két sík hajlásszöge
- Hasábok, hengerek felszíne és térfogata
- Gúlák, kúpok felszíne és térfogata
- Csonka gúlák, csonka kúpok felszíne és térfogata
- A gömb felszíne és térfogata, gömbi síkmetszetek
- Szabályos testek (platói testek) és az Euler-féle poliédertétel: c + l - e = 2
- Összetett és gyakorlati térgeometriai modellezési feladatok
