# 3. Az egész számok osztása

## Tananyag Áttekintés
Egész számok osztásának elmélete, előjelszabályok, és a nullával való osztás tilalma.

---

## Főbb Ismeretek

### 1. Előjelszabályok az Osztásnál
Az előjelszabályok pontosan megegyeznek a szorzásnál megismert szabályokkal:
- **Azonos előjelű számok hányadosa pozitív ($+$):**
  - $(+) : (+) = (+)$ $\rightarrow (+15) : (+3) = +5$
  - $(-) : (-) = (+)$ $\rightarrow (-15) : (-3) = +5$
- **Különböző előjelű számok hányadosa negatív ($-$):**
  - $(+) : (-) = (-)$ $\rightarrow (+15) : (-3) = -5$
  - $(-) : (+) = (-)$ $\rightarrow (-15) : (+3) = -5$

### 2. Fontos Szabályok
- **Nullával nem osztunk!** A nullával való osztás matematikailag nincs értelmezve.
- $0$-t bármely nem nulla számmal osztva az eredmény $0$: $0 : a = 0$ ($a \neq 0$).
- Bármely számot $1$-gyel osztva önmagát kapjuk: $a : 1 = a$.
- Bármely számot $(-1)$-gyel osztva az ellentettjét kapjuk: $a : (-1) = -a$.
