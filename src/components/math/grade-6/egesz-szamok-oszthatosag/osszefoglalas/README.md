# 14. Összefoglalás

## Tananyag Áttekintés
Az I. Egész számok, oszthatóság fejezet átfogó rendszerezése, elméleti összefoglalása és felkészülés a témazáró dolgozatra.

---

## A Fejezet Főbb Témakörei

1. **Egész számok és műveletek:**
   - Negatív számok a számegyenesen, ellentett, abszolút érték.
   - Összeadás, kivonás, szorzás, osztás előjelszabályai.
2. **Kombinatorikai alapok:**
   - Esetek összeszámolása, faszerkezet, szorzási szabály.
3. **Oszthatóság elmélete:**
   - Osztó, többszörös, maradékos osztás ($a = b \cdot q + r$).
   - Oszthatósági szabályok (2, 5, 10, 3, 9, 4, 100 és összetett szabályok: 6, 12, 15, stb.).
4. **Prímszámok és felbontás:**
   - Prímszámok, összetett számok, számelmélet alaptétele.
   - Kanonikus alak felírása, osztók számának kiszámítása.
5. **Közös osztók és többszörösök:**
   - Legnagyobb közös osztó ($\text{LKÖ}$) és legkisebb közös többszörös ($\text{LKKT}$) meghatározása prímfelbontással.
   - Relatív prímek, alkalmazás törteknél és szöveges feladatoknál.
