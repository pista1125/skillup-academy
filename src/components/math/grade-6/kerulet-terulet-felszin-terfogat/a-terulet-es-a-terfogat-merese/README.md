# 3. A terület és a térfogat mérése

## Tananyag Áttekintés
A terület és térfogat mérésének szemléletes alapjai (egységnégyzetek és egységkockák számlálása), a terület ($100$-as) és a térfogat ($1000$-es) mértékegységeinek rendszere és átváltásai, kapcsolat az űrtartalommal.

---

## Mértékegységrendszerek és Váltószámok

### 1. Területmértékek ($100$-as váltószám)
- **Alapmértékegység:** négyzetméter ($\text{m}^2$)
- **Váltószámok:**
  $$1\text{ km}^2 = 100\text{ ha (hektár)} = 1\,000\,000\text{ m}^2$$
  $$1\text{ ha} = 100\text{ a (ár)} = 10\,000\text{ m}^2$$
  $$1\text{ a} = 100\text{ m}^2$$
  $$1\text{ m}^2 = 100\text{ dm}^2 = 10\,000\text{ cm}^2 = 1\,000\,000\text{ mm}^2$$
  $$1\text{ dm}^2 = 100\text{ cm}^2$$
  $$1\text{ cm}^2 = 100\text{ mm}^2$$

### 2. Térfogat- és Űrmértékek ($1000$-es váltószám)
- **Alapmértékegység:** köbméter ($\text{m}^3$) és liter ($\text{l}$)
- **Fontos azonosítások:**
  $$1\text{ dm}^3 = 1\text{ liter (l)}$$
  $$1\text{ cm}^3 = 1\text{ milliliter (ml)}$$
  $$1\text{ m}^3 = 1000\text{ dm}^3 = 1000\text{ l} = 10\text{ hl (hektoliter)}$$
  $$1\text{ l} = 10\text{ dl} = 100\text{ cl} = 1000\text{ ml}$$
