# 5. Alakzatok a térben

## Tananyag Áttekintés
Térbeli testek fogalma és csoportosítása (poliéderek, forgástestek), a testek részei (lapok, élek, csúcsok), Euler-féle poliédertétel, testek síkbeli kiterítése (hálója) és nézetei (elöl-, felül-, oldalnézet).

---

## Főbb Ismeretek és Fogalmak

### 1. Testek Csoportosítása
- **Poliéderek (soklapú testek):** Csak síklapok (sokszögek) határolják (pl. kocka, téglatest, hasábok, gúlák).
- **Forgástestek:** Görbe felület is határolja őket (pl. henger, kúp, gömb).

### 2. Testek Elemei és Kapcsolatuk
- **Csúcsok ($C$), Élek ($É$), Lapok ($L$)**
- **Kocka és Téglatest:** $8\text{ csúcs}$, $12\text{ él}$, $6\text{ lap}$
- **Euler-féle poliédertétel konvex testekre:**
  $$C + L = É + 2$$

### 3. Testháló és Nézetek
- **Testháló:** A test felületének síkba kiterített rajza.
- **Nézetek:** A térbeli test merőleges vetületei (elölnézet, felülnézet, oldalnézet).
