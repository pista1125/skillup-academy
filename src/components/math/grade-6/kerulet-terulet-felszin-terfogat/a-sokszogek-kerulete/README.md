# 2. A sokszögek kerülete

## Tananyag Áttekintés
A kerület fogalma mint a határoló vonalak összhossza, háromszögek, négyszögek és tetszőleges sokszögek kerületének kiszámítása képletekkel és gyakorlati összefüggésekkel.

---

## Főbb Képletek és Definíciók

### 1. A Kerület Definíciója
- **Kerület ($K$):** A síkidomot határoló oldalak hosszának összege.
  $$K = a + b + c + \dots$$

### 2. Nevezetes Síkidomok Kerülete
- **Általános háromszög:** $K = a + b + c$
- **Egyenlő szárú háromszög:** $K = a + 2b$
- **Szabályos háromszög:** $K = 3a$
- **Téglalap:** $K = 2 \cdot (a + b) = 2a + 2b$
- **Négyzet és rombusz:** $K = 4a$
- **Paralelogramma és deltoid:** $K = 2 \cdot (a + b)$
- **Szabályos $n$-szög:** $K = n \cdot a$
