# 1. Hosszúság, tömeg, idő

## Tananyag Áttekintés
Alapvető mértékegységek rendszere (SI alapú prefixumok), hosszúság, tömeg és idő mértékegységeinek átváltása, tizedestörtek használata a mértékváltásban és gyakorlati mérések.

---

## Főbb Mértékegységek és Váltószámok

### 1. Hosszúság Mértékegységei
- **Alapmértékegység:** méter ($\text{m}$)
- **Váltószámok:**
  $$1\text{ km} = 1000\text{ m}$$
  $$1\text{ m} = 10\text{ dm} = 100\text{ cm} = 1000\text{ mm}$$
  $$1\text{ dm} = 10\text{ cm} = 100\text{ mm}$$
  $$1\text{ cm} = 10\text{ mm}$$

### 2. Tömeg Mértékegységei
- **Alapmértékegység:** kilogramm ($\text{kg}$) és gramm ($\text{g}$)
- **Váltószámok:**
  $$1\text{ t (tonna)} = 1000\text{ kg} = 10\,000\text{ q (mázsa)}$$
  $$1\text{ q (mázsa)} = 100\text{ kg}$$
  $$1\text{ kg} = 100\text{ dkg} = 1000\text{ g}$$
  $$1\text{ dkg} = 10\text{ g}$$
  $$1\text{ g} = 1000\text{ mg}$$

### 3. Idő Mértékegységei
- **Váltószámok (vegyes alapú):**
  $$1\text{ nap} = 24\text{ óra (h)}$$
  $$1\text{ h} = 60\text{ perc (min)} = 3600\text{ másodperc (s)}$$
  $$1\text{ min} = 60\text{ s}$$
