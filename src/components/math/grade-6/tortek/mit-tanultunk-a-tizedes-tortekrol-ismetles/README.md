# 4. Mit tanultunk a tizedes törtekről? Ismétlés (Grade 6)

Ez a modul a 6. osztályos matematika tanterv **II. Törtek** fejezetének 4. altémája: **"Mit tanultunk a tizedes törtekről? Ismétlés"**.

## Komponensek
- **`DecimalFractionsTheory.tsx`**: Interaktív elméleti tananyag helyiérték-műhellyel, tört ⇄ tizedestört kalkulátorral, kerekítési műhellyel és írásbeli összeadás/kivonás szemléltetővel.
- **`DecimalFractionsQuiz.tsx`**: 30 kérdéses átfogó szintfelmérő kvíz 3 nehézségi szinten, lépésről lépésre megoldásokkal, tippekkel, képletekkel, puskakártyákkal és beágyazott játékmódokkal.
- **`FractionToDecimalMatcher.tsx`**: 3 szintű párosító játék (nevezetes törtek, bővítés/osztás, vegyes számok).
- **`DecimalFractionsSorter.tsx`**: 3 szintű csoportosító játék (nagyságrend 1-hez képest, intervallumsávok, kerekítés).
- **`index.ts`**: Tiszta exportok a modulhoz.
