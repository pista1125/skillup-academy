# 4. Mit tanultunk a tizedes törtekről? Ismétlés

## Tananyag Áttekintés
A tizedes törtek helyiérték-rendszere (tized, század, ezred), közönséges tört átírása tizedes tört alakba és viszont, tizedes törtek összehasonlítása, kerekítése, valamint összeadása és kivonása.

---

## Főbb Ismeretek és Szabályok

### 1. A Tizedes Törtek Helyiértékei
A tizedesvessző bal oldalán az egész helyiértékek (egyesek, tízesek, százasok), jobb oldalán a törtrészek állnak:
- $0{,}1 = \frac{1}{10}$ (tized)
- $0{,}01 = \frac{1}{100}$ (század)
- $0{,}001 = \frac{1}{1000}$ (ezred)

### 2. Átváltás Közönséges Tört és Tizedes Tört Között
- **Tizedes törtből közönséges tört:**
  $$0{,}75 = \frac{75}{100} = \frac{3}{4}$$
  $$1{,}2 = 1\frac{2}{10} = 1\frac{1}{5} = \frac{6}{5}$$
- **Közönséges törtből tizedes tört:**
  - Bővítéssel $10, 100, 1000$ nevezőre: $\frac{2}{5} = \frac{4}{10} = 0{,}4$.
  - Számláló osztása a nevezővel: $\frac{3}{8} = 3 : 8 = 0{,}375$.

### 3. Tizedes Törtek Összeadása és Kivonása
- Írásbeli összeadásnál és kivonásnál a számokat úgy írjuk egymás alá, hogy a **tizedesvesszők pontosan egymás alá essenek**!
- Szükség esetén a törtrész végére $0$-kat írhatunk (értéke nem változik).
