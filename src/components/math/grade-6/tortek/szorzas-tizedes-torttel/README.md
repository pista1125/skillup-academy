# 5. Szorzás tizedes törttel (Grade 6)

Ez a modul a 6. osztályos matematika tanterv **II. Törtek** fejezetének 5. altémája: **"Szorzás tizedes törttel"**.

## Komponensek
- **`DecimalMultiplicationTheory.tsx`**: Interaktív elméleti tananyag vessző-eltoló szimulátorral, tizedestört-szorzó műhellyel, 0,1-gyel/0,01-gyel szorzó laborral és becslési szabályokkal.
- **`DecimalMultiplicationQuiz.tsx`**: 30 kérdéses átfogó szintfelmérő kvíz 3 nehézségi szinten, lépésről lépésre levezetésekkel, tippekkel, képletekkel, puskakártyákkal és beágyazott játékmódokkal.
- **`DecimalMultiplicationMatcher.tsx`**: 3 szintű párosító játék (10/100/1000 és egész szám, tizedestört tizedessel, 0,1/0,01 és összetett szorzatok).
- **`DecimalMultiplicationSorter.tsx`**: 3 szintű csoportosító játék (szorzat 1-hez képest, tizedesjegyek száma, nagyságrendi tartományok).
- **`index.ts`**: Tiszta exportok a modulhoz.
