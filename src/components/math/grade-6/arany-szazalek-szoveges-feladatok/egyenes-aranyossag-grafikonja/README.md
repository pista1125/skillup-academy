# 4. Egyenes arányosság grafikonja

## Tananyag Áttekintés
Összetartozó értékpárok ábrázolása derékszögű koordináta-rendszerben, az egyenes arányosság képe (origón átmenő egyenes/félegyenes vagy pontsor), adatok leolvasása grafikonról.

---

## Főbb Ismeretek és Tulajdonságok

### 1. A Grafikon Megjelenése
- Az egyenes arányosság grafikonja a derékszögű koordináta-rendszerben egy **origón ($O(0,0)$) átmenő egyenes** (vagy félegyenes, illetve diszkrét pontok halmaza, ha a változók csak nemnegatív/egész számok lehetnek).
- Az origó $O(0,0)$ pont mindig része a kapcsolatnak ($0$ mennyiséghez $0$ érték tartozik).

### 2. Értékpárok és Grafikon Olvasása
- A vízszintes tengely ($x$) általában a független változót (pl. idő, darabszám, tömeg), a függőleges tengely ($y$) a függő változót (pl. út, fizetendő összeg) jelöli.
- A grafikon meredeksége az arányossági tényezőtől ($k$) függ: minél nagyobb a $k$, annál meredekebb az egyenes.
