# 1. Az arány fogalma

## Tananyag Áttekintés
Két azonos vagy különböző fajta mennyiség összehasonlítása osztással (hányadossal), az arány fogalma, egyszerűsítése, bővítése és szemléletes ábrázolása (keverékek, zászlók, receptek).

---

## Főbb Ismeretek és Szabályok

### 1. Az Arány Definíciója
- **Arány:** Két mennyiség hányadosa, amely megmutatja, hogy az egyik mennyiség hányszorosa a másiknak, vagy mekkora része annak.
- **Jelölése:** $a : b$ (olvasd: „$a$ aránylik a $b$-hez”), ahol $b \neq 0$.
- Az $a : b$ arány felírható közönséges tört alakban is: $\frac{a}{b}$.

### 2. Az Arány Bővítése és Egyszerűsítése
- Ha az arány mindkét tagját ugyanazzal a 0-tól különböző számmal szorozzuk vagy osztjuk, az arány értéke **nem változik**:
  $$a : b = (a \cdot k) : (b \cdot k) = (a : k) : (b : k)$$
- **Egyszerűsített alak:** A legkisebb pozitív egész számok arányaként megadott alak (pl. $6 : 8 = 3 : 4$).

### 3. Három és Többtagú Arány
- Három vagy több mennyiség egyidejű összehasonlítására összetett arányt használunk (pl. $2 : 3 : 5$).
