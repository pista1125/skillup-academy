# 2. Arányos osztás

## Tananyag Áttekintés
Adott mennyiség vagy egész felosztása megadott arány szerint, az 1 arányrészre jutó érték kiszámítása és ellenőrzése.

---

## Az Arányos Osztás Lépései

### 1. A Módszer Lépései
1. **Arányrészek összeadása:** Összeadjuk az arány tagjait, hogy megkapjuk, összesen hány egyenlő részre osztjuk a mennyiséget.
   $$\text{Összes rész} = a + b$$
2. **Egy rész értékének kiszámítása:** Az egész mennyiséget elosztjuk az összes résszel:
   $$\text{1 rész értéke} = \frac{\text{Teljes mennyiség}}{a + b}$$
3. **Az egyes részek kiszámítása:** Az 1 rész értékét megszorozzuk az arány megfelelő tagjaival ($a$-val és $b$-vel).
4. **Ellenőrzés:** A kapott részek összegének ki kell adnia a teljes kiindulási mennyiséget.

### Példa:
Osszunk el $6000\text{ Ft}$-ot $2 : 3$ arányban!
1. Összes rész: $2 + 3 = 5\text{ rész}$
2. 1 rész: $6000 : 5 = 1200\text{ Ft}$
3. Első személy: $2 \cdot 1200 = 2400\text{ Ft}$
4. Második személy: $3 \cdot 1200 = 3600\text{ Ft}$
5. Ellenőrzés: $2400 + 3600 = 6000\text{ Ft}$ és $2400 : 3600 = 2 : 3$.
