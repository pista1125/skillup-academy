# 6. A műveletek közötti kapcsolatok

## Tananyag Áttekintés
Az alapműveletek egymással való szoros kapcsolata: összeadás és kivonás, valamint szorzás és osztás mint egymás megfordított (inverz) műveletei, valamint a felcserélhetőség és csoportosíthatóság tulajdonságai.

---

## Műveleti Kapcsolatok és Tulajdonságok

### 1. Inverz Műveletek
- **Összeadás és Kivonás:**
  $$a + b = c \iff c - b = a \iff c - a = b$$
  $$3400 + 1600 = 5000 \iff 5000 - 1600 = 3400$$
- **Szorzás és Osztás:**
  $$a \cdot b = c \iff c : b = a \iff c : a = b \quad (b \neq 0, a \neq 0)$$
  $$7 \cdot 80 = 560 \iff 560 : 80 = 7$$

### 2. Műveleti Tulajdonságok
- **Felcserélhetőség (Kommutativitás):**
  - Összeadásnál: $a + b = b + a$
  - Szorzásnál: $a \cdot b = b \cdot a$
  - *(Kivonásra és osztásra NEM érvényes!)*
- **Csoportosíthatóság (Asszociativitás):**
  - $(a + b) + c = a + (b + c)$
  - $(a \cdot b) \cdot c = a \cdot (b \cdot c)$
- **Szorzás széttagolása (Disztributivitás):**
  - $(a + b) \cdot c = a \cdot c + b \cdot c$
  - $(a - b) \cdot c = a \cdot c - b \cdot c$
