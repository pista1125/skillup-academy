# 3. Összehasonlítás és változások

## Tananyag Áttekintés
Negatív és pozitív számok nagyságrendi összehasonlítása és rendezése, a relációs jelek ($<, >$) helyes alkalmazása, valamint a hőmérséklet-változások (emelkedés, süllyedés) lépései.

---

## Szabályok és Feladatok

### 1. Összehasonlítás a Számegyenes Alapján
- **Alapszabály:** A számegyenesen a **jobbra** lévő szám mindig **nagyobb**, a **balra** lévő szám mindig **kisebb**.
- **Példák:**
  - $-5 < -1$ (mert a $-1$ jobbra van a $-5$-höz képest, "a $-1$ enyhébb fagy, mint a $-5$")
  - $-8 < 0$ (minden negatív szám kisebb a nullánál)
  - $-3 < +2$ (minden negatív szám kisebb minden pozitív számnál)
  - $0 > -10$

### 2. Sorbarendezés
- **Növekvő sorrend (legkisebbtől a legnagyobbig):**
  $$-9 < -6 < -2 < 0 < +3 < +7$$
- **Csökkenő sorrend (legnagyobbtól a legkisebbig):**
  $$+8 > +4 > 0 > -1 > -5 > -10$$

### 3. Változások Kiszámítása
- **Emelkedés:** Lépés jobbra (felfelé a hőmérőn).
  - *Reggel $-4\,^\circ\text{C}$ volt, délre $6\,^\circ\text{C}$-ot emelkedett.* $\implies -4 + 6 = +2\,^\circ\text{C}$.
- **Süllyedés:** Lépés balra (lefelé a hőmérőn).
  - *Este $+3\,^\circ\text{C}$ volt, éjszaka $5\,^\circ\text{C}$-ot hűlt a levegő.* $\implies 3 - 5 = -2\,^\circ\text{C}$.
