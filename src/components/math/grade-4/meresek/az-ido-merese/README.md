# 6. Az idő mérése (4. osztály)

## Tananyag Áttekintés
Az idő mérésének, mértékegységeinek (másodperc, perc, óra, nap, hét, hónap, év, évszázad) és az időtartamok számításának elsajátítása 4. osztályos szinten.

---

## 1. Mértékegységek és Átváltások

### Alapvető összefüggések
$$1\text{ perc (min)} = 60\text{ másodperc (s)}$$
$$1\text{ óra (h)} = 60\text{ perc (min)} = 3600\text{ másodperc (s)}$$
$$1\text{ nap} = 24\text{ óra}$$
$$1\text{ hét} = 7\text{ nap}$$
$$1\text{ év} = 12\text{ hónap} = 365\text{ nap} \quad (\text{szökőévben } 366\text{ nap})$$
$$1\text{ évtized} = 10\text{ év}$$
$$1\text{ évszázad} = 100\text{ év}$$
$$1\text{ évezred} = 1000\text{ év}$$

---

## 2. Óraleolvasás és Időtartamok

### Analóg és Digitális Óra
- **Délelőtt:** `0:00` és `12:00` között.
- **Délután:** `12:00` és `24:00` között (pl. délután 4 óra = `16:00`).
- **Törtrészek:**
  - Negyed óra = $15\text{ perc}$
  - Fél óra = $30\text{ perc}$
  - Háromnegyed óra = $45\text{ perc}$

### Eltelt Idő Kiszámítása
$$\text{Időtartam} = \text{Befejezési időpont} - \text{Kezdési időpont}$$
- *Példa:* Az edzés $16:45$-kor kezdődik és $18:15$-ig tart.
  - $16:45$-től $17:00$-ig: $15\text{ perc}$
  - $17:00$-tól $18:15$-ig: $1\text{ óra } 15\text{ perc}$
  - **Összesen:** $1\text{ óra } 30\text{ perc}$.
