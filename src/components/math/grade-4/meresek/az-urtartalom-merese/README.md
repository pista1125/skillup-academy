# 5. Az űrtartalom mérése

## Tananyag Áttekintés
Folyadékok és üreges testek befogadóképességének (űrtartalmának) mérése, az űrmértékek rendszere és átváltásaik.

---

## Mértékegységek és Váltószámok

```
  1 hl (hektoliter) = 100 l
  1 l (liter)       = 10 dl = 100 cl = 1000 ml
  1 dl (deciliter)  = 10 cl = 100 ml
  1 cl (centiliter) = 10 ml
  1 ml (milliliter)
```

### 1. Váltási Példák
- $3\text{ l} = 30\text{ dl} = 300\text{ cl} = 3000\text{ ml}$
- $2\text{ hl } 40\text{ l} = 240\text{ l}$
- $45\text{ dl} = 4\text{ l } 5\text{ dl}$
- $750\text{ ml} = 7\text{ dl } 5\text{ cl} = 75\text{ cl}$

### 2. Mérőedények és Hétköznapi Térfogatok
- Mérőhenger, mérőkancsó (beosztással)
- Pohár ($\approx 2\text{ dl}$), csésze ($\approx 1{,}5 - 2{,}5\text{ dl}$)
- Tejesdoboz, üdítős palack ($1\text{ l}, 1{,}5\text{ l}, 2\text{ l}$)
- Vödör ($\approx 10-12\text{ l}$)
- Kád ($\approx 150-200\text{ l} \approx 1{,}5 - 2\text{ hl}$)
