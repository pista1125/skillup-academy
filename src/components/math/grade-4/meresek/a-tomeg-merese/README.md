# 4. A tömeg mérése

## Tananyag Áttekintés
A testek nehézségének, tömegének mérése, a tömeg mértékegységei, váltószámai, mérőeszközei és a mindennapi tömegszámítások.

---

## Mértékegységek és Váltószámok

```
  1 t (tonna)      = 1000 kg
  1 kg (kilogramm) = 100 dkg = 1000 g
  1 dkg (dekagramm)= 10 g
  1 g (gramm)
```

### 1. Váltási Példák
- $4\text{ kg} = 400\text{ dkg} = 4000\text{ g}$
- $3\text{ t } 500\text{ kg} = 3500\text{ kg}$
- $75\text{ dkg} = 750\text{ g}$
- $2500\text{ g} = 2\text{ kg } 50\text{ dkg}$

### 2. Mérőeszközök
- Kétkarú mérleg (súlysorozattal)
- Rugós mérleg
- Konyhai digitális mérleg
- Személymérleg, hídmérleg (járművekhez)

### 3. Bruttó, Nettó, Tára
- **Nettó tömeg:** Az áru valódi tömege csomagolás nélkül.
- **Tára tömeg:** A göngyöleg / csomagolás tömege önmagában.
- **Bruttó tömeg:** Össztömeg ($\text{Bruttó} = \text{Nettó} + \text{Tára}$).
