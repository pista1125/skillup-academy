# 5. Nyitott mondatok

## Tananyag Áttekintés
Olyan matematikai kijelentések, amelyekben ismeretlenek (jelek, betűk: $\square, \triangle, x$) szerepelnek. Célunk az összes olyan szám megtalálása, amely az állítást igazzá teszi.

---

## Típusok és Megoldási Módszerek

### 1. Hiányos Műveletek és Egyenlőségek
- $\square + 240 = 600 \implies \square = 600 - 240 = 360$
- $720 - \triangle = 450 \implies \triangle = 720 - 450 = 270$
- $8 \cdot x = 560 \implies x = 560 : 8 = 70$
- $y : 6 = 80 \implies y = 80 \cdot 6 = 480$

### 2. Egyenlőtlenségek és Intervallumok
- $300 + x < 305 \quad (\text{ha } x \in \mathbb{N}) \implies x \in \{0, 1, 2, 3, 4\}$
- $450 \le \square < 454 \implies \square \in \{450, 451, 452, 453\}$

### 3. Lebontogatási Lépések
- $2 \cdot \square + 50 = 170$
  1. $2 \cdot \square = 170 - 50 = 120$
  2. $\square = 120 : 2 = 60$
- **Ellenőrzés:** $2 \cdot 60 + 50 = 120 + 50 = 170$.
