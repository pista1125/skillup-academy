# 8. Játékok a logikai lapokkal

## Tananyag Áttekintés
A logikai készlet lapjaival végzett játékos tevékenységek (válogatások, mátrixok, szabályjátékok és kombinatorika) fejlesztik az absztrakt és logikai gondolkodást.

---

## Főbb Tevékenységek

### 1. Tulajdonságok és Készlet
- **Készlet elemei:** 48 db lap.
- **4 tulajdonságpár:**
  - Forma: kör, négyzet, háromszög, téglalap
  - Szín: piros, sárga, kék, zöld
  - Méret: nagy, kicsi
  - Vastagság / Lyukasság: teli / lyukas (vastag / vékony)

### 2. Válogatási Feladatok és Mátrixok
- **Egytulajdonságú válogatás:** "Minden piros elem"
- **Kéttulajdonságú válogatás (Mátrix / $2 \times 2$-es táblázat):**
  - Vízszintesen: Szín (piros / sárga)
  - Függőlegesen: Forma (kör / négyzet)
- **Különbségi láncok:** Olyan sorozat építése, ahol minden szomszédos lap pontosan 1, 2 vagy 3 tulajdonságban tér el az előzőtől.
