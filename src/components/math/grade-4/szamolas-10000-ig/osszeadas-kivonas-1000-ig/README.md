# 2. Összeadás és kivonás 1000-ig

## Tananyag Áttekintés
Szóbeli és írásbeli összeadás és kivonás háromjegyű számokkal, kerek számokkal és átlépéssel (tízes- és százasátlépés).

---

## Műveletek és Módszerek

### 1. Szóbeli Összeadás és Kivonás
- **Kerek százasok és tízesek:**
  $$300 + 400 = 700, \quad 850 - 300 = 550$$
- **Tagokra bontásos összeadás:**
  $$340 + 280 = (340 + 200) + 80 = 540 + 80 = 620$$
- **Pótlással vagy bontással történő kivonás:**
  $$630 - 270 = (630 - 200) - 70 = 430 - 70 = 360$$

### 2. Írásbeli Összeadás és Kivonás
- **Helyiértékek pontos egymás alá rendezése:** Egyes alá egyes, tízes alá tízes, százas alá százas.
- **Továbbvitel (maradék) kezelése összeadásnál.**
- **Kölcsönkérés (átváltás) kezelése kivonásnál.**
- **Ellenőrzés:** Összeadás kivonással, kivonás összeadással.
