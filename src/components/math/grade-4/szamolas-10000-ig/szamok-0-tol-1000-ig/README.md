# 1. Számok 0-tól 1000-ig

## Tananyag Áttekintés
A 3. osztályban tanult 1000-es számkör átismétlése és stabilizálása: a háromjegyű számok felépítése, helyiértékei, ábrázolása a számegyenesen és összehasonlításuk.

---

## Főbb Fogalmak és Összefüggések

### 1. A Helyiérték-rendszer 1000-ig
- **Százasok (Sz), Tízesek (T), Egyesek (E):**
  $$472 = 4\text{ Sz} + 7\text{ T} + 2\text{ E} = 400 + 70 + 2$$
- **Alaki érték:** A leírt számjegy önmagában ($4, 7, 2$).
- **Helyiérték:** A hely, ahol a számjegy áll (százasok helye $\rightarrow 100$, tízesek helye $\rightarrow 10$, egyesek helye $\rightarrow 1$).
- **Valódi érték:** Az alaki érték és a helyiérték szorzata ($400, 70, 2$).

### 2. A Számegyenes és Számszomszédok 1000-ig
- **Egyes szomszédok (kisebb/nagyobb):** $358 < 359 < 360$
- **Tízes szomszédok:** $350 < 359 < 360$
- **Százas szomszédok:** $300 < 359 < 400$
- **Páros és páratlan számok:** Páros számok utolsó számjegye $0, 2, 4, 6, 8$; páratlan számoké $1, 3, 5, 7, 9$.
