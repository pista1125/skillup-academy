# 1. Síkidomok, sokszögek

## Tananyag Áttekintés
A 2D síkidomok és sokszögek vizsgálata: az oldalak, csúcsok és belső szögek száma, a sokszögek elnevezései, a háromszögek és négyszögek főbb fajtái, valamint az egyenesek kölcsönös helyzete (párhuzamos, merőleges, metsző).

---

## Főbb Fogalmak és Csoportosítás

### 1. Sokszögek Felépítése
- Olyan zárt törött vonallal határolt síkrész, amelynek oldalai egyenes szakaszok.
- **Háromszögek (3 oldal, 3 csúcs, 3 szög):** hegyesszögű, derékszögű, tompaszögű; egyenlő szárú, egyenlő oldalú (szabályos).
- **Négyszögek (4 oldal, 4 csúcs, 4 szög):** négyzet, téglalap, rombusz, paralelogramma, trapéz, deltoid.
- **További sokszögek:** ötszög, hatszög, nyolcszög.

### 2. Egyenesek és Szakaszok Kölcsönös Helyzete
- **Párhuzamos egyenesek ($a \parallel b$):** Nem metszik egymást, távolságuk mindenütt azonos.
- **Metsző egyenesek:** Egyetlen közös pontjuk van.
- **Merőleges egyenesek ($a \perp b$):** Egymást $90^\circ$-os derékszögben metszik.
