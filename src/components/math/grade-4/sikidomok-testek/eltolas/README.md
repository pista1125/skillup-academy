# 6. Eltolás

## Tananyag Áttekintés
Síkidomok párhuzamos eltolása adott irányba és meghatározott távolságra a négyzethálón, az egybevágóság és az állás megőrzése.

---

## Az Eltolás Jellemzői

### 1. Főbb Szabályok
- **Alak-, méret- és szögtartás:** Az eltolt alakzat pontosan egybevágó az eredetivel.
- **Állástertás:** Az eltolt alakzat nem fordul el, az oldalak párhuzamosak maradnak az eredeti oldalakkal.
- **Minden pont azonos irányban és távolságra mozdul el:**
  - *Példa utasítás:* "Told el az alakzatot $4$ négyzettel jobbra és $2$ négyzettel fel!"

### 2. Eltolás Alkalmazása
- Díszítősorok, mintázatok, sorminták készítése
- Parkettázás, mozaikok
- Animációk és számítógépes grafikák alapeleme
