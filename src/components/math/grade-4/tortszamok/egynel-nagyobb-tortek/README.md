# 3. Az 1 egész és az egynél nagyobb törtek

## Tananyag Áttekintés
Az egésszel egyenlő és az egynél nagyobb törtek szemléltetése: több egész pizza felosztása, áltörtek és vegyes számok kapcsolata.

---

## Egészek és Egynél Nagyobb Törtek

### 1. Az 1 Egész Törtalakjai
- Ha a számláló megegyezik a nevezővel ($\text{Számláló} = \text{Nevező}$), a tört értéke pontosan **1 egész**:
  $$\frac{2}{2} = \frac{3}{3} = \frac{4}{4} = \frac{10}{10} = 1$$

### 2. Egynél Nagyobb Törtek (Áltörtek)
- Ha a **számláló nagyobb a nevezőnél** ($\text{Számláló} > \text{Nevező}$), a tört értéke nagyobb $1$ egésznél:
  - $\frac{5}{4}$: $5$ darab negyed (ami több, mint egy egész pizza).

### 3. Vegyes Szám Alak
Egy egynél nagyobb törtet felírhatunk egész és törtrész összegeként (vegyes számként):
- $\frac{5}{4} = \frac{4}{4} + \frac{1}{4} = 1 \text{ egész } \frac{1}{4}$
- $\frac{7}{3} = \frac{6}{3} + \frac{1}{3} = 2 \text{ egész } \frac{1}{3}$
- $\frac{11}{5} = 2 \text{ egész } \frac{1}{5}$
