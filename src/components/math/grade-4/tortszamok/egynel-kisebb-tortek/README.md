# 2. Egynél kisebb törtek

## Tananyag Áttekintés
A valódi törtek tulajdonságai: amikor a tört értéke kisebb $1$ egésznél, az egészből hiányzó rész kiszámítása, törtrészek színezése és leolvasása.

---

## A Valódi Törtek Jellemzői

### 1. Definíció
- Egy tört értéke **kisebb 1 egésznél**, ha a **számlálója kisebb a nevezőjénél** ($\text{Számláló} < \text{Nevező}$).
- **Példák:** $\frac{1}{2}, \frac{2}{3}, \frac{3}{5}, \frac{7}{10}, \frac{5}{8}$.

### 2. Kiegészítés 1 Egészre
- Ha megettünk a torta $\frac{3}{8}$ részét, mennyi maradt meg belőle?
  $$1 - \frac{3}{8} = \frac{8}{8} - \frac{3}{8} = \frac{5}{8}$$
- **Szabály:** A meglévő és a hiányzó rész számlálójának összege kiadja a nevezőt!
  - $\frac{2}{5} + \frac{3}{5} = \frac{5}{5} = 1$
  - $\frac{7}{10} + \frac{3}{10} = \frac{10}{10} = 1$
