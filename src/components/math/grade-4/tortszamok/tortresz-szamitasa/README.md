# 5. Törtrész kiszámítása és szöveges feladatok

## Tananyag Áttekintés
Mennyiségek törtrészének kiszámítása lépésről lépésre, valamint a mindennapi életből vett szöveges feladatok megoldása (idő, pénz, tömeg, hosszúság, űrmérték).

---

## A Törtrész Kiszámításának Menete

### 1. Lépések Két Lépésben:
1. **1 rész értéke:** Elosztjuk az alapmennyiséget a nevezővel ($: \text{nevező}$).
2. **Kért részek értéke:** Az eredményt megszorozzuk a számlálóval ($\cdot \text{ számláló}$).

### 2. Példák:
- **Számold ki $36$-nak a $\frac{3}{4}$ részét!**
  1. $36 : 4 = 9$ (ez $1$ negyed rész)
  2. $9 \cdot 3 = 27$ (ez $3$ negyed rész)
  $$\text{Tehát } 36\text{-nak a } \frac{3}{4} \text{ része } = 27.$$

- **Mennyi $1\text{ óra}$ $\frac{2}{3}$ része?**
  1. $1\text{ óra} = 60\text{ perc}$
  2. $60 : 3 = 20\text{ perc}$ ($1$ harmad)
  3. $20 \cdot 2 = 40\text{ perc}$ ($2$ harmad)
  $$\text{Tehát } 1\text{ óra } \frac{2}{3}\text{ része } = 40\text{ perc}.$$

- **Mennyi $1000\text{ Ft}$ $\frac{3}{10}$ része?**
  $$1000 : 10 = 100\text{ Ft} \implies 100 \cdot 3 = 300\text{ Ft}.$$
